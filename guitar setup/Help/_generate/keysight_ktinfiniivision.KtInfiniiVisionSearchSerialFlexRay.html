KtInfiniiVisionSearchSerialFlexRay¶

Access interface members using: driver.search.serial.flex_ray
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSearchSerialFlexRay¶

KtInfiniiVisionSearchSerialFlexRay interface.

property cycle_number¶

Sets and gets the cycle value to find when searching for FlexRay frames.

Access:

ReadWrite

Type:

str

Remarks:
The CycleNumber property can be specified in one of the following formats:
  • "ALL"
  • "n", where n: an integer from 0-63
property frame_id¶

Sets and gets the frame ID value to find when searching for FlexRay frames.

Access:

ReadWrite

Type:

str

Remarks:
The FrameID property can be specified in one of the following formats:
  • "ALL"
  • "n", where n is an integer from 1-2047
property mode¶

Sets and gets the type of FlexRay information to find in the Lister display.

Access:

ReadWrite

Type:

SearchSerialFlexRayMode

Remarks:
The Mode property can be set to one of the following values:
  • FrameID: Finds frames with the specified ID.
  • CycleNumber: Finds frames with the specified cycle number and ID.
  • ModeData: Finds frames with the specified data, cycle number and frame ID.
  • HeaderCRC: Finds cyclic redundancy check errors in headers.
  • FrameCRC: Finds cyclic redundancy check errors in frames.
  • AllErrors: Finds all errors.
property pattern_data¶

Seta nd gets the data value to find when searching for FlexRay frames.

Access:

ReadWrite

Type:

str

Remarks:
The PatternData property can be specified in the following format: "nn..n", where n: { 0 | 1 | X }
property pattern_data_length¶

Sets and gets the length (from 1 to 12) of data values when searching for FlexRay frames.

Access:

ReadWrite

Type:

int

Remarks:
To specify the data value use SearchSerialFlexRay property.
