KtInfiniiVisionSearchSerialUSB¶

Access interface members using: driver.search.serial.usb
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSearchSerialUSB¶

KtInfiniiVisionSearchSerialUSB interface.

property address¶

Sets and gets the 7-bit Address portion of the search value (in hex.)

Access:

ReadWrite

Type:

str

Remarks:
• Its value can be in string format as "0xnn" where n : {0,..,9 | A,..,F | X | $ }
• Only supported for X4000 and X6000 series oscilloscopes.
