KtInfiniiVisionTriggerDelay¶

Access interface members using: driver.trigger.delay
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionTriggerDelay¶

KtInfiniiVisionTriggerDelay interface.

property arming_slope¶

Specifies rising (Positive) or falling (Negative) for the arming edge in the Edge Then Edge trigger.

Access:

ReadWrite

Type:

TriggerDelaySlope

Remarks:
The ArmingSlope property can be set to one of the following values:
  • Negative: specifies falling (Negative) for the arming edge in the Edge Then Edge trigger
  • Positive: specifies rising (Positive) for the arming edge in the Edge Then Edge trigger
property arming_source¶

Selects the input used for the arming edge in the Edge Then Edge trigger.

Access:

ReadWrite

Type:

str

Remarks:
The ArmingSource property can be specified in one the following string formats:
  • "Channel<n>", where <n> can be from 1 to the number of analog channels.
  • "DigitalChannel<d>", where <d> can be from 0 to the number of digital channels minus 1.
configure(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionTriggerDelay, trigger_source: str, trigger_slope: keysight_ktinfiniivision.keysight_ktinfiniivision.TriggerDelaySlope, edge_count: int, arming_source: str, arming_slope: keysight_ktinfiniivision.keysight_ktinfiniivision.TriggerDelaySlope, delay_time: float) → None¶

Configures the trigger source, trigger slope, edge count, arming source, arming slope and the delay time parameters for the Edge Then Edge trigger.

Parameters:

  • trigger_source (str) – Specifies the input used for the trigger edge in the Edge Then Edge trigger.

  • trigger_slope (TriggerDelaySlope) – Specifies rising (Positive) or falling (Negative) for the trigger edge in the Edge Then Edge trigger.

  • edge_count (int) – Sets the Nth edge of the trigger source to trigger on

  • arming_source (str) – Selects the input used for the arming edge in the Edge Then Edge trigger.

  • arming_slope (TriggerDelaySlope) – Specifies rising (Positive) or falling (Negative) for the arming edge in the Edge Then Edge trigger.

  • delay_time (float) – Sets the delay time between the arming edge and the trigger edge in the Edge Then Edge trigger. The time is in seconds and must be from 4 ns to 10 s.

Returns:

None
