KtInfiniiVisionMathFunctionMeasurementTrend¶

Access interface members using: driver.math_functions[<name_or_index>].measurement_trend
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionMathFunctionMeasurementTrend¶

KtInfiniiVisionMathFunctionMeasurementTrend interface.

property slot¶

The measurement whose trend is shown in the math waveform.

Access:

ReadWrite

Type:

MeasurementSlot

Remarks:
  • This property is not supported by 2000X and 3000X series.
  • There are 10 locations (or slots) that installed measurements can occupy. The Measure<n> parameter specifies the location of the measurement whose trend you want to analyze.
  • If no measurements are installed, this returns None
  • Preset value is None.
    • property type¶

    Specifies the measurement whose trend is shown in the math waveform.

    Access:

    ReadWrite

    Type:

    MathMeasurementTrendType

    Remarks:
    This property is not supported for T3000, X400, M9240X, P9240X and 6000X series oscilloscopes.
