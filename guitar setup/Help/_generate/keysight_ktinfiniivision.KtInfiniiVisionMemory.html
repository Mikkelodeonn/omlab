recall(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionMemory, options: keysight_ktinfiniivision.keysight_ktinfiniivision.MemoryRecallOptions, file_name: str) → None¶

Recall option for Mask, Oscilloscope Setup and Reference memory.

Parameters:

  • options (MemoryRecallOptions) – Recall Options

  • file_name (str) – Specifies file to be recalled.

Returns:

None

Remarks:

• For Mask: If a file extension is provided as part of a specified <file_name>, it must be ".msk". The value of internal location specified as a part of string will range from 1 to 3.
• For Setup: If a file extension is provided as part of a specified <file_name>, it must be ".scp". The value of internal location specified as a part of string will range from 0 to 9.
• For WMemory: If a file extension is provided as part of a specified <file_name>, it must be ".h5".

• The data segment which is part of string lets you recall a reference waveform from a local file on the controller PC (instead of from a USB storage device connected to the oscilloscope).
• In this case, your remote program reads data from the local ".h5" format reference waveform file in the same way that setup files are restored to the oscilloscope

• For Arbitrary: If a file extension is provided as part of a specified <file_name>, it must be ".csv".

• For internal locations, the column not be mentioned in string.
• For external (USB storage device) files iis optional to mention as a part of string or not. If specified in string, the 2nd column(assumed to be voltage) is automatically be selected. And if not and that column does not exist in the file, then the operation gets failed.
• The string input values have wavegen id which specifies which waveform generator to recall the arbitrary waveform into.
• When recalling arbitrary waveforms (from an external USB storage device) that were not saved from the oscilloscope, be aware that the oscilloscope uses a maximum of 8192 points for an arbitrary waveform. For more efficient recalls, make sure your arbitrary waveforms are 8192 points or less.

• For LDF:If a file extension is provided as part of a specified <file_name>, it must be ".ldf". The serialbus segment which is a part of string specifies which serial decode waveform the LIN symbolic data will be loaded for.
• For DBC:If a file extension is provided as part of a specified <file_name>, it must be ".dbc". The serialbus segment which is a part of string specifies which serial decode waveform the CAN symbolic data will be loaded for.
property reference_waveform_source¶

Sets and gets the source to be saved as a reference waveform file.

Access:

ReadWrite

Type:

str

Remarks:

• Only Addition or Substract math operations can be saved as reference waveforms.
• The <source> can be specified in one of the following string formats:

• "Channel<n>", where n: 1 to the number of available analog channels.
• "Math<m>", where m : 1 to number of available math functions. For X1000, X1200, X2000 and X3000 series oscilloscopes only "Math" or "Math1" is valid.
• "Function<m>", where m : 1 to number of available math functions. For X1000, X1200, X2000 and X3000 series oscilloscopes only "Functon" or "Function1" is valid.
• "WMemory<m>", where m : 1 to number of available reference waveforms.For X1000, X1200, X2000 and X3000 series oscilloscopes the value of r will be from 1 to 2.

• "Math" is an alias "Function". So for both the sources "Function" is returned.

save(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionMemory, options: keysight_ktinfiniivision.keysight_ktinfiniivision.MemorySaveOptions, file_name: str) → None¶

Save option for Mask, Image, Lister display data, Oscilloscope Setup, Waveform data and Reference memory.

Parameters:

  • options (MemorySaveOptions) – Save options

  • file_name (str) – Specifies file to be saved.

Returns:

None

Remarks:

• For Image:

• Be sure to set the MemoryImageFormat before saving an image. If the format is None, the save image command will not succeed.
• If a file extension is provided as part of a specified <file_name>, and it does not match the extension expected by the format, the format will be changed if the extension is a valid image file extension.
• If the extension ".bmp" is used and the current format is not BMP or BMP8, the format will be changed to BMP.

• For Waveform:

• Be sure to set the MemoryWaveformFormat before saving an image. If the format is None, the save image command will not succeed.
• If a file extension is provided as part of a specified <file_name>, and it does not match the extension expected by the format, the format will be changed if the extension is a valid image file extension.

• For WMemory: If a file extension is provided as part of a specified <file_name>, it must be ".h5".
• For Setup: If a file extension is provided as part of a specified <file_name>, it must be ".scp". The value of internal location which is a part of string will range from 0 to 9.
• For Setup: If a file extension is provided as part of a specified <file_name>, it must be ".msk". The value of internal location which is a part of string will range from 0 to 3.
• For Lister: If a file extension is provided as part of a specified <file_name>, it must be ".csv".
• For Setup: If a file extension is provided as part of a specified <file_name>, it must be ".msk".
• For Arbitrary:

• The wavegen id which is a part of input spring specifies which waveform generator to save the arbitrary waveform from.
• If a file extension is provided as part of a specified <file_name>, it must be ".csv".
• The value of internal location which is a part of string will range from 0 to 3.

• For Multi: If a file extension is provided as part of a specified <file_name>, it must be ".h5".
• For Results:

• It saves analysis results to a comma-separated values (.csv) file on a USB storage device.
• When multiple types of analysis results are selected, they are all saved to the same file and separated by a blank line.

• For Power: If a file extension is provided as part of a specified <file_name>, it must be ".csv".
• For Compliance USB: If a file extension is provided as part of a specified <file_name>, it must be ".html".

property waveform_format¶

Sets and gets the selected data format type of waveform.

Access:

ReadWrite

Type:

MemoryWaveformFormat

Remarks:

• On selecting

• ASCII: It creates a comma-separated value files for each analog channel that is displayed (turned on). The proper file extension for this format is ".csv".
• CSV: It creates one comma-separated value file that contains information for all analog channels that are displayed (turned on). The proper file extension for this format is ".csv".
• Binary: It creates an oscilloscope binary data format file. See the User's Guide for a description of this format. The proper file extension for this format is ".bin".

• When "None" is returned, it indicates that an image file format is currently selected.
