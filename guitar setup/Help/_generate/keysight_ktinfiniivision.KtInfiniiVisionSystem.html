disable_local_controls(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionSystem) → None¶

Puts the instrument into a state where all local controls, including return to local, are disabled from changing the state of the instrument. The power switch is excluded.

Returns:

None

Remarks:

• The client program can ensure that an operator cannot change the state of an instrument through its front panel.
• This method is only supported by instruments using a GPIB connection.
• It is the equivalent of sending a local lockout message over the programming interface.
• It disables the front panel.
eject_usb(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionSystem, usb_path: str) → None¶

Ejects connected USB storage devices.

Parameters:

usb_path (str) – Path of USB storage device. See Remarks for path details.

Returns:

None

Remarks:
• Parameters:
• All: When the "All" parameter is given as input, all connected USB storage devices will get dismounted/ejected.
• USB Path of your storage device: Parameter should be a string that may contain letters, numbers, spaces, and other common characters.

• The USB mass storage device before unplugging must be ejected otherwise, the device will be marked as needing repair when connecting to a computer with the Windows operating system (even though there are no harmful effects to the device).

property protection_enabled¶

Enables/Disables the fifty ohm impedance setting for all analog channels by specifying the analog channel protection lock status.

Access:

ReadWrite

Type:

bool

Remarks:
Be careful when enabling this property because there is no visual indication of this setting in the front-panel user interface (other than a disabled 50 Ω channel input impedance selection), and a user could think the oscilloscope is not working properly.

property time_zone¶

Sets and gets the system time zone based on the specified offset from UTC.

Access:

ReadWrite

Type:

int

Remarks:

• <UTC_offset> is an integer offset from UTC in the form HHMM, for example, 1000 for UTC+1000 or -230 for UTC-0230.
• This keeps local time constant and moves the UTC by setting the system clock to match the displayed oscilloscope clock.
• Supported time zone offsets are: -1200, -1100, -1000, -900, -800, -700, -600, -500, -400, -330, -300, -230, -200, -100, 0, 100, 200, 300, 330, 400, 430, 500, 530, 600, 700, 800, 845, 900, 930, 1000, 1030, 1100, 1200
