class KtInfiniiVisionCounter¶

KtInfiniiVisionCounter interface.

configure(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionCounter, resolution_digits: int, source: str) → None¶

This method sets the counter mode, source and Number of digits of resolution used for the frequency or period counter.

Parameters:

  • resolution_digits (int) – The number of digits of resolution used for the frequency or period counter. This parameter can be used when Mode is set to requency and Period.

  • source (str) – The waveform source that the counter measures. Input value can be from Channel1 to number of analog channels or TQEvent.

Returns:

None

Remarks:
• The parameter value of <resolutionDigits> for:

• T3000 Series: from 3 to 8
• X4000 Series: 5 normally, 8 with 10 MHz reference signal
• X6000 Series: from 3 to 10
• M9240X Series: from 3 to 8
• P9240X Series: from 3 to 8

• The parameter <source> can be specified in one of the following string formats: { Channel<n> | TqEvent } where n: 1 to the number of available analog channels.
• Input value TqEvent is not available when Trigger type is edge.
• Preset value is Channel1.
• Higher resolutions require longer gate times, which cause the measurement times to be longer as well.
• For 4000X series :class:`KtInfiniiVisionCounter`.ResolutionDigits is a read only property. So :class:`KtInfiniiVisionCounter`.Configure will skip to set :class:`KtInfiniiVisionCounter`.ResolutionDigits. The number of digits is not adjustable and is normally 5 digits. However, the resolution can be increased to 8 digits by inputting an external 10 MHz reference signal to the oscilloscope (on the rear panel 10MHz REF connector).
• To see how often trigger events are detected, "TqEvent" (Triggerd Qualified Event) can be specified as source. This can be more often than when triggers actually occur, due to the oscilloscope's acquisition time or update rate capabilities.
• When Trigger Out signal is selected as source, it shows triggers that actually occur.
• The oscilloscope's trigger circuitry does not re-arm until the holdoff time occurs and that the minimum holdoff time is 40 ns; therefore, the maximum trigger qualified event frequency that can be counted is 25 MHz.

property mode¶

Sets and gets the counter mode.

Access:

ReadWrite

Type:

CounterMode

Remarks:
The counter modes are:
  • Freqency: the cycles per second (Hz) of the signal.
  • Period: the time periods of the signal's cycles.
  • Totalize: the count of edge events on the signal. Not available for X4000 Series.
  • Preset value is Frequency.
