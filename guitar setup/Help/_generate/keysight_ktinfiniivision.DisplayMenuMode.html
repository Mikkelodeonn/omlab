DisplayMenuMode¶

class DisplayMenuMode¶

Selects the appropriate Menu mode for display.

Members:

MASK : Display Menu is of Mask mode.

MEASURE : Display Menu is of Measure mode.

SEGMENTED : Display Menu is of Segmented mode.

LISTER : Display Menu is of Lister mode.

POWER : Display Menu is of Power mode.

OFF : Sets the Display Menu to OFF.
