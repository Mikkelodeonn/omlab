KtInfiniiVisionSerialBusManchester¶

Access interface members using: driver.serial_buses[<name_or_index>].manchester
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSerialBusManchester¶

KtInfiniiVisionSerialBusManchester interface.

property base¶

Sets and gets the base for the Manchester bus decode and Lister display when the display format is WORD.

Access:

ReadWrite

Type:

SerialBusManchesterBase

Remarks:
When the display format is bit, the only legal decode base value is Binary.
property baud_rate¶

Sets and gets the baud rate of the Manchester signal.

Access:

ReadWrite

Type:

int

Remarks:
Range : 500 to 5000000 in 100 b/s increments.
property bit_order¶

Sets and gets the order of transmission (MSB or LSB first) on the Manchester bus when the display format is WORD.

Access:

ReadWrite

Type:

SerialBusManchesterBitOrder

Remarks:

• MSBFirst: specifies the most significant bit is transmitted first.
• LSBFirst: specifies the least significant bit is transmitted first.
property data_words_size¶

Sets and gets the number of words in the data field of Manchester protocol definition when the display format is WORD.

Access:

ReadWrite

Type:

int

Remarks:

• Range : 0 to 255.
• In Auto Mode, the value retunred is 0.
• In Bit format, noly allowed value is 0.
property display¶

Sets and gets the format of the Manchester bus display.

Access:

ReadWrite

Type:

SerialBusManchesterDisplay

property header_size¶

Sets and gets the number of bits in the header field of Manchester protocol definition when the display format is WORD.

Access:

ReadWrite

Type:

int

Remarks:
Range : 0 to 32
property idle_time¶

Sets and gets the minimum idle time or inter-frame gap time in terms of the number of bits.

Access:

ReadWrite

Type:

float

Remarks:
Range : minimum idle time, 1.50 to 32.00 in 0.25 increments
property polarity¶

Sets and gets the polarity of the Manchester signal.

Access:

ReadWrite

Type:

SerialBusManchesterPolarity

Remarks:
  • Falling: A falling edge is used to encode a bit value of logic 1 (and a rising edge encodes a bit value of logic 0).
  • Rising: A rising edge is used to encode a bit value of logic 1.
    • property source¶

    Sets and gets the oscilloscope channel connected to the Manchester signal line.

    Access:

    ReadWrite

    Type:

    str

    Remarks:
    Source can be of the format:
    • "Channel<n>", where <n> can be from 1 to the number of analog channels.
    • "DigitalChannel<d>", where <d> can be from 0 to the number of digital channels minus 1.
    property start_edge¶

    Sets and gets the starting edge of the Manchester signal.

    Access:

    ReadWrite

    Type:

    int

    Remarks:
    Range : 1 to 256
    property sync_size¶

    Sets and gets the number of sync bits for the Manchester signal.

    Access:

    ReadWrite

    Type:

    int

    Remarks:
    Range : 0 to 255
    property tolerance¶

    Sets and gets the tolerance for the Manchester signal in terms of the percentage of the bit period.

    Access:

    ReadWrite

    Type:

    int

    Remarks:
    Range : 5 to 30
    property trailer_size¶

    Sets and gets the number of bits in the trailer field of Manchester protocol definition.

    Access:

    ReadWrite

    Type:

    int

    Remarks:
    Range : 0 to 32
    property trigger_mode¶

    Sets and gets the trigger mode.

    Access:

    ReadWrite

    Type:

    SerialBusManchesterTriggerMode

    Remarks:
  • SOF (Start Of Frame): triggers at the start of a Manchester frame, after the starting edge.
  • Value: triggers on the specified bit values.
  • Merror: triggers on a Manchester error.
    • property trigger_value_data¶

    Sets and gets the value to trigger on when the trigger mode is Value.

    Access:

    ReadWrite

    Type:

    str

    Remarks:

    • The TriggerValueData can be specified in one of the following string formats:

    • "nn...n", where n: {0 | 1 | X | $}
    • "0xnn...n", where n: {0,..,9 | A,..,F | X | $}

    • The Trigger value bit order is always for bits as they arrive (that is, MSB first) regardless of the serial decode bit order setting.
    • The bit width (length) of the value is set with the using SerialBusManchesterTriggerValueLength property.
    property trigger_value_length¶

    Sets and gets the bit width (length) of the value to trigger on when the trigger mode is value.

    Access:

    ReadWrite

    Type:

    int

    Remarks:

    • Range: from 4 to 128.
    • The actual value to trigger on is set with the SerialBusManchesterTriggerValueData property.
    property word_size¶

    Sets and gets the number of bits per word in the data field of Manchester protocol definition.

    Access:

    ReadWrite

    Type:

    int

    Remarks:
    Range : 2 to 32
