KtInfiniiVisionWaveGenArbitraryAttribute¶

Access interface members using: driver.wave_gens[<name_or_index>].arbitrary.attribute
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionWaveGenArbitraryAttribute¶

KtInfiniiVisionWaveGenArbitraryAttribute interface.

property number_of_points¶

Read Only - Gets the number of points used by the current Arbitrary waveform.

Access:

ReadOnly

Type:

int

Remarks:

• On T3000, X4000, X6000, M9240X and P9240X series oscilloscopes it supports both waveform generators (i.e. WaveGen1, WaveGen2).
• On X3000 series oscilloscopes it supports one waveform generator only (i.e WaveGen1).
