KtInfiniiVisionTriggerUSB¶

Access interface members using: driver.trigger.usb
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionTriggerUSB¶

KtInfiniiVisionTriggerUSB interface.

property condition¶

Sets and get where the USB trigger will occur.

Access:

ReadWrite

Type:

TriggerUSBCondition

Remarks:
  • The Condition property can be set to one of the following values:
    • StartOfPacket: Start of packet
    • EndOfPacket: End of packet
    • EnterSuspend: Enter suspend state
    • ExitSuspend: Exit suspend state
    • Reset: Reset complete

  • Not supported for X4000 and X6000 series oscillocopes. But for X4000 series use SerialBusesUSBSpeed property.
    • configure(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionTriggerUSB, condition: keysight_ktinfiniivision.keysight_ktinfiniivision.TriggerUSBCondition, speed: keysight_ktinfiniivision.keysight_ktinfiniivision.TriggerUSBSpeed, d_plus_source: str, d_minus_source: str) → None¶

    Configures the condition, speed, D+ source and D- source parameters for a USB trigger.

    Parameters:

    • condition (TriggerUSBCondition) – Specifies where the USB trigger will occur.

    • speed (TriggerUSBSpeed) – Specifies the expected USB signal speed to be Low Speed (1.5 Mb/s) or Full Speed (12 Mb/s).

    • d_plus_source (str) – Specifies the source for the USB D+ signal.

    • d_minus_source (str) – Specifies the source for the USB D- signal.

    Returns:

    None

    Remarks:
    Not supported for X4000 and X6000 series oscillocopes. But for X4000 series use SerialBusesUSBSpeed property.
    property d_minus_source¶

    Sets and gets the source for the USB D- signal.

    Access:

    ReadWrite

    Type:

    str

    Remarks:

    • The DMinusSource can be specified in one the following string formats:

    • For DSO Models:

    • "Channel<n>", where <n> can be from 1 to the number of analog channels.
    • "VAL_EXTERNAL", for External

    • For MSO Models:

    • "Channel<n>", where <n> can be from 1 to the number of analog channels.
    • "DigitalChannel<d>", where <d> can be from 0 to the number of digital channels minus 1.

    • Not supported for X4000 and X6000 series oscillocopes. But for X4000 series use SerialBusesUSBSpeed property.
    property d_plus_source¶

    Sets and gets the source for the USB D+ signal.

    Access:

    ReadWrite

    Type:

    str

    Remarks:

    • The DPlusSource can be specified in one the following string formats:

    • For DSO Models:

    • "Channel<n>", where <n> can be from 1 to the number of analog channels.
    • "VAL_EXTERNAL", for External

    • For MSO Models:

    • "Channel<n>", where <n> can be from 1 to the number of analog channels.
    • "DigitalChannel<d>", where <d> can be from 0 to the number of digital channels minus 1.

    • Not supported for X4000 and X6000 series oscillocopes. But for X4000 series use SerialBusesUSBSpeed property.
    property speed¶

    Sets and gets the expected USB signal speed to be Low Speed (1.5 Mb/s) or Full Speed (12 Mb/s).

    Access:

    ReadWrite

    Type:

    TriggerUSBSpeed

    Remarks:

    • The Speed property can be set to one of the following values:

    • Low: sets the expected USB signal speed to be Low Speed (1.5 Mb/s).
    • Full: sets the expected USB signal speed to be Full Speed (12 Mb/s).

    • Not supported for X4000 and X6000 series oscillocopes. But for X4000 series use SerialBusesUSBSpeed property.
