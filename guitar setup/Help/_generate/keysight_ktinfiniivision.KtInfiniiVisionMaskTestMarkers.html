KtInfiniiVisionMaskTestMarkers¶

Access interface members using: driver.mask_test.markers
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionMaskTestMarkers¶

KtInfiniiVisionMaskTestMarkers interface.

property x1_coordinate¶

The position of X1 coordinate where X=0 in the base coordinate system used for mask testing. The X1 value is a time value specifying the location of the X1 coordinate, which will then be treated as X=0 for mask regions coordinates.

Access:

ReadWrite

Type:

float

Remarks:
• Once the X1 and XDELta coordinates are set, all X values of vertices in the mask regions are defined with respect to this value, according to the equation: X = (X \* deltaX) + X1
• Thus, if X1 is set o 100 ms, and XDelta to 100 ms, an X value of 0.100 is a vertex at 110 ms.
• The oscilloscope uses this equation to normalize vertices. This simplifies reprogramming to handle different data rates.
• For example, if you halve the period of the waveform of interest, you need only to adjust the XDelta value to set up the mask for the new waveform.
property x_delta¶

The position of the X2 marker with respect to the X1 marker. In the mask test coordinate system, the X1 marker defines where X=0; thus, the X2 marker defines where X=1.

Access:

ReadWrite

Type:

float

Remarks:
• Because all X vertices of the regions defined for mask testing are normalized with respect to X1 and deltaX, redefining DeltaX also moves those vertices to stay in the same locations with respect to X1 and DeltaX.
• In many applications, it is best if you define XDelta as a pulse width or bit period.
• A change in data rate without corresponding changes in the waveform can easily be handled by changing DeltaX.
• The X-coordinate of polygon vertices is normalized using this equation: X = (X \* deltaX) + X1
• The X delta value is a time value specifying the distance of the X2 marker with respect to the X1 marker.
• For example, if the period of the waveform you wish to test is 1 ms, setting deltaX to 1 ms ensures that the waveform's period is between the X1 and X2 markers.
property y1_coordinate¶

Position of Y1 coordinate where Y=0 in the base coordinate system used for mask testing.

Access:

ReadWrite

Type:

float

Remarks:
• All Y values of vertices in the coordinate system are defined with respect to the boundaries set by MarkersY1Position and this property according to the equation: Y = (Y \* (Y2 - Y1)) + Y1
• If you set Y1 to 100 mV, and Y2 to 1 V, a Y value of 0.100 in a vertex is at 190 mV.
• The Y1 value is a voltage value specifying the location of the Y1 marker.
property y2_coordinate¶

Position of the Y2 marker with respect to the Y1 marker. In the mask test coordinate system, the Y1 marker defines where Y=0; thus, the Y2 marker defines where Y=1.

Access:

ReadWrite

Type:

float

Remarks:
• All Y values of vertices in the coordinate system are defined with respect to the boundaries set by this property and MarkerY2Position property according to the equation: Y = (Y \* (Y2 - Y1)) + Y1
• If you set Y1 to 100 mV, and Y2 to 1 V, a Y value of 0.100 in a vertex is at 190 mV.
• The Y2 value is a voltage value specifying the location of the Y2 marker.
