SearchI2SMode¶

class SearchI2SMode¶

To specify the type of I2S information to find in the Lister display.

Members:

EQUAL : Search for the specified audio channel’s data word when it equals the specified word.

NOT_EQUAL : Searches for any word other than the specified word.

LESS_THAN : Search for channel data words less than the specified value.

GREATER_THAN : Search for channel data words greater than the specified value.

IN_RANGE : Search for channel data words in the range.

OUT_RANGE : Searches for channel data words outside the range.
