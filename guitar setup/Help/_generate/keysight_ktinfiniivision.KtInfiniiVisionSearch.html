KtInfiniiVisionSearch¶

Access interface members using: driver.search
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSearch¶

KtInfiniiVisionSearch interface.

property count¶

Read Only - Gets the number of search events found.

Access:

ReadOnly

Type:

int

Remarks:

• This property performs a digitize operation, so it's important that user trigger is set up so that data is captured and is available to perform the search on.
• User can get times out because there is no data to search, user may need to send a device clear to the oscilloscope to cancel its wait for the data.
property edge¶

Reference to the KtInfiniiVisionSearchEdge interface.

Access:

Readonly

Type:

KtInfiniiVisionSearchEdge

property enabled¶

Enables or disables the search feature.

Access:

ReadWrite

Type:

bool

property event¶

Sets and gets the search event number.

Access:

ReadWrite

Type:

int

Remarks:
  • When On, the horizontal position is changed so that the specified event is located at the time reference.

    property mode¶

    Sets and gets the oscilloscope search mode.

    Access:

    ReadWrite

    Type:

    SearchMode

    Remarks:
    The Mode property can be set to one of the following values:
    • Edge:the Edge search mode
    • Glitch: the Glitch search mode
    • Runt: the Runt search mode
    • Transition: the Transition search mode
    • Serial1: the Serial1 search mode
    • Serial2: the Serial2 search mode
    • Peak: the Peak search mode
    • Off: the search mode is Off
