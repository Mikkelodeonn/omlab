SearchSerialM1553Mode¶

class SearchSerialM1553Mode¶

Specifies the MIL-STD 1553 search mode.

Members:

DATA_START : Finds the start of a data word (at the end of a valid Data Sync pulse).

COMMAND_START : Finds the start of a Command/Status word (at the end of a valid C/S Sync pulse).

RTA : Finds the Command/Status Word whose RTA matches the specified value. The value is specified in hex.

RTA11 : Finds the RTA and the remaining 11 bits that match the specified criteria. The RTA can be specified as a hex value and the remaining bits are specified as 1 or 0.

PARITY_ERROR : Finds (odd) parity bits that are incorrect for the data in the word.

SYNC_ERROR : Finds invalid sync pulses.

MANCHESTER_ERROR : Finds Manchester encoding errors.
