KtInfiniiVisionTriggerRunt¶

Access interface members using: driver.trigger.runt
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionTriggerRunt¶

KtInfiniiVisionTriggerRunt interface.

property condition¶

Sets and gets the condition used for specifying runt pulse widths.

Access:

ReadWrite

Type:

TriggerRuntCondition

Remarks:

• Greatherthan: triggers on runt pulses whose width is greater than the TriggerQualifierTime.
• Lessthan: triggers on runt pulses whose width is less than the TriggerQualifierTime.
• None: triggers on runt pulses of any width.
configure(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionTriggerRunt, source: str, threshold_low: float, threshold_high: float, polarity: keysight_ktinfiniivision.keysight_ktinfiniivision.TriggerRuntPolarity) → None¶

Configures the runt trigger Source, ThresholdLow, ThresholdHigh, and Polarity. A runt trigger occurs when the trigger signal crosses one of the runt thresholds twice without crossing the other runt threshold.

Parameters:

  • source (str) – Specifies the trigger source. This value sets the Trigger Source property.

  • threshold_low (float) – Sets the runt triggering low threshold in volts.

  • threshold_high (float) – Sets the runt triggering high threshold in volts.

  • polarity (TriggerRuntPolarity) – Sets the runt polarity.

Returns:

None

property polarity¶

Sets and gets the polarity of the runt that triggers the oscilloscope.

Access:

ReadWrite

Type:

TriggerRuntPolarity

Remarks:

• Positive: positive runt pulses.
• Negative: negative runt pulses.
• Either: either positive or negative runt pulses.
property qualifier_time¶

Sets and gets the time used for triggering on runt pulses whose width is greater than or less than the specified time value.

Access:

ReadWrite

Type:

float

Remarks:
With the input value suitable suffix from { s | ms | us | ns | ps } can be selected.
property source¶

Sets and gets the runt trigger source.

Access:

ReadWrite

Type:

str

Remarks:
The parameter <source> can be specified in following string format: Channel<n>, where n: 1 to the number of available analog channels.
property threshold_high¶

Sets and gets the high threshold the oscilloscope uses for runt triggering. The units are volts.

Access:

ReadWrite

Type:

float

property threshold_low¶

Sets and gets the low threshold the oscilloscope uses for runt triggering. The units are volts.

Access:

ReadWrite

Type:

float
