KtInfiniiVisionSerialBusFlexRay¶

Access interface members using: driver.serial_buses[<name_or_index>].flex_ray
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSerialBusFlexRay¶

KtInfiniiVisionSerialBusFlexRay interface.

auto_setup(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionSerialBusFlexRay) → None¶

Automatically configures oscilloscope settings to facilitate FlexRay triggering and serial decode.

Returns:

None

Remarks:
Sets the selected source channel's impedance to 50 Ohms, sets the selected source channel's probe attenuation to 10:1, sets the trigger level (on the selected source channel) to -300 mV, turns on trigger Noise Reject, turns on Serial Decode and sets the trigger type to FlexRay.

Sets and gets the ByteStart Sequence ID.

ReadWrite

Type:

str

Remarks:

• The TriggerEventBSSID property can be specified in one of the following formats:

• "All"

property trigger_event_type¶

Sets and gets the FlexRay event to trigger on. The event setting is only valid when the FlexRay TriggerType property is set to Event.

Access:

ReadWrite

Type:

SerialBusFlexRayTriggerEventType

Remarks:

• The TriggerEventType property can be set to one of the following values:

• WakeUp: triggers on Wake-Up event.
• TSS: triggers on Transmission Start Sequence event.
• BSS: triggers on Byte Start Sequence event.
• FES: triggers on Frame End Sequence event.
• DTS: triggers on Dynamic Trailing Sequence event.
property trigger_frame_cc_base¶

Sets and gets the base of the FlexRay cycle count (in the frame header) to trigger on. The cycle count base setting is only valid when the FlexRay TriggerType property is set to Frame.

Access:

ReadWrite

Type:

int

Remarks:
This property can be set to a value from 0 through the Cycle Count Repetition factor minus 1.
property trigger_frame_cc_repetition¶

Sets and gets the repetition number of the FlexRay cycle count (in the frame header) to trigger on. The cycle count repetition setting is only valid when the FlexRay TriggerType property is set to Frame.

Access:

ReadWrite

Type:

str

Remarks:

• The TriggerFrameCCRepetition property can be specified in one of the following formats:

• "All"
• "n", where n is an integer from 2 to 64
property trigger_frame_id¶

Sets and gets the FlexRay frame ID to trigger on. The frame ID setting is only valid when the FlexRay TriggerType property is set to Frame.

Access:

ReadWrite

Type:

str

Remarks:

• This property can be specified in one of the following formats:

• "All"
• "n", where n is an integer from 1-2047
property trigger_frame_type¶

Sets and gets the FlexRay frame type to trigger on. The frame type setting is only valid when the FlexRay TriggerType property is set to Frame.

Access:

ReadWrite

Type:

SerialBusFlexRayTriggerFrameType

Remarks:

• The TriggerFrameType property can be set to one of the following values:

• Normal: will trigger on only normal (NStartup and NNull and NSync) frames.
• Startup: will trigger on only startup frames.
• Null: will trigger on only null frames.
• Sync: will trigger on only sync frames.
• Startup: will trigger on frames other than startup frames.
• Null: will trigger on frames other than null frames.
• Sync: will trigger on frames other than sync frames.
• All: will trigger on all FlexRay frame types.
property trigger_type¶

Sets and gets the FlexRay trigger on condition.

Access:

ReadWrite

Type:

SerialBusFlexRayTriggerType

Remarks:

• This property can be set to one of the following values:

• Frame: triggers on specified frames (without errors).
• Error: triggers on selected active error frames and unknown bus conditions.
• Event: triggers on specified FlexRay event/symbol.
