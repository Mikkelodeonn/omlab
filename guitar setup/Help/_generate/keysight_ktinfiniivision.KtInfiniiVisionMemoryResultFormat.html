class KtInfiniiVisionMemoryResultFormat¶

KtInfiniiVisionMemoryResultFormat interface.

property color_grade_enabled¶

Enables or disables whether color grade bin counts will be included when analysis results are saved.

Access:

ReadWrite

Type:

bool

Remarks:
  • Analysis results are saved using MemorySave method having Save Option as AnalysisResults Type.
  • When multiple types of analysis results are saved, they are all saved to the same file and separated by a blank line.
  • Preset value is false.
