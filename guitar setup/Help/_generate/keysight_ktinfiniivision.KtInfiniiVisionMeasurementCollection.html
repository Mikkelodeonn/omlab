class KtInfiniiVisionMeasurementCollection¶

      Returns the ratio of ACRMS values of the specified sources expressed as dB.

      Parameters:

      • interval_type (MeasurementIntervalType) - Specifies the type of measurement interval.

      • source1 (str) - Specifies the value of source1 for the ratio measurement.

      • source2 (str) - Specifies the value of source2 for the ratio measurement.

      Returns:

      Ratio value in dB.

      Return type:

      float

      remarks:
      • Ratio measurements show the ratio of the ACRMS value of source1 to that of source2, expressed in dB.
      • The parameter <source> can be specified in one of the following string formats:
      • Channel<n>, where n: 1 to the number of available analog channels.
      • Function<m>, where m: 1 to the number of available math functions.
      • Math<m>, where m: 1 to the number of available math functions.
      • Wmemory<r>, where r: 1 to the number of available reference waveforms.

      • The method is not available, if the "FFT" is chosen as <source>.
      • The <interval> option lets you specify the measurement interval: either an integral number of cycles, or the full screen.
      • If <interval> is not specified, then "Display" is chosen as interval type.

    get_slew_rate(*args, **kwargs)¶

    Overloaded function.

    1. get_slew_rate(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionMeasurementCollection, source: str, slope: keysight_ktinfiniivision.keysight_ktinfiniivision.MeasurementEdgeSlope) -> float

      Returns the measured slew rate of the specified edge closest to the timebase reference.

      Parameters:

      • source (str) - Specifies the source for the slew rate meausurement.

      • slope (MeasurementEdgeSlope) - Specifies the type of edge be measured for slew rate measurement.

      Returns:

      Slew rate in vertical units/second.

      Return type:

      float

      remarks:
      • The slew rate of an edge is the change in vertical value between the lower and upper thresholds of a waveform source (typically volts) divided by the change in time between where the waveform threshold crossings take place.
      • The lower and upper thresholds for the measurement are specified by the measurement threshold settings for the source waveform.
      • If the <source> parameter is not specified, then current MeasurementsSetSource setting is used.
      • The method is not available when "FFT" is selected as a source.
      • The on-screen edge closest to the timebase reference is measured.
      • You can specify that a Rising edge be measured, a Falling edge be measured, or either a rising or a falling edge be measured (Either). If the <slope>is not specified, a rising edge is measured.

    get_y(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionMeasurementCollection, horizontal_location: datetime.timedelta, source: str) → float¶

    Returns the vertical value at a specified horizontal value on the source specified.

    Parameters:

    • horizontal_location (datetime.timedelta) – Specifies the horizantal location i.e. the time from trigger in seconds for the vertical value measurement.

    • source (str) – Specifies the source for the vertical value measurement at the specified horizontal location.

    Returns:

    Vertical value at the specified horizontal location.

    Return type:

    float

    Remarks:
    • The parameter <horizontalLocation> is the time from trigger in seconds.
    • The parameter <source> can be specified in one of the following string formats:
    • Channel<n>, where n: 1 to the number of available analog channels.
    • Digital<d>, where d: 1 to the number of available digital channels - 1.
    • Function<m>, where m: 1 to the number of available math functions.
    • Math<m>, where m: 1 to the number of available math functions.
    • Wmemory<r>, where r: 1 to the number of available reference waveforms.

    • When the <source> is "FFT" waveform, the <horizontalLocation> is a frequency value instead of a time value.
    • The specified horizontal value must be on the screen; when it is a time value, it is referenced to the trigger event.
    • If the optional source parameter is specified, then measurement source is modified.

      Installs a slew rate measurement on the oscilloscope’s front-panel screen.

      Parameters:

      • source (str) - Specifies the source for the slew rate meausurement.

      • slope (MeasurementEdgeSlope) - Specifies the type of edge be measured for slew rate measurement.

      Returns:

      None

      remarks:
      • The slew rate of an edge is the change in vertical value between the lower and upper thresholds of a waveform source (typically volts) divided by the change in time between where the waveform threshold crossings take place.
      • The lower and upper thresholds for the measurement are specified by the measurement threshold settings for the source waveform.
      • If the <source> parameter is not specified, then current MeasurementsSetSource setting is used.
      • The method is not available when "FFT" is selected as a source.
      • The on-screen edge closest to the timebase reference is measured.
      • You can specify that a Rising edge be measured, a FALLing edge be measured, or either a rising or a falling edge be measured (Either). If the <slope>is not specified, a rising edge is measured.

      • Channel<n>, where n: 1 to the number of available analog channels.

      • Wmemory<r>, where r: 1 to the number of available reference waveforms.

      • Source2 applies only to Delay & Phase measurements.
      • MATH<m> is an alias for FUNCtion<m>.
      • FUNCtion or MATH (without the "<m>" math function number) is an alias for FUNCtion2 or MATH2.
      • FUNC2 will be returned if the source is FUNCtion or MATH.

    set_y(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionMeasurementCollection, horizontal_location: datetime.timedelta, source: str) → None¶

    Installs a screen measurement of the vertical value at a specified horizontal value on the source specified.

    Parameters:

    • horizontal_location (datetime.timedelta) – Specifies the horizantal location i.e. the time from trigger in seconds for the vertical value measurement.

    • source (str) – Specifies the source for the vertical value measurement at the specified horizontal location.

    Returns:

    None

    Remarks:
    • The parameter <horizontalLocation> is the time from trigger in seconds.
    • The parameter <source> can be specified in one of the following string formats:
    • Channel<n>, where n: 1 to the number of available analog channels.
    • Digital<d>, where d: 1 to the number of available digital channels - 1.
    • Function<m>, where m: 1 to the number of available math functions.
    • Math<m>, where m: 1 to the number of available math functions.
    • Wmemory<r>, where r: 1 to the number of available reference waveforms.

    • When the <source> is "FFT" waveform, the <horizontalLocation> is a frequency value instead of a time value.
    • The specified horizontal value must be on the screen; when it is a time value, it is referenced to the trigger event.
    • If the optional source parameter is specified, then measurement source is modified.
