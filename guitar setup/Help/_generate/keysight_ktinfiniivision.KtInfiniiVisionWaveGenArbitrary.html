KtInfiniiVisionWaveGenArbitraryAttribute

property byte_order¶

Sets and gets the byte order for binary transfers.

Access:

ReadWrite

Type:

WaveformGeneratorArbitraryByteOrder

Remarks:
The ByteOrder property can be set to one of the following values:
  • LSBFirst: specifies the LSB first byte order
  • MSBFirst: specifies the MSB first byte order

• On T3000, X4000, X6000, M9240X and P9240X series oscilloscopes it supports both waveform generators (i.e. WaveGen1, WaveGen2).
• On X3000 series oscilloscopes it supports one waveform generator only (i.e WaveGen1).
property interpolation¶

Enables or disables the Interpolation control.

Access:

ReadWrite

Type:

bool

Remarks:
• Interpolation specifies how lines are drawn between arbitrary waveform points:
• When On, lines are drawn between points in the arbitrary waveform. Voltage levels change linearly between one point and the next.
• When Off, all line segments in the arbitrary waveform are horizontal. The voltage level of one point remains until the next point.
• On T3000, X4000, X6000, M9240X and P9240X series oscilloscopes it supports both waveform generators (i.e. WaveGen1, WaveGen2).
• On X3000 series oscilloscopes it supports one waveform generator only (i.e WaveGen1).

store(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionWaveGenArbitrary, source: str) → None¶

Stores the source’s waveform (source can be any analog channel, or reference waveforms) into the Arbitrary waveform memory.

Parameters:

source (str) – The source for the waveform.

Returns:

None

Remarks:
• The <source> parameter can be specified in one of the following formats:
  • Channel<n>, where n: from 1 to the number of analog channels.
  • WMemeory<r>, where r: from 1 to the number of reference waveforms. And from 1 to 2 for X3000 series oscilloscopes.
  • Math<m>, where m: from 1 to the number of available math functions.
  • Function<m>, where m: from 1 to the number of available math functions. For X3000 only Function1 or Function is valid.
  • FFT, only valid for T3000 series oscilloscopes.

• On T3000, 4000X, X6000, M9240X and P9240X series oscilloscopes it supports both waveform generators (i.e. WaveGen1, WaveGen2).
• On X3000 series oscilloscopes it supports one waveform generator only (i.e WaveGen1).
