SerialBusCXPITriggerType¶

class SerialBusCXPITriggerType¶

The CXPI trigger type.

Members:

START_OF_FRAME : Triggers at the start bit of any frame.

DATA : Triggers on CXPI frames at the end of the last data byte defined in the trigger.

ID : Triggers on a user-defined Frame ID at the end of the PID byte.

P_TYPE : Triggers on any frame that starts with the special PTYPE byte.

ALL_ERRORS : Triggers on all CRC, Parity, IBS, Stop Bit, Data Length, and Sample errors.

PARITY_ERROR : Triggers when the parity bit in the PID or PTYPE field is not correct.

IBS_ERROR : Triggers when there are more than 9 bits between consecutive bytes in a frame.

END_OF_FRAME : Triggers at the end of any frame.

IFS_ERROR : Triggers when there are fewer than 10 idle bits before a new frame begins.

FRAMING_ERROR : Triggers when the stop bit of a byte is not logical 1.

DATALENGTH_ERROR : Triggers when there are more data bytes in a frame than is indicated by the DLC or Extended DLC field.

CRC_ERROR : Triggers when the calculated CRC does not match the transmitted CRC.

SAMPLE_ERROR : Triggers when 10 consecutive logical 0s are detected.

SLEEP_FRAME : Triggers when a normal frame is transmitted matching the definition of a sleep frame in the CXPI specification.

WAKE_UP_PULSE : Triggers when a wakeup pulse is detected.

L_DATA : Triggers on CXPI frames at the end of the last data byte defined in the trigger.
