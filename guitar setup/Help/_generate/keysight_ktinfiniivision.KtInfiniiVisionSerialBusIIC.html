KtInfiniiVisionSerialBusIIC¶

Access interface members using: driver.serial_buses[<name_or_index>].iic
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSerialBusIIC¶

KtInfiniiVisionSerialBusIIC interface.

property address_width¶

Sets and gets the current IIC address width setting. It specifies whether the Read/Write bit is included as the LSB in the display of the IIC address field of the decode bus.

Access:

ReadWrite

Type:

SerialBusIICAddressWidth

Remarks:
This property can be set to one of the following values:
  • Bit7: Bit 7
  • Bit8: Bit 8
property clock_source¶

Specifies the source for IIC serial clock (SCL).

Access:

ReadWrite

Type:

str

Remarks:

• The ClockSource property can be specified in one the following string formats:

• For DSO Models:

• "Channel<n>", where <n> can be from 1 to the number of analog channels.
• "External", for External

• For MSO Models:

• "Channel<n>", where <n> can be from 1 to the number of analog channels.
• "Digital<d>", where <d> can be from 0 to the number of digital channels minus 1. For X2000 series DigitalChannels are not supported as source.
property data_source¶

Specifies the source for IIC serial data (SDA).

Access:

ReadWrite

Type:

str

Remarks:

• The Data Source property can be specified in one the following string formats:

• For DSO Models:

• "Channel<n>", where <n> can be from 1 to the number of analog channels.
• "External", for External

• For MSO Models:

• "Channel<n>", where <n> can be from 1 to the number of analog channels.
• "Digital<d>", where <d> can be from 0 to the number of digital channels minus 1. For X2000 series DigitalChannels are not supported as source.
property trigger_condition¶

Sets and gets the current IIC data qualifier when the TriggerType property is set to ReadEprom.

Access:

ReadWrite

Type:

SerialBusIICTriggerCondition

Remarks:
This property can be set to one of the following values:
  • Equal: Equal
  • NotEqual: Not Equal
  • GreaterThan: Greater Than
  • LessThan: Less Than
property trigger_pattern_address¶

Sets and gets the address for IIC data. The address can range from 0x00 to 0x7F (7-bit) or 0x3FF (10-bit) hexadecimal. Use the don’t care address (-1 or 0xFFFFFFFF) to ignore the address value.

Access:

ReadWrite

Type:

str

Remarks:
The address can be specified in one of the following string formats:
  • "n", where n is an integer.
  • "0xnn", where n: {0,..,9 | A,..,F}
property trigger_pattern_data¶

Sets and gets the IIC data. The data value can range from 0x00 to 0x0FF (hexadecimal). Use the don’t care data pattern (-1 or 0xFFFFFFFF) to ignore the data value.

Access:

ReadWrite

Type:

str

Remarks:
The data can be specified in one of the following string formats:
  • "n", where n is an integer.
  • "0xnn", where n: {0,..,9 | A,..,F}
property trigger_pattern_data2¶

Stes and gets the IIC data 2. The data value can range from 0x00 to 0x0FF (hexadecimal). Use the don’t care data pattern (-1 or 0xFFFFFFFF) to ignore the data value.

Access:

ReadWrite

Type:

str

Remarks:
The second data pattern can be specified in one of the following string formats:
  • "n", where n is an integer.
  • "0xnn", where n: {0,..,9 | A,..,F}
property trigger_type¶

Sets and gets the IIC trigger type.

Access:

ReadWrite

Type:

SerialBusIICTriggerType

Remarks:
This property can be set to one of the following values:
  • Start: Start condition
  • Stop: Stop condition
  • Read7: 7-bit address frame containing (Start:Address7:Read:Ack:Data)
  • R7Data2: 7-bit address frame containing (Start:Address7:Read:Ack:Data:Ack:Data2)
  • ReadEprom: EEPROM data read
  • Write7: 7-bit address frame containing (Start:Address7:Write:Ack:Data)
  • W7Data2: 7-bit address frame containing (Start:Address7:Write:Ack:Data:Ack:Data2)
  • Write10: 10-bit address frame containing (Start:Address byte1:Write:Ack:Address byte 2:Data)
  • NoAcknowledge: Missing acknowledge
  • AddressNoAck: Address with no acknowledge
  • Restart: Another start condition occurs before a stop condition
  • Address: Triggers on the selected address. The R/W bit is ignored
  • DataNoAck: Write data with no acknowledge
  • REPRom: EEPROM data read
  • HD3 series oscilloscopes models HD302MSO and HD304MSO does not support ReadEprom option
