KtInfiniiVisionSearchGlitch¶

Access interface members using: driver.search.glitch
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSearchGlitch¶

KtInfiniiVisionSearchGlitch interface.

property condition¶

Sets and gets the mode of operation of the glitch (pulse width) search. The oscilloscope can search for a pulse width that is greater than a time value, less than a time value, or within a range of time values.

Access:

ReadWrite

Type:

SearchGlitchCondition

Remarks:
The Condition property can be set to one of the following values:
  • GreaterThan: to search for a pulse width greater than a time value
  • LessThan: to search for a pulse width less than a time value
  • Range: to search for a pulse width within a range of time values
configure(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionSearchGlitch, source: str, polarity: keysight_ktinfiniivision.keysight_ktinfiniivision.SearchGlitchPolarity, condition: keysight_ktinfiniivision.keysight_ktinfiniivision.SearchGlitchCondition) → None¶

Configures the Source, Polarity and Condition properties for the Glitch search.

Parameters:

  • source (str) – The channel on which to search for glitches (pulse widths). The source is a string specified in the format: Channe<n>, where n can be set to a value from 1 to the total number of analog channels available.

  • polarity (SearchGlitchPolarity) – The polarity for the glitch (pulse width) source.

  • condition (SearchGlitchCondition) – The mode of operation of the glitch (pulse width) search. The oscilloscope can search for a pulse width that is greater than a time value, less than a time value, or within a range of time values.

Returns:

None

property polarity¶

Sets and gets the polarity for the glitch (pulse width) source.

Access:

ReadWrite

Type:

SearchGlitchPolarity

Remarks:
The Polarity property can be set to one of the following values:
  • Positive: to specify positive polarity for the glitch search

set_range(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionSearchGlitch, lower_limit: float, upper_limit: float) → None¶

Sets the pulse width duration time (in seconds) for the selected source.

Parameters:

  • lower_limit (float) – The lower limit for the pulse width duration time (in seconds) for the selected source (from 15 ns to 10 sec).

  • upper_limit (float) – The upper limit for the pulse width duration time (in seconds) for the selected source (from 10ns to 9.99 sec).

Returns:

None

Remarks:
The parameters can be entered in any order. The smaller value becomes LowerLimit and the larger value becomes UpperLimit.
property source¶

Sets and gets the channel on which to search for glitches (pulse widths).

Access:

ReadWrite

Type:

str

Remarks:

• The parameter <source> can be specified in following string format: Channel<n>, where n: 1 to the number of available analog channels.
• If all the channels are off, then "None" is returned.
