get_data(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionFRA, frequency_mode: keysight_ktinfiniivision.keysight_ktinfiniivision.FRAFrequencyMode) → Tuple[numpy.ndarray[numpy.float64], numpy.ndarray[numpy.float64], numpy.ndarray[numpy.float64], numpy.ndarray[numpy.float64]]¶

Returns the frequency response analysis data.

Parameters:

frequency_mode (FRAFrequencyMode) – Specifies the frequency mode setting of the Frequency Response Analysis (FRA).

Returns:

A tuple containing:

  • frequency (numpy.ndarray<dtype:double>) : Frequency

  • amplitude (numpy.ndarray<dtype:double>) : Amplitude

  • gain (numpy.ndarray<dtype:double>) : Gain

  • phase (numpy.ndarray<dtype:double>) : Phase

Type:

tuple[numpy.ndarray<dtype:double>, numpy.ndarray<dtype:double>, numpy.ndarray<dtype:double>, numpy.ndarray<dtype:double>]

Remarks:
• FRATrace can be used to specify whether to include gain,phase, both gain and phase, or neither in the frequency response analysis results.
• FRASweepMode can be used whether to get the data from a sweep or single-frequency analysis.
• If this option is not specified, the data from the sweep analysis is returned by default.

property output_load_impedance¶

The current expected output load impedance

Access:

ReadWrite

Type:

WaveformGeneratorOutputLoadImpedance

Remarks:
• The output impedance of the Gen Out BNC is fixed at 50 ohms. However, the output load selection lets the waveform generator display the correct amplitude and offset levels for the expected output load.
• If the actual load impedance is different than the selected value, the displayed amplitude and offset levels will be incorrect.

run(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionFRA) → None¶

Initiates the Frequency Response Analysis.

Returns:

None

Remarks:
  • This analysis controls the built-in waveform generator to sweep a sine wave across a range of frequencies while measuring the input to and output from a device under test (DUT). At each frequency, gain (A) and phase are measured and plotted on a Bode frequency response chart.
  • When the frequency response analysis completes, you can use the FetchData method to get list of data for each step in the sweep: Frequency (Hz), Amplitude (Vpp), Gain (dB), and Phase (°).
  • It takes some time for the frequency sweep analysis to complete.

    property single_frequency¶

    Sets and gets the single frequency value.

    Access:

    ReadWrite

    Type:

    float

    Remarks:
    • The frequency response analysis is displayed on a log scale Bode plot, so user can select from decade values in addition to the minimum frequency of 20 Hz.
    • The input <value>

    • For X1000 & X1200 Series: between 10 Hz and 20 MHz with a resolution of 0.1 Hz
    • For T3000, X4000, X6000, M9240X & P9240X Series: must be from { 20 | 100 | 1000 | 10000 | 100000 | 1000000 | 10000000 | 2000000 }

    • With the input, any of the <suffix> can be used from { Hz | kHz | MHz }
    property start_frequency¶

    The frequency sweep start value.

    Access:

    ReadWrite

    Type:

    float

    Remarks:
    • The frequency response analysis is displayed on a log scale Bode plot, so user can select from decade values in addition to the minimum frequency of 20 Hz.
    • The input <value>

    • For X1000 & X1200 Series: must be in between between 10 Hz and 19.99 MHz with a resolution of 0.1 Hz in NR3 format.
    • For T3000, X4000, X6000, M9240X & P9240X Series: must be from { 20 | 100 | 1000 | 10000 | 100000 | 1000000 | 10000000 }

    • With the input, any of the <suffix> can be used from { Hz | kHz | MHz }
    property stop_frequency¶

    The frequency sweep stop value.

    Access:

    ReadWrite

    Type:

    float

    Remarks:

    • The input <value>

    • For X1000 & X1200 Series: must be in between 10.1 Hz and 20 MHz with a resolution of 0.1 Hz in NR3 format.
    • For T3000, X4000, X6000, M9240X & P9240X Series: must be from { 100 | 1000 | 10000 | 100000 | 1000000 | 10000000 | 2000000 }

    • With the input, any of the <suffix> can be used from { Hz | kHz | MHz }
