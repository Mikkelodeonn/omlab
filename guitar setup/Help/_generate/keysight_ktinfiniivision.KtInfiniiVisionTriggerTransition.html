KtInfiniiVisionTriggerTransition¶

Access interface members using: driver.trigger.transition
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionTriggerTransition¶

KtInfiniiVisionTriggerTransition interface.

property condition¶

Sets and gets whether user are looking for rise/fall times greater than or less than a certain time value. The time value is set using the QualifierTime property.

Access:

ReadWrite

Type:

TriggerTransitionCondition

Remarks:
The Condition property can be set to one of the following values:
  • GreaterThan: specifies that user is looking for rise/fall times greater than a certain time value.
  • LessThan: specifies that user is looking for rise/fall times less than a certain time value.
configure(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionTriggerTransition, source: str, slope: keysight_ktinfiniivision.keysight_ktinfiniivision.TriggerTransitionSlope, condition: keysight_ktinfiniivision.keysight_ktinfiniivision.TriggerTransitionCondition, qualifier_time: float) → None¶

Configures the source, slope, condition and qualifier time parameters for the Transition trigger.

Parameters:

  • source (str) – Specifies the channel used to produce the trigger.

  • slope (TriggerTransitionSlope) – Specifies a Positive rising edge or a Negative falling edge.

  • condition (TriggerTransitionCondition) – Specifies whether you are looking for rise/fall times greater than or less than a certain time value. The time value is set using the QualifierTime property.

  • qualifier_time (float) – Specifies the time value for rise/fall time triggers. You also use the Condition property to specify whether you are triggering on times greater than or less than this time value.

Returns:

None

property qualifier_time¶

Sets and gets the time value for rise/fall time triggers. User can also use the Condition property to specify whether user is triggering on times greater than or less than this time value.

Access:

ReadWrite

Type:

float

Remarks:
With the input value suitable suffix from { s | ms | us | ns | ps } can be selected.
property slope¶

Sets and gets a Positive rising edge or a Negative falling edge.

Access:

ReadWrite

Type:

TriggerTransitionSlope

Remarks:
The Slope property can be set to one of the following values:
  • Negative: specifies a negative falling edge.
  • Positive: specifies a positive rising edge.
property source¶

Sets and gets the transition trigger source.

Access:

ReadWrite

Type:

str

Remarks:
The parameter <source> can be specified in following string format: Channel<n>, where n: 1 to the number of available analog channels.
property threshold_high¶

Sets and gets the high threshold the oscilloscope uses for the transition trigger. The units are volts.

Access:

ReadWrite

Type:

float

property threshold_low¶

Sets and gets the low threshold the oscilloscope uses for the transition trigger. The units are volts.

Access:

ReadWrite

Type:

float
