bool

get_method(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionClockRecovery) → Tuple[keysight_ktinfiniivision.keysight_ktinfiniivision.ClockRecoveryMethod, float, float, float, str, keysight_ktinfiniivision.keysight_ktinfiniivision.EdgeSlope, int]¶

Returns the currently selected clock recovery method.

Returns:

A tuple containing:

  • clockMethod (ClockRecoveryMethod) : Currently selected clock method.

  • dataRate (float) : The data signal’s expected bits/second rate. This value is not valid when clock method is KtInfiniiVisionClockMethodExplicit.

  • loopBandwidth (float) : The -3 dB bandwidth specification of PLL. This value is only valid when clock method is KtInfiniiVisionClockMethodFirstOrderPLL or KtInfiniiVisionClockMethodSecondOrderPLL.

  • dampingFactor (float) : The PLL’s observed jitter transfer function. This value is only valid when clock method is KtInfiniiVisionClockMethodSecondOrderPLL.

  • source (str) : Explicit clock source, CHANnel1 to number of analog channels. This value is only valid when clock method is KtInfiniiVisionClockMethodExplicit.

  • slope (EdgeSlope) : Slope. This value is only valid when clock method is KtInfiniiVisionClockMethodExplicit.

  • multiplier (int) : Explicit clock multiplier from 1 to 1000. This value is only valid when clock method is KtInfiniiVisionClockMethodExplicit.

Type:

tuple[ClockRecoveryMethod, float, float, float, str, EdgeSlope, int]
