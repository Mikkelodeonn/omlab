Installs a screen measurement and starts an RMS value measurement.

Parameters:

  • interval_type (MeasurementIntervalType) – Specify the type of measurement interval between Cycle and Display.

  • type (MeasurementType) – Specifies the type of measurement between AC RMS or DC RMS.

  • source1 (str) – Specifies the value of source1 for meausrement.

  • source2 (str) – Specifies the value of source2 for meausrement.

Returns:

None

Remarks:
• Parameter "source1" & "source2" can be specified as: "Channel<n>", where n: 1 to the number of available analog channels with N2820A probe connected.
• If parameter "intervalType" is not specified then Display is selected as interval type.
• If the optional source parameter(s) are specified, the currently specified source(s) are modified.
• This measurement is available with the N2820A high sensitivity current probewhen both the Primary and Secondary probe cables are used.
• This measurement joins the Zoom In waveform data below the probe's clamp level with Zoom Out waveform data above the probe's clamp level to create the waveform on which the measurement is made.
