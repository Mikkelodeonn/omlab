KtInfiniiVisionPowerOnOff¶

Access interface members using: driver.power.on_off
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionPowerOnOff¶

KtInfiniiVisionPowerOnOff interface.

property analysis_type¶

Sets and gets the analysis (turn on or turn off) to perform.

Access:

ReadWrite

Type:

bool

Remarks:
  • On: Will turn on and measures the time taken to get the output voltage of the power supply after the input voltage is applied.
  • Off: Will turn off and measures the time taken for the output voltage of the power supply to turn off after the input voltage is removed.
    • get_in_out_threshold(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionPowerOnOff, type: keysight_ktinfiniivision.keysight_ktinfiniivision.PowerOnOffType) → Tuple[int, int]¶

    Gets the input and output thresholds used in the Turn On/Turn Off analysis.

    Parameters:

    type (PowerOnOffType) – The turn on/off analysis type.

    Returns:

    A tuple containing:

    • inputThreshold (int) : Input threshold percentage.

    • outputThreshold (int) : Output threshold percentage.

    Type:

    tuple[int, int]

    Remarks:

    • Turn On analysis determines how fast a turned on power supply takes to reach some percent of its steady state output.
    • Turn Off analysis determines how fast a turned off power supply takes to reduce its output voltage to some percent of maximum.
    • Turn On time is between T1 and T2 and Turn Off between T2 and T1 wherr

    • T1 = when the input voltage first rises to some percent (typically the 10% threshold) of its maximum amplitude.
    • T2 = when the output DC voltage rises to some percent (typically the 90% threshold) of its maximum amplitude.
    next_step(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionPowerOnOff) → None¶

    Take the next step of the turn on/turn off analysis.

    Returns:

    None

    Remarks:
    It is equivalent to pressing the "Next" softkey on the oscilloscope front panel when prompted during the analysis.
