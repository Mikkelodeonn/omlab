KtInfiniiVisionTimebase¶

Access interface members using: driver.timebase
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionTimebase¶

KtInfiniiVisionTimebase interface.

property delay¶

Sets and gets the time interval (in seconds) between the trigger event and the display reference point on the screen.

Access:

ReadWrite

Type:

float

Remarks:
  • The display reference point is either left, right, or center.
  • The maximum position value depends on the time/division.
    • property horizontal_scale¶

    Horizontal scale or seconds per division for the main window.

    Access:

    ReadWrite

    Type:

    float

    property mode¶

    Sets and gets the current time base mode.

    Access:

    ReadWrite

    Type:

    TimebaseMode

    Remarks:
    The time base modes are:
    • Main: The normal time base mode is the main time base. It is the default time after Reset.
    • Window: In the Window (zoomed or delayed) time base mode, measurements are made in the zoomed time base if possible; otherwise, the measurements are made in the main time base
    • XY: No measurements are available in this mode. TimebaseTimeReference are not available.
    • Roll: In the Roll mode, data moves continuously across the display from left to right. The oscilloscope runs continuously and is untriggered. TimebaseTimeReference changes to Right.
    property range¶

    Sets and gets the full-scale horizontal time in seconds for the main window.

    Access:

    ReadWrite

    Type:

    float

    Remarks:
    The range is 10 times the current time-per-division.
    property reference_clock_enabled¶

    Enables or disables the 10 MHz REF BNC located on the rear panel of the oscilloscope.

    Access:

    ReadWrite

    Type:

    bool

    Remarks:
    The 10 MHz REF BNC can be used as an input for the oscilloscope's reference clock (instead of the internal 10 MHz reference), or it can be used to output the internal 10 MHz reference clock when synchronizing multiple instruments.
    property reference_location¶

    Sets and gets the time base reference custom location when TimeReference is custom.

    Access:

    ReadWrite

    Type:

    float

    Remarks:
    Value of location can be from 0.0 to 1.0
    property time_reference¶

    Time reference selection can be made to one division from the left side of the screen, to the center of the screen, or to one division from the right side of the screen or custom.

    Access:

    ReadWrite

    Type:

    TimebaseReference

    Remarks:
  • For referrnce to be Custom, this property places the time reference location at a percent of the graticule width (where 0.0 is the left edge and 1.0 is the right edge)
  • This affects the trigger point on the display.
    • property vernier_enabled¶

    Specifies whether the time base control’s ernier (fine horizontal adjustment) setting is ON or OFF.

    Access:

    ReadWrite

    Type:

    bool

    property window¶

    Reference to the KtInfiniiVisionTimebaseWindow interface.

    Access:

    Readonly

    Type:

    KtInfiniiVisionTimebaseWindow
