KtInfiniiVisionTriggerTVUDTV¶

Access interface members using: driver.trigger.tv.udtv
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionTriggerTVUDTV¶

KtInfiniiVisionTriggerTVUDTV interface.

property edge_number¶

Sets and gets the edge count setting by specifying the Generic video trigger’s Nth edge to trigger on after synchronizing with the vertical sync.

Access:

ReadWrite

Type:

int

property horizontal_sync_enabled¶

Enables or disables the horizontal sync control in the Generic video trigger.

Access:

ReadWrite

Type:

bool

Remarks:

• For interleaved video, enabling this property to true and setting the TriggerTVUDTVHorizontalSyncTime property to the sync time of the probed video signal allows the Edge Number function to count only lines and not double count during equalization.
• Additionally, the Field Holdoff can be adjusted so that the oscilloscope triggers once per frame.
• Similarly, for progressive video with a tri-level sync, enabling this property to true and setting the TriggerTVUDTVHorizontalSyncTime property to the sync time of the probed video signal allows the Edge Number property to count only lines and not double count during vertical sync.
property horizontal_sync_time¶

Sets and gets the minimum time setting the horizontal sync pulse must be present to be considered valid.

Access:

ReadWrite

Type:

float

Remarks:
When the TriggerTVUDTVHorizontalSyncEnabled property is set to true, this property sets the minimum time setting of the horizontal sync pulse.
property min_time¶

Sets and gets the “greater than the sync pulse width” time setting in the Generic video trigger. This setting allows oscilloscope synchronization to the vertical sync.

Access:

ReadWrite

Type:

float
