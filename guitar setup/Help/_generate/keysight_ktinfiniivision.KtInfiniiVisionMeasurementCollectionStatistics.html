KtInfiniiVisionMeasurementCollectionStatistics¶

Access interface members using: driver.measurements.statistics
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionMeasurementCollectionStatistics¶

KtInfiniiVisionMeasurementCollectionStatistics interface.

property count¶

Specifies the maximum number of values used when calculating measurement statistics.

Access:

ReadWrite

Type:

str

Remarks:
The Count property can be specified in one of the following string formats:
  • "Infinite"
  • "n", where n: an integer from 2 to 2000
property display_enabled¶

Enables or disables the display of the measurement statistics.

Access:

ReadWrite

Type:

bool

property format¶

Specifies the type of information returned by the GetResults() method.

Access:

ReadWrite

Type:

MeasurementStatisticsFormat

Remarks:
The Format property can be set to one of the following values:
  • All: All statistics are on
  • Current: Only the Current statistic is on
  • Minimum: Only the Minimum statistic is on
  • Maximum: Only the Maximum statistic is on
  • Mean: Only the Mean statistic is on
  • StandardDeviation: Only the Standard Deviation statistic is on
  • Count: Only the Count statistic is on
get_results(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionMeasurementCollectionStatistics) → str¶

Returns the results of the continuously displayed measurements.

Returns:

  • results (str) : The results for the continuously displayed measurements.

Type:

str

Remarks:
  • If more than one measurement is running continuously, the return values are duplicated for each continuous measurement from the first to last (left to right) result displayed. Each result returned is separated from the previous result by a comma. There is a maximum of four continuous measurements that can be continuously displayed at a time.
  • When no quick measurements are installed, this method returns nothing (empty string). When the count for any of the measurements is 0, the value of infinity (9.9E+37) is returned for the min, max, mean, and standard deviation.
  • Measurement label, current, min, max, mean, std dev, and count are only returned if the If MeasurementsStatisticsFormatproperty is set to ON.
  • The following shows the order of values received for a single measurement:
    • Measurement label current min max mean std dev count


    If MeasurementsStatisticsFormat property is set to Current, Min, Max, Mean, Standard Deviation or Count, only that particular statistic value is returned for each measurement that is on.
    increment(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionMeasurementCollectionStatistics) → None¶

    This command updates the statistics once (incrementing the count by one) using the current measurement values.

    Returns:

    None

    Remarks:
  • This command lets you, for example, gather statistics over multiple pulses captured in a single acquisition. To do this, change the horizontal position and enter the command for each new pulse that is measured.
  • This method is only valid when the oscilloscope is stopped and quick measurements are on.
  • The method is valid in segmented acquisition mode even though the corresponding front panel softkey is not available.

    install_power_measurement(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionMeasurementCollectionStatistics, measurement: keysight_ktinfiniivision.keysight_ktinfiniivision.MeasurementPowerFunction, source1: str, source2: str) → None¶

    Installs the specified power measurement.

    Parameters:

    • measurement (MeasurementPowerFunction) – The power measurements.

    • source1 (str) – Source - Channel{1|2|..|max analog channels}

    • source2 (str) – Source - Channel{1|2|..|max analog channels}

    Returns:

    None

    Remarks:
  • The Power measurements are:
      Angle: Installs a power phase angle measurement on screen.
      Apparent: Installs an apparent power measurement on screen.
      CPLoss: Installs a power loss per cycle measurement on screen.
      Crest: Installs a crest factor measurement on screen.
      Efficiency: Installs an efficiency measurement on screen.
      ELoss: Installs an energy loss measurement on screen.
      Factor: Installs a power factor measurement on screen.
      IPower: Installs an input power measurement on screen.
      OffTime: Installs an "off time" measurement on screen.
      OnTime: Installs an "on time" measurement on screen.
      OPower: Installs an output power measurement on screen.
      PCurrent: Installs a peak current measurement on screen.
      PLoss: Installs a power loss measurement on screen.
      RDson: Installs a power Rds-on measurement on screen.
      Reactive: Installs a reactive power measurement on screen.
      Real: Installs a real power measurement on screen.
      Ripple: Installs an output ripple measurement on screen.
      TResponse: Installs a transient response time measurement on screen.
      VceSat: Installs a power Vce saturation measurement on screen.
  • The Source1 parameter is the channel probing voltage and the Source2 parameter is the channel probing current.
