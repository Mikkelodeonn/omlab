KtInfiniiVisionPowerSwitch¶

Access interface members using: driver.power.switch
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionPowerSwitch¶

KtInfiniiVisionPowerSwitch interface.

property conduction_calculation_method¶

Sets and gets the conduction calculation method.

Access:

ReadWrite

Type:

PowerConductionMethod

Remarks:
  • Waveform: The Power waveform uses the original voltage waveform data, and the calculation is: P = V x I
  • RDS: Rds(on) - The Power waveform includes error correction:
      In the On Zone (where the voltage level is below V Ref): the Power calculation is: P = Id2 x Rds(on)
      In the Off Zone (where the current level is below I Ref): the Power calculation is: P = 0 Watt
  • VCE: Vce(sat) - The Power waveform includes error correction:
      In the On Zone (where the voltage level is below V Ref): the Power calculation is: P = Vce(sat) x Ic
      In the Off Zone (where the current level is below I Ref): the Power calculation is: P = 0 Watt
    • property current_percentage¶

    Sets and gets the current switching level for the start of switching edges.

    Access:

    ReadWrite

    Type:

    int

    Remarks:
  • The value is in percentage of the maximum switch current.
  • User can adjust this value to ignore noise floors or null offset that is difficult to eliminate in current probes.
  • This value specifies the threshold that is used to determine the switching edges.
    • property rds¶

    Sets and gets the Rds(on) value when the RDS conduction calculation method is chosen.

    Access:

    ReadWrite

    Type:

    float

    Remarks:
    Suffix from { OHM | mOHM } can be chosen depending upon the input value.
    property vce¶

    Sets and gets the Vce(sat) value when the VCE conduction calculation method is chosen.

    Access:

    ReadWrite

    Type:

    float

    Remarks:
    Suffix from { V | mV } can be chosen depending upon the input value.
    property voltage_percentage¶

    Sets and gets the voltage switching level for the switching edges.

    Access:

    ReadWrite

    Type:

    int

    Remarks:
  • The value is in percentage of the maximum switch voltage.
  • User can adjust this value to ignore noise floors.
  • This value specifies the threshold that is used to determine the switching edges.
