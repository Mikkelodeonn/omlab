WaveformPointMode¶

class WaveformPointMode¶

Type of data record to be transferred

Members:

NORMAL : Normal: The measurement record is transferred. It is a 62,500-point (maximum) representation of the raw acquisition record

MAXIMUM : Maximum: Whichever record contains the maximum amount of points is used.

RAW : Raw: Raw acquisition record is transferred. The maximum number of points available in this record is determined by number of points available to be transferred.
