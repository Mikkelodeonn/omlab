KtInfiniiVisionStatusMaskTestEvent¶

Access interface members using: driver.status.mask_test_event
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionStatusMaskTestEvent¶

KtInfiniiVisionStatusMaskTestEvent interface.

property enable_register¶

Enable register (16 bit). Enable bits select whether an Event bit causes the register summary condition bit to become true in the StatusByte register and potentially cause an SRQ (Service Request) interrupt to be generated.

Access:

ReadWrite

Type:

StatusMaskTestEventFlags

Remarks:

For details on the status register structure see the Status System Overview page.

read_event_register(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionStatusMaskTestEvent) → keysight_ktinfiniivision.keysight_ktinfiniivision.StatusMaskTestEventFlags¶

Read the Mask Test Event register (16 bit). Conditions which are part of the instrument’s normal operation. Event bits capture changes in Condition bits and remain set until cleared. Reading an event register clears it.

Returns:

The current value of the register.

Return type:

StatusMaskTestEventFlags

Remarks:

For details on the status register structure see the Status System Overview page.
