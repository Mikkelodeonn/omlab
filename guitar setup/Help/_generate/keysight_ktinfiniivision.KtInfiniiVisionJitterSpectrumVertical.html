KtInfiniiVisionJitterSpectrumVertical¶

Access interface members using: driver.jitter.spectrum.vertical
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionJitterSpectrumVertical¶

KtInfiniiVisionJitterSpectrumVertical interface.

property offset¶

Sets and gets the vertical value represented at center screen for the jitter measurement spectrum.

Access:

ReadWrite

Type:

float

Remarks:
Preset value is 0.
property range¶

Sets and gets the full-scale vertical range for the jitter measurement spectrum.

Access:

ReadWrite

Type:

float

Remarks:
Preset value is 8.00E+00.
property unit¶

Sets and gets the vertical units for the jitter spectrum.

Access:

ReadWrite

Type:

JitterSpectrumVerticalUnits

Remarks:
Preset value is Decibel.
