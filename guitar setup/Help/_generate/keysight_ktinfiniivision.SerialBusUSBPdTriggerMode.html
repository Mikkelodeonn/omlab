SerialBusUSBPdTriggerMode¶

class SerialBusUSBPdTriggerMode¶

The USB PD trigger mode.

Members:

PREAMBLE_START : Preamble Start, triggers at the start of a preamble, which starts with 0.

END_OF_PACKET : EOP, triggers at the end of packet.

START_OF_PACKET : SOP, triggers on ordered set Sync-1, Sync-1, Sync-1, Sync-2.

S_PRIME : SOP’, triggers on ordered set Sync-1, Sync-1, Sync-3, Sync-3.

SD_PRIME : SOP’’, triggers on ordered set Sync-1, Sync-3, Sync-1, Sync-3.

SP_DEBUG : SOP’ Debug, triggers on ordered set Sync-1, RST-2, RST-2, Sync-3.

SDP_DEBUG : SOP’’ Debug, triggers on ordered set Sync-1, RST-2, Sync-3, Sync-2.

HARD_RESET : Hard Reset, triggers on ordered set RST-1, RST-1, RST-1, RST-2.

CABLE_RESET : Cable Reset, triggers on ordered set RST-1, Sync-1, RST-1, Sync-3.

CRC_ERROR : CRC Error, triggers when an error is detected on a 32-bit CRC.

PREAMBLE_ERROR : Preamble Error, triggers when an error is detected on a 64-bit sequence of alternating 0 and 1.

HEADER : Header Content, triggers on a user-defined 16-bit value.
