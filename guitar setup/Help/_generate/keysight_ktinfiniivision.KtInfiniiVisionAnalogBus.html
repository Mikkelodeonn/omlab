property label¶

The label for analog bus. Setting a label for a bus will also result in the name being added to the label list.

Access:

ReadWrite

Type:

str

Remarks:
Label strings are 10 characters or less, and may contain any commonly used ASCII characters. Labels with more than 10 characters are truncated to 10 characters.
property mask_value¶

Sets and gets the mask value for the specified bus.

Access:

ReadWrite

Type:

str

Remarks:
Set a mask bit to a "1" to include that bit in the selected bus, and set a mask bit to a "0" to exclude it.
