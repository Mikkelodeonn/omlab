Reads screen image data.

Parameters:

  • image_format (DisplayImageFormat) – Type of Image Data Format.

  • palette (DisplayPaletteType) – Type of Image Data Palette.

Returns:

Screen image data is returned in the IEEE-488.2 # binary block data format.

Return type:

numpy.ndarray<with dtype:uint8>

Remarks:
  • The image returned is also affected by DisplayInvertColorEnabled.
  • By default DisplayInvertColorEnabled is ON and returns an inverted image.
  • To get an non inverted image, DisplayInvertColorEnabled have to be set OFF.
  • If no format or palette option is specified then BMP, Color format is used.

property graticule_type¶

Sets and gets the graticule (grid) type, when the TriggerType is TV and the vertical scaling of at least one displayed channel is 140 mV per division.

Access:

ReadWrite

Type:

DisplayGraticuleType

Remarks:
  • Full: the normal oscilloscope grid.
  • MVolt: shows vertical grids, labeled on the left, from -0.3 V to 0.8 V.
  • IRE: (Institute of Radio Engineers) shows vertical grids in IRE units, labeled on the left, from -40 to 100 IRE. The 0.35 V and 0.7 V levels from the MVolt grid are also shown and labeled at the right. When the IRE grid is selected, cursor values on the display are also shown in IRE units. However, cursor values via the remote interface are not in IRE units.
  • The MVolt and IRE grid values are accurate when the vertical scaling is 140 mV/division and the vertical offset is 245 mV.

    Adds labels to the label list in alphabetical order.

    Parameters:

    label (str) – Specifies the labels to be added in label list.

    Returns:

    None

    Remarks:
    • Labels that begin with the same alphabetic base string followed by decimal digits are considered duplicate labels.
    • Duplicate labels are not added to the label list. For example, if label "A0" is in the list and you try to add a new label called "A1234567890123456789012345678901", the new label is not added.

    property vector_enabled¶

    Enables or disables the lines drawn between acquired data points on the screen.

    Access:

    ReadWrite

    Type:

    bool

    Remarks:
  • 1000X, 2000X, 3000X, 3000T, M924x and P924x: The vector setting cannot be adjusted by user (this property will always return true).
  • 4000X: The vector setting can only be adjusted on models with bandwidth greater or equal to 1GHz.
  • 6000X: The vector setting can only be adjusted on models with bandwidth greater or equal to 6GHz.
    • When vectors are turned on, the oscilloscope displays lines connecting sampled data points. On the 1 GHz and 1.5 GHz bandwidth models, you can turn off vectors to view just waveform data points.
