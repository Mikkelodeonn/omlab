    save(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionReferenceWaveform, waveform_location: int, source: str) → None¶

    Copies the analog channel or math function waveform to the specified reference waveform location.

    Parameters:

    • waveform_location (int) – Reference waveform Location 1 or 2

    • source (str) – Waveform Source

    Returns:

    None

    Remarks:
    • Math functions whose x-axis is not frequency can be saved as reference waveforms.
    • The parameter < source > can be specified in one of the following string formats:
    • Channel<n>, where n: 1 to the number of available analog channels.
    • Function<m>, where m: 1 to the number of available math functions. For X1000, X1200, X2000, & X3000 family series oscilloscopes only "Math" or "Math1" is valid as source.
    • Math<m>, where m: 1 to the number of available math functions. For X1000, X1200, X2000, & X3000 family series oscilloscopes only "Function" or "Func1" is valid as source.
    set_label(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionReferenceWaveform, waveform_location: int, label: str) → None¶

    Sets the label for the specified reference waveform.

    Parameters:

    None

    Remarks:
  • Label strings are 10 characters or less, and may contain any commonly used ASCII characters.
  • Labels with more than 10 characters are truncated to 10 characters. Lower case characters are converted to upper case.
  • Setting a label for a reference waveform also adds the name to the label list in non-volatile memory (replacing the oldest label in the list).
