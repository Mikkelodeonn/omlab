KtInfiniiVisionTriggerAcLine¶

Access interface members using: driver.trigger.ac_line
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionTriggerAcLine¶

KtInfiniiVisionTriggerAcLine interface.

property slope¶

Sets and gets the slope of the zero crossing upon which the scope triggers.

Access:

ReadWrite

Type:

ACLineSlope

Remarks:

• The property is not valid in TV trigger mode.
• User can use TriggerTVPolarity to set the polarity in TV trigger mode
