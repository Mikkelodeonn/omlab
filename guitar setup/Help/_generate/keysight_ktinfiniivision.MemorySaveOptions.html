MemorySaveOptions¶

class MemorySaveOptions¶

Save Options

Members:

IMAGE : Saves an Image

WAVEFORM : Saves waveform data

REFERENCE_WAVEFORM : Saves oscilloscope waveform data to a reference waveform file.

SETUP : Saves an oscilloscope setup

MASK : Saves a mask

LISTER : ONLY SUPPORTED ON THE 3000X SERIES- Saves the Lister display data

ARB_CSV : Saves the currently-loaded Arbitrary waveform 1 to the file location specified (internal or external).

MULTI_WAVEFORM_DATA : Save multiple oscilloscope waveform to a h5 waveform file.

ANALYSIS_RESULTS : Saves analysis results to a comma-separated values (*.csv) file on a USB storage device.

POWER : Saves the power measurement application’s current harmonics analysis results to a file.

USB : Saves USB 2.0 signal quality test results to a file.
