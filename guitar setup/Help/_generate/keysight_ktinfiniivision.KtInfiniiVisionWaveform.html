property data_format¶

Sets and gets the data transmission mode for waveform data points. It controls how the data is formatted when sent from the oscilloscope.

Access:

ReadWrite

Type:

WaveformDataFormat

Remarks:

• ASCII: The formatted data converts the internal integer data values to real Y-axis values. Values are transferred as ASCii digits in floating point notation, separated by commas. ASCII formatted data is transferred ASCii text.
• Word: The formatted data transfers 16-bit data as two bytes.
• Byte: The formatted data transfers 16-bit data as two bytes.

property point_mode¶

Sets and gets the type of data record to be transferred.

Access:

ReadWrite

Type:

WaveformPointMode

Remarks:
• For the analog or digital sources, there are three different records that can be transferred:
• Raw Acquistion Record: The maximum number of points available in this record is returned by AcquisitionMemoryDepth property. The raw acquisition record can only be retrieved from the analog or digital sources.
• Measurement Reciord: It is a maximum point representation of the raw acquisition record. The measurement record can be retrieved, when SystemPrecision is off from any source.
• Precision Analysis Record: It is a user-selectable 100k-point to 1M-point (maximum) representation of the raw acquisition record. The precision analysis record can be retrieved when SystemPrecision is on from analog sources.

• If Normal is selected as <points_mode> and SystemPrecision is off,the measurement record is retrieved.
• If Normal is selected as <points_mode> and SystemPrecision is on,the precision analysis record is retrieved.
• If Raw is selected as <points_mode>, under some conditions this data record is unavailable.
• If Maximum is selected as <points_mode> and whichever record contains the maximum amount of points is used. Usually, this is the raw acquisition record. But, the measurement record may have more data. If data is being retrieved as the oscilloscope is stopped and as the data displayed is changing, the data being retrieved can switch between the measurement and raw acquisition records.
• If WaveformSource is not an analog or digital source, then only Normal and Maximum modes are allowed.
• Considerations for Maximum or Raw data retrieval:

• The instrument must be stopped in order to return more than the measurement record or precision analysis record.
• TimeBaseMode must be selected as Main.
• AcquisitonType must be set to either of Normal, Avergae or HRESolution.
• Maximum or Raw will allow up to 4,000,000 points to be returned. The number of points returned will vary as the instrument's configuration is changed. You can use the AcquisitonNumberOfPointsMin with <value> as Maximum to determine the maximum number of points that can be retrieved at the current settings.

property segment_data_enabled¶

Enables or disables the waveform data for all or curent segment(s).

Access:

ReadWrite

Type:

bool

Remarks:
• When On:

• Only available when WaveformSource is an analog input channel.
• WaveformDataPoints returns data for all segments.

• When Off: WaveformDataPoints returns data for the current segment.
• The ability to get waveform data for all segments is faster and more convenient than iterating over multiple segments and retrieving each one separately.
• The performance improvement comes primarily when raw acquisition record data is being retrieved instead of the measurement record data.
• Raw record data or normal Measurement record data can be set through WaveformPointMode.
• One corner case where you may want to retreive the measurement record data is when the acquired data for a segment is less than the screen resolution and the measurement record is interpolated.
• Most often though, the acquired data for a segment is enough to fill the screen,and less than the maximum measurement record size, so the segmented rawacquisition data and the measurement record data are the same.
• If the number of segments is small, the raw acquisition segment size is greaterthan the measurement record size.
property source¶

Sets and gets the source for the waveform.

Access:

ReadWrite

Type:

str

Remarks:
• This property selects the analog channel, function, digital pod, digital bus, reference waveform, or serial decode bus to be used as the source.
• The parameter <source> can be specified in one of the following string formats:
For X1000 and X1200 Series oscilloscopes.
• Channel<n>, where n: 1 to the number of available analog channels.
• Function
• Math
• FFT
• Wmemory<r>, where r: 1 or 2.
• Abus
• SBus1, only allowed in X1200 series oscilloscopes.
• External

For DSO Models (Other then X1000 and X1200 series oscilloscopes)
• Channel<n>, where n: 1 to the number of available analog channels.
• Function<m>, where m: 1 to the number of available math functions.
• Math<m>, where m: 1 to the number of available math functions.
• Wmemory<r>, where r: 1 to the number of available reference waveforms.
• Sbus { 1 | 2 }. Only SBus1 is allowed for X2000 series oscillocopes.
• FFT, only allowed in T3000, M9240X and P9240X seies oscilloscopes.

For MSO Models (Other then X1000 and X1200 series oscilloscopes)
• Channel<n>, where n: 1 to the number of available analog channels.
• Function<m>, where m: 1 to the number of available math functions.
• Math<m>, where m: 1 to the number of available math functions.
• Wmemory<r>, where r: 1 to the number of available reference waveforms.
• POD { 1 | 2 }
• Sbus { 1 | 2 }. Only SBus1 is allowed for X2000 series oscillocopes.
• Bus { 1 | 2 }
• FFT, only allowed in T3000, M9240X and P9240X seies oscilloscopes.

• External as a source is only available in 2 channel oscilloscopes only.
• Math<m> is an alias for Function<m> So function is alwways returned when either one is selected as a source.
• Function capabilities include add, subtract, multiply, integrate, differentiate, and FFT (Fast Fourier Transform) operations.
• When Sbus1 or Sbus2 is selected as source, ASCii is the only waveform format allowed. A string with timestamps and associated bus decode information is returned.
property sub_source¶

Selects the sub-source for those sources that have more than one possibility.

Access:

ReadWrite

Type:

WaveformSubSource

Remarks:
  • If the WaveformSource is serial decode, more than one data set may be available, and this property lets you choose from the available data sets.
  • When using UART serial decode, this option lets you get "TX" data. (TX is an alias for SUB1.) The default, SUB0, specifies "RX" data. (RX is an alias for SUB0.)
  • When using SPI serial decode, this option lets you get "MISO" data. (MISO is an alias for SUB1.) The default, SUB0, specifies "MOSI" data. (MOSI is an alias for SUB0.)
  • When using SENT serial decode, this option lets you get "SLOW" data. (SLOW is an alias for SUB1.) The default, SUB0, specifies "FAST" data. (FAST is an alias for SUB0.) Only allowed in X4000, P9240X, M9240X and X6000 series oscilloscopes.
  • If theSerialBusMode is not UART, SPI, or SENT, the only valid subsource is SUB0.
