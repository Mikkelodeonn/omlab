KtInfiniiVisionPowerSignalsMaxVoltage¶

Access interface members using: driver.power.signals.max_voltage
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionPowerSignalsMaxVoltage¶

KtInfiniiVisionPowerSignalsMaxVoltage interface.

property inrush¶

Sets and gets the maximum expected input voltage for inrush current analysis.

Access:

ReadWrite

Type:

float

Remarks:
  • This value is used to set the vertical scale of the channel probing voltage for inrush current analysis
  • When PowerInputType is DC, it defines the maximum DC input voltage amplitude value. The values can be negative.
  • When PowerInputType is AC, it defines the maximum peak-to-peak input voltage. Only positive values are allowed.
  • With the input value suitable <suffix> can be chosen from { V | mV }.
