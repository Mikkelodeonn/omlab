KtInfiniiVisionTriggerSetupAndHold¶

Access interface members using: driver.trigger.setup_and_hold
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionTriggerSetupAndHold¶

KtInfiniiVisionTriggerSetupAndHold interface.

property clock_source¶

Selects the channel used to produce the trigger.

Access:

ReadWrite

Type:

str

Remarks:

• The CLoclkSource property can be specified in one the following string formats:
• For DSO Models:

• "Channel<n>", where <n> can be from 1 to the number of analog channels.
• "VAL_EXTERNAL", for External

• For MSO Models:

• "Channel<n>", where <n> can be from 1 to the number of analog channels.
• "DigitalChannel<d>", where <d> can be from 0 to the number of digital channels minus 1.
configure(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionTriggerSetupAndHold, clock_source: str, slope: keysight_ktinfiniivision.keysight_ktinfiniivision.TriggerSetupAndHoldSlope, data_source: str, setup_time: float, hold_time: float) → None¶

Configures the clock source, slope, data source, setup time and hold time parameters for the Setup and Hold trigger.

Parameters:

  • clock_source (str) – Selects the channel used to produce the trigger.

  • slope (TriggerSetupAndHoldSlope) – Selects the clock signal’s active edge.

  • data_source (str) – Selects the channel used to produce the trigger.

  • setup_time (float) – Sets the setup time.

  • hold_time (float) – Sets the hold time.

Returns:

None
