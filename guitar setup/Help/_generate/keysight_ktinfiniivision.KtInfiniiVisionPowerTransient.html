KtInfiniiVisionPowerTransient¶

Access interface members using: driver.power.transient
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionPowerTransient¶

KtInfiniiVisionPowerTransient interface.

property initial_load_current¶

Sets and gets the initial load current value.

Access:

ReadWrite

Type:

float

Remarks:

• The initial load current will be used as a reference and to trigger the oscilloscope.
• Suffix from { A | mA } can be chosen depending upon the input value.
property new_load_current¶

Sets and gets the new load current value.

Access:

ReadWrite

Type:

float

Remarks:

• The new load current will be used as a reference and to trigger the oscilloscope.
• Suffix from { A | mA } can be chosen depending upon the input value.
next_step(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionPowerTransient) → None¶

Takes the next step of the transient analysis.

Returns:

None

Remarks:
It is equivalent to pressing the "Next" softkey on the oscilloscope front panel when prompted during the analysis.
stop(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionPowerTransient) → None¶

Exits (stops) the transient analysis.

Returns:

None

Remarks:
It is equivalent to pressing the "Exit" softkey on the oscilloscope front panel during the analysis.
