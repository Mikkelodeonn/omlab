KtInfiniiVisionWaveGen¶

Access interface members using: driver.wave_gens[<name_or_index>]
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionWaveGen¶

Root interface for the WaveGen repeated capability.

property additional_noise¶

Sets and gets the amount of noise to add to the currently selected signal.

Access:

ReadWrite

Type:

int

Remarks:
• The sum of the amplitude between the original signal and injected noise is limited to the regular amplitude limit (for example, 5 Vpp in 1 MOhm), so the range for input value varies according to current amplitude.
• Adding noise affects edge triggering on the waveform generator source as well as the waveform generator sync pulse output signal. This is because the trigger comparator is located after the noise source.
• On T3000, 4000X, X6000, M9240X and P9240X series oscilloscopes it supports both waveform generators (i.e. WaveGen1, WaveGen2).
• On X1000, X1200, X2000 and X3000 series oscilloscopes it supports one waveform generator only (i.e WaveGen1).
property amplitude¶

Sets and gets the amplitude in volts for currently specified waveform. Sine, Square, Ramp, Pulse, and Noise waveforms.

Access:

ReadWrite

Type:

float

Remarks:
• Not valid for DC type waveforms.
• You can use the WaveGenOffsetVoltage specify the offset voltage or DC level.
• Amplituse and offset can also be indirectly set using WaveGensLowVoltage properties. For example, an amplitude of 5 V and an offset of 1 V is the same as a high-level voltage of 4 V and a low-level voltage of -1 V.
• When the amplitude is below 40 mV, the offset is limited to ±500 mV.
• On T3000, 4000X, X6000, M9240X and P9240X series oscilloscopes it supports both waveform generators (i.e. WaveGen1, WaveGen2).
• On X1000, X1200, X2000 and X3000 series oscilloscopes it supports one waveform generator only (i.e WaveGen1).

property duty_cycle¶

Sets and gets the square wave duty cycle (20% to 80%) for Square waveforms.

Access:

ReadWrite

Type:

float

Remarks:
  • Duty cycle is the percentage of the period that the waveform is high.

    • • On T3000, X4000, X6000, M9240X and P9240X series oscilloscopes it supports both waveform generators (i.e. WaveGen1, WaveGen2).
    • On X1000, X1200, X2000 and X3000 series oscilloscopes it supports one waveform generator only (i.e WaveGen1).
    • For X1200 Series oscilloscopes, the duty cycle can be adjusted from 1% to 99% up to 500 kHz. At higher frequencies, the adjustment range narrows to not allow pulse widths less than 20 ns. For example:

    • At 1 MHz, the duty cycle can be adjusted from 2% to 98%.
    • At 5 MHz, the duty cycle can be adjusted from 10% to 90%.
    • At 5 MHz, the duty cycle can be adjusted from 10% to 90%.
