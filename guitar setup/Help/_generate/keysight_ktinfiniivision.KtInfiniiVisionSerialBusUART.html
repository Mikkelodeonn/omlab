KtInfiniiVisionSerialBusUART¶

Access interface members using: driver.serial_buses[<name_or_index>].uart
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSerialBusUART¶

KtInfiniiVisionSerialBusUART interface.

property base¶

Sets and gets the base to use for the UART decode and Lister display.

Access:

ReadWrite

Type:

SerialBusUARTBase

Remarks:
The Base property can be set to one of the following values:
  • ASCII
  • Binary
  • Hexadecimal
property baud_rate¶

Sets and gets the bit rate (in bps) for the serial decoder and/or trigger when in UART mode. The baud rate can be set from 1200 b/s to 8 Mb/s in 100 b/s increments.

Access:

ReadWrite

Type:

int

Remarks:

• If you enter a baud rate that is not divisible by 100 b/s, the baud rate is set to the nearest baud rate divisible by 100 b/s.
• Valid values are from 1200 to 8000000 in 100b/s increments.
• If the baud rate you select does not match the system baud rate, false triggers may occur.
property bit_order¶

Sets and gets the order of transmission used by the physical Tx and Rx input signals for the serial decoder and/or trigger when in UART mode.

Access:

ReadWrite

Type:

SerialBusUARTBitOrder

Remarks:

• The BitOrder property can be set to one of the following values:

• MSBFirst: MSB First
• LSBFirst: LSB First

• On selecting "LSBFirst", it sets the least significant bit of each message "byte" as transmitted first. Whereas on slecting "MSBFirst", it sets the most significant bit as transmitted first.
property error_count¶

Read Only - Gets the UART error frame count.

Access:

ReadOnly

Type:

int

property framing¶

Sets and gets the byte value to use for framing (end of packet) or to turn off framing for UART decode.

Access:

ReadWrite

Type:

str

Remarks:
The Framing property can be specified in one of the following formats:
  • "OFF"
  • "n", where n: 8-bit integer in decimal from 0 - 255
  • "0xnn", where n: {0,..,9 | A,..,F} from 0x00 - 0xff
  • "#Bnn..n", where n: {0 | 1}
property parity¶

Sets and gets the parity to be used with each message “byte” for the serial decoder and/or trigger when in UART mode.

Access:

ReadWrite

Type:

SerialBusUARTParity

Remarks:
The Parity property can be set to one of the following values:
  • Even: Even parity
  • Odd: Odd parity
  • None: No parity
property polarity¶

Sets and gets the polarity as idle low or idle high for the serial decoder and/or trigger when in UART mode.

Access:

ReadWrite

Type:

SerialBusUARTPolarity

Remarks:
The Polarity property can be set to one of the following values:
  • High: High polarity
  • Low: Low polarity
reset_counters(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionSerialBusUART) → None¶

This method resets the UART frame counters.

Returns:

None

property rx_frame_count¶

Read Only - Gets the UART Rx frame count.

Access:

ReadOnly

Type:

int

property rx_source¶

Sets and gets which signal is used as the Rx source by the serial decoder and/or trigger when in UART mode.

Access:

ReadWrite

Type:

str

Remarks:

• The RxSource can be specified in one the following string formats:

• For DSO Models:

• "Channel<n>", where <n> can be from 1 to the number of analog channels.

• For MSO Models:

• "Channel<n>", where <n> can be from 1 to the number of analog channels.
• "DigitalChannel<d>", where <d> can be from 0 to the number of digital channels minus 1. For X2000 series DigitalChannels are not supported as source.
property trigger_base¶

Sets and gets the front panel UART/RS232 trigger setup data selection.

Access:

ReadWrite

Type:

SerialBusUARTTriggerBase

Remarks:

• The TriggerBase property can be set to one of the following values:

• ASCII: front panel data selection is from ASCII values.
• Hexadecimal: front panel data selection is from hexadecimal values.

• The TriggerBase property does not affect the SerialBusUARTTriggerData property which can always set data values using ASCII or hexadecimal values.
• The TriggerBase property is independent of the Base property which affects decode and Lister only.
property trigger_burst¶

Sets and gets the burst value (Nth frame after idle period) in the range 1 to 4096 or OFF, for the trigger when in UART mode.

Access:

ReadWrite

Type:

str

Remarks:
The TriggerBurst property can be specified in one of the following formats:
  • "Off"
  • "n", where n is integer from 1 to 4096
property trigger_condition¶

Sets and gets the data qualifier when TriggerType is set to RData, RD1, RD0, RDX, TData, TD1, TD0, or TDX for the trigger when in UART mode.

Access:

ReadWrite

Type:

SerialBusUARTTriggerCondition

Remarks:
The TriggerCondition property can be set to one of the following values:
  • Equal
  • Not Equal
  • Greater Than
  • Less Than
property trigger_data¶

Sets and gets the data byte value (0x00 to 0xFF) for the trigger condition when in UART mode. The data value is used when one of the RD or TD trigger types is selected.

Access:

ReadWrite

Type:

str

Remarks:
The TriggerData property can be specified in one of the following string formats:
  • "n", where n: 8-bit integer from 0-255
  • "#Hnn", where n: {0,..,9 | A,..,F} from 0x00 to 0xff
  • "0xnn", where n: {0,..,9 | A,..,F} from 0x00 to 0xff
  • "#Bnn..n", where n: {0 | 1}
  • Any of the 128 valid 7-bit ASCII characters (or standard abbreviations)
property trigger_idle_time¶

Sets and gets the value of the idle period for burst trigger in the range from 1 us to 10 s when in UART mode.

Access:

ReadWrite

Type:

float

property trigger_type¶

Sets and gets the UART Trigger Type

Access:

ReadWrite

Type:

SerialBusUARTTriggerType

Remarks:

• The TriggerType property can be set to one of the following values: { RStart | RStop | RData | RD1 | RD0 | RDX | Parity Error | TStart | TStop | TData | TD1 | TD0 | TDX }
• When one of the RD or TD types is selected, the SerialBusUARTTriggerCondition properties are used to specify the data value and comparison operator.
• The RD1, RD0, RDX, TD1, TD0, and TDX types (for triggering on data and alert bit values) are only valid when a 9-bit width has been selected.
property tx_frame_count¶

Read Only - Gets the UART Tx frame count.

Access:

ReadOnly

Type:

int

property tx_source¶

Sets and gets which signal is used as the Tx source by the serial decoder and/or trigger when in UART mode.

Access:

ReadWrite

Type:

str

Remarks:

• The TxSource property can be specified in one the following string formats:

• For DSO Models:

• "Channel<n>", where <n> can be from 1 to the number of analog channels.
• "VAL_EXTERNAL", for External

• For MSO Models:

• "Channel<n>", where <n> can be from 1 to the number of analog channels.
• "DigitalChannel<d>", where <d> can be from 0 to the number of digital channels minus 1. For X2000 series DigitalChannels are not supported as source.
property width¶

Sets and gets the number of bits (5-9) for each message “byte” for the serial decoder and/or trigger when in UART mode.

Access:

ReadWrite

Type:

int

Remarks:
Valid values are from 5 to 9.
