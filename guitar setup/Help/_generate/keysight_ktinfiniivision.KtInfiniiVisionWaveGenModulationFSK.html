KtInfiniiVisionWaveGenModulationFSK¶

Access interface members using: driver.wave_gens[<name_or_index>].modulation.fsk
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionWaveGenModulationFSK¶

KtInfiniiVisionWaveGenModulationFSK interface.

property frequency¶

Sets and gets the “hop frequency”. Hop frequency in Hz

Access:

ReadWrite

Type:

float

Remarks:
• The output frequency "shifts" between the original carrier frequency and this "hop frequency".
• On T3000, X4000, X6000, M9240X and P9240X series oscilloscopes it supports both waveform generators (i.e. WaveGen1, WaveGen2).
• On X1000, X1200, X2000 and X3000 series oscilloscopes it supports one waveform generator only (i.e WaveGen1).
property rate¶

Sets and gets the rate at which the output frequency “shifts”. FSK modulation rate in Hz.

Access:

ReadWrite

Type:

float

Remarks:
• The FSK rate specifies a digital square wave modulating signal.
• On T3000, X4000, X6000, M9240X and P9240X series oscilloscopes it supports both waveform generators (i.e. WaveGen1, WaveGen2).
• On X1000, X1200, X2000 and X3000 series oscilloscopes it supports one waveform generator only (i.e WaveGen1).
