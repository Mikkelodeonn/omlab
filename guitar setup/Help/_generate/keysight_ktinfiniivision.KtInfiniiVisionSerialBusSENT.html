property crc_format¶

Sets and gets the format of the CRC.

Access:

ReadWrite

Type:

SerialBusSENTCRC

Remarks:
Enhanced Serial Message CRCs are always calculated using the recommended format, but for the Fast Channel Messages, and for Short Serial Message CRCs, this setting is used.
property format¶

Sets and gets the message decode/triggering format.

Access:

ReadWrite

Type:

SerialBusSENTFormat

Remarks:

• Format can be from the following types:

• Nibbles: displays the raw transmitted nibble values.
• FSignal: displays Fast Channel Message Signals.
• FSSerial: displays both Fast and Slow Messages (Short format) simultaneously.
• FESerial: displays both Fast and Slow Messages (Enhanced format) simultaneously.
• SSerial: displays Slow Channel Messages in Short format.

• Note that for the Slow Channel, the proper format, Short or Enhanced, must be chosen for proper decoding and triggering to occur.
• Slow Channel Serial Messages are always displayed as defined by the SENT specification.

property number_base¶

Sets and gets the number base used by the decoder.

Access:

ReadWrite

Type:

SerialBusSENTNumberBase

Remarks:

• The chosen base is used for the data nibbles in Raw decode format, the defined Signals in the other formats, and for the data field of the Serial Messages.
• The selection is used for both the Lister and the decode line displays.
• When Symbolic is selected, Fast Channel Signals display a calculated physical value based on the specified multiplier and offset: PhysicalValue = (Multiplier * SignalValueAsUnsignedInteger) * Offset

property pause_pulse¶

Specifies whether the SENT messages are followed by a pause pulse or not.

Access:

ReadWrite

Type:

bool

Remarks:

• When Off: There is no pause pulse between Fast Channel Messages. A "Sent" serial bus with no pause pulse is never idle. This means, during normal operation, the fast channel decode line will show a continuous stream of packets, with a new packet opening as soon as the previous one has closed.
• When On: Pause pulses are added between Fast Channel Messages so that frames come at a regular interval. If there is a pause pulse (and Pause Pulse is on), idle time is shown between messages.
