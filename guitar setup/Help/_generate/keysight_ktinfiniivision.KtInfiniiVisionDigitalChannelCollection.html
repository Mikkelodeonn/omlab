read_activity(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionDigitalChannelCollection) → Tuple[int, int]¶

Returns whether there has been activity (edges) on the digital channels since the last query, and returns the current logic levels

Returns:

A tuple containing:

  • edge (int) : Presence of edges

  • level (int) : Logical highs or lows

Type:

tuple[int, int]

Remarks:

• Levels: are current logic levels.
• Edges: are active edges since the last DigitalChannelsResetActivity call.
• In the values read, bit 0 is for digital channel 0, and bit 15 is for digital channel 15.
• A bit = 0 (zero) in the <edges> result indicates that no edges were detected on that channel (across the specified threshold voltage) since the last call.
• A bit = 1 (one) in the <edges> result indicates that edges have been detected on that channel (across the specified threshold voltage) since the last call.
• The threshold voltage must be set appropriately for the logic levels of the signals being probed.
• Because theis property have returned edge activity since the last call, you must select this property twice before the edge activity result is valid.
