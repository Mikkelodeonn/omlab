KtInfiniiVisionMathFunctionBus¶

Access interface members using: driver.math_functions[<name_or_index>].bus
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionMathFunctionBus¶

KtInfiniiVisionMathFunctionBus interface.

property clock_source¶

Specifies the clock signal source for the Chart Logic Bus State operation.

Access:

ReadWrite

Type:

str

Remarks:
The Source can be specified in the following string formats: "Digital<d>", where d: 0 to the number of available digital channels - 1.
property slope¶

Specifies the clock signal edge for the Chart Logic Bus State operation.

Access:

ReadWrite

Type:

MathBusSlope

Remarks:
The Slope property can be set to one of the following values:
  • Negative: specifies negative slope.
  • Positive: specifies the positive slope.
  • Either: specifies either negative or positive slope.
property y_increment¶

Specifies the value associated with each increment in Chart Logic Bus data.

Access:

ReadWrite

Type:

float

Remarks:
The units for this property are selected using the MathFunctionsBusYUnits property.
property y_origin¶

Specifies the value associated with Chart Logic Bus data equal to zero.

Access:

ReadWrite

Type:

float

Remarks:
The units for this property are selected using MathFunctionsBusYUnits property.
property y_units¶

Specifies the vertical units for the Chart Logic Bus operations.

Access:

ReadWrite

Type:

MathBusYUnits

Remarks:
The YUnits property can be set to one of the following values:
  • Volts: specifies the units as Volts
  • Amps: specifies the units as Amperes
  • None: specifies the units as None
