KtInfiniiVisionMaskTestConfiguration¶

Access interface members using: driver.mask_test.configuration
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionMaskTestConfiguration¶

KtInfiniiVisionMaskTestConfiguration interface.

property measurement_enabled¶

Enables/Disables measuring only mask failures setting. Gets the current measure only mask failures settings

Access:

ReadWrite

Type:

bool

Remarks:
• When On, measurements and measurement statistics run only on waveforms that contain a mask violation; passing waveforms do not affect measurements and measurement statistics.
• This mode is not available when the AcquisitionType is set to Average.
property number_of_waveform¶

Sets and gets the number of waveform acquisitions that are mask tested, when termination condition is waveforms.

Access:

ReadWrite

Type:

int

Remarks:
Range : 1 to 2,000,000,000
property sigma_level¶

Sigma Level when the termination condition is set to Sigma. Allowed Range is 0.1 to 9.3.

Access:

ReadWrite

Type:

float

property source¶

The source that is used to create an AutoMask and for mask testing. In case KtInfiniiVisionMaskTest.AllChannelEnabled is enabled all ON channels are tested.

Access:

ReadWrite

Type:

str

Remarks:
• The parameter < source > can be specified in the following string formats: Channel , where n: 1 to the number of available analog channels.
• Value returned are { Channel<n> | None }
property termination_condition¶

Sets and gets the termination conditions for the mask test.

Access:

ReadWrite

Type:

MaskTestTerminationCondition

Remarks:
The termination conditions are:
  • Forever: the mask test runs until it is turned off
  • Sigma: the mask test runs until the Sigma level is reached
  • Time: the mask test runs for a fixed amount of time
  • Waveforms: the mask test runs until a fixed number of waveforms are acquired
property termination_enabled¶

Enables/Disables stopping of mask test and acquisition on a mask failure. Gets the current stopping on mask failure setting.

Access:

ReadWrite

Type:

bool

property time¶

The number of seconds for a mask test to run. Permissible Range is 1 to 86400.

Access:

ReadWrite

Type:

float
