KtInfiniiVisionSerialBusUSBPd¶

Access interface members using: driver.serial_buses[<name_or_index>].usb_pd
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSerialBusUSBPd¶

KtInfiniiVisionSerialBusUSBPd interface.

property c_message_type¶

Sets and gets the control message type when SerialBusUSBPdTriggerMode is Header and SerialBusUSBPdHeaderType is Control message.

Access:

ReadWrite

Type:

SerialBusUSBPdControlMessage

Remarks:
The control message types:
  • GoodCRC
  • GotoMin
  • Accept
  • Reject
  • Ping
  • PSRdy: PS_RDY
  • GSRCap: Get_Source_Cap
  • GSNCap: Get_Sink_Cap
  • DRSwap: DR_Swap
  • PRSwap: PR_Swap
  • VCSwap: VCONN_Swap
  • Wait
  • SRST: Soft_Reset
  • GSCX: Get_Source_Cap_Extended
  • GStatus: Get_Status
  • FRSwap: FR_Swap
  • GPStatus: Get_PPS_Status
  • GCCodes: Get_Country_Codes
property condition¶

Sets and gets an additional qualifier for the Header Content trigger when SerialBusUSBPdTriggerMode is Header.

Access:

ReadWrite

Type:

SerialBusUSBPdHeaderQualifier

Remarks:
The header qualifier types are:
  • None: There is no additional qualifier for the trigger.
  • SOP: The trigger occurs on Sync-1, Sync-1, Sync-1, Sync-2 ordered sets only.
  • SPrime: SOP'. The trigger occurs on Sync-1, Sync-1, Sync-3, Sync-3 ordered sets only.
  • SDPrime: SOP''. The trigger occurs on Sync-1, Sync-3, Sync-1, Sync-3 ordered sets only.
property d_message_type¶

Sets and gets the data message type when SerialBusUSBPdTriggerMode is Header and SerialBusUSBPdHeaderType is Data message.

Access:

ReadWrite

Type:

SerialBusUSBPdDataMessage

Remarks:
The data message types are:
  • SRCap: Source_Capabilities
  • Request
  • BIST
  • SNCap: Sink_Capabilities
  • BStatus: Battery_Status
  • Alert
  • GCInfo: Get_Country_Info
  • VDefined: Vendor_Defined
property e_message_type¶

Sets and gets the extended message type when SerialBusUSBPdTriggerMode is Header and SerialBusUSBPdHeaderType is Extended message.

Access:

ReadWrite

Type:

SerialBusUSBPdExtendedMessage

Remarks:
The extended message types are:
  • SCX: Source_Capabilities_Extended
  • Status
  • GBCap: Get_Battery_Cap
  • GBStatus: Get_Battery_Status
  • BCAP: Battery_Capabilities
  • GMInfo: Get_Manufacturer_Info
  • MInfo: Manufacturer_Info
  • SRequest: Security_Request
  • SResponse: Security_Response
  • FRequest: Firmware_Update_Request
  • FResponse: Firmware_Update_Response
  • PStatus: PPS_Status
  • CInfo: Country_Info
  • CCodes: Country_Codes
property header_type¶

Sets and gets the header type when SerialBusUSBPdTriggerMode is Header.

Access:

ReadWrite

Type:

SerialBusUSBPdHeader

Remarks:
The header types are:
  • CMessage: Control Message, triggers on control message types (0 data object).
  • DMessage: Data Message, triggers on data message types (1 or more data objects).
  • EMessage: Extended Message, triggers on extended message types (bit 15 is set).
  • Value: Value, triggers on a user-defined header value.
property source¶

Sets and gets the USB PD waveform source.

Access:

ReadWrite

Type:

str

Remarks:
  • Source can be of the format: Channel<n>, where n: 1 to the number of available analog channels.
  • User can use the analog channels.
    • property trigger_mode¶

    Sets and gets the USB PD trigger mode.

    Access:

    ReadWrite

    Type:

    SerialBusUSBPdTriggerMode

    Remarks:
    The trigger modes are:
    • PStart: Preamble Start, triggers at the start of a preamble, which starts with 0.
    • EOP: EOP, triggers at the end of packet.
    • SOP: SOP, triggers on ordered set Sync-1, Sync-1, Sync-1, Sync-2.
    • SPrime: SOP', triggers on ordered set Sync-1, Sync-1, Sync-3, Sync-3.
    • SDPrime: SOP'', triggers on ordered set Sync-1, Sync-3, Sync-1, Sync-3.
    • SPDebug: SOP' Debug, triggers on ordered set Sync-1, RST-2, RST-2, Sync-3.
    • SDPDebug: SOP'' Debug, triggers on ordered set Sync-1, RST-2, Sync-3, Sync-2.
    • HRST: Hard Reset, triggers on ordered set RST-1, RST-1, RST-1, RST-2.
    • CRST: Cable Reset, triggers on ordered set RST-1, Sync-1, RST-1, Sync-3.
    • CRCerror: CRC Error, triggers when an error is detected on a 32-bit CRC.
    • PError: Preamble Error, triggers when an error is detected on a 64-bit sequence of alternating 0 and 1.
    • Header: Header Content, triggers on a user-defined 16-bit value.
    property user_defined_header_value¶

    Sets and gets the user-defined header value when SerialBusUSBPdTriggerMode is Header and SerialBusUSBPdHeaderType is user defined value type.

    Access:

    ReadWrite

    Type:

    str

    Remarks:
  • User defined header value format:
      "nn...n" where n ::= {0 | 1 | X}
      "0xnn...n" where n ::= {0,..,9 | A,..,F | X}
  • Returned data values are always quoted binary format strings.
