property mode¶

Sets and gets the PXI trigger mode to bus primary/secondary or off.

Access:

ReadWrite

Type:

TriggerPXIMode

Remarks:
The PXIe oscilloscope multi module triggering modes are:
  • Off: This module does not participate in multi-module triggering and is a standalone module
  • PrimaryModule: This module is the primary module
  • SecondaryModule: This module is a secondary module
property secondary_arm_line¶

Sets and gets the PXI secondary to primary arm line or off.

Access:

ReadWrite

Type:

TriggerPXI

Remarks:

• When this PXIe oscilloscope is a secondary, this property specifies which chassis PXI Trigger line (0-7) to use for its "armed" signal.
• Each secondary module must use a different PXI Trigger line for its arm signal.
• If the modules are in different chassis trigger bus segments (which are isolated by default), user must use the chassis Soft Front Panel (SFP) application to connect the selected PXI Trigger line between trigger bus segments.

property slot¶

Sets and gets the PXI primary slot number.

Access:

ReadWrite

Type:

int

Remarks:

• It is important to identify the primary slot number on each secondary so that the proper set of calibration factors can be used when aligning waveforms.
• Calibration factors are created and saved using the KtScopeCal.exe application on the chassis controller.
property sync_enabled¶

Enables or disables the sync mode (when setting up multiple M924xA oscilloscope module triggers).

Access:

ReadWrite

Type:

bool

Remarks:
  • Sync mode lessens the jitter between channels in different modules so that it is more like the jitter between channels within a single module. Sync mode uses the trigger system in the primary module for all modules.
  • When sync mode is Off, this is called asynchronous mode. Asynchronous mode uses the trigger systems in all modules where the trigger output from the primary odule is fed to the trigger input of the secondary modules.
  • When sync mode is On, user must use the KtScopeCal.exe application on the chassis controller to align the reference clock signals and perform sync mode trigger delay calibration.
    • property trigger_line¶

    Sets and gets the PXI specified chassis PXI Trigger line (0-7) to be used for the multi-module trigger signal.

    Access:

    ReadWrite

    Type:

    TriggerPXI

    Remarks:

    • The primary module and all secondary modules must use the same trigger line.
    • If the modules are in different chassis trigger bus segments (which are isolated by default), user must use the chassis Soft Front Panel (SFP) application to connect the selected PXI Trigger line between trigger bus segments.
