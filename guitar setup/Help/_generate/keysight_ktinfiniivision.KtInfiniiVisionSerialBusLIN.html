KtInfiniiVisionSerialBusLIN¶

Access interface members using: driver.serial_buses[<name_or_index>].lin
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSerialBusLIN¶

KtInfiniiVisionSerialBusLIN interface.

property baud_rate¶

Sets and gets the standard baud rate of the LIN signal from 2400 b/s to 625 kb/s in 100 b/s increments. If you enter a baud rate that is not divisible by 100 b/s, the baud rate is set to the nearest baud rate divisible by 100 b/s

Access:

ReadWrite

Type:

int

Remarks:
Valid values are from 2400 to 625000 in 100 b/s increments
property display¶

Sets and gets the LIN decode display type.

Access:

ReadWrite

Type:

SerialBusLINDisplay

property parity_enabled¶

Sets and gets the the current LIN parity bits display setting of the serial decode bus. It specifies whether the parity bits are included as the most significant bits (MSB) in the display of the Frame Id field in the LIN decode bus.

Access:

ReadWrite

Type:

bool

property sample_point¶

Sets and gets the point during the bit time where the bit level is sampled to determine whether the bit is dominant or recessive. The sample point represents the percentage of time between the beginning of the bit time to the end of the bit time.

Access:

ReadWrite

Type:

float

Remarks:

• Valid values are: 60, 62.5, 68, 70, 75, 80, 87.5
• The sample point values are not limited by the baud rate.
property source¶

Sets and gets the source for the LIN signal.

Access:

ReadWrite

Type:

str

Remarks:

• The source property can be specified in one the following string formats:

• For DSO Models:

• "Channel<n>", where <n> can be from 1 to the number of analog channels.
• "External", for External

• For MSO Models:

• "Channel<n>", where <n> can be from 1 to the number of analog channels.
• "Digital<d>", where <d> can be from 0 to the number of digital channels minus 1. For X2000 series DigitalChannels are not supported as source.
property standard¶

Sets and gets the LIN standard in effect for triggering and decoding to be LIN1.3, LIN2.0 or LIN1.3NLC.

Access:

ReadWrite

Type:

SerialBusLINStandard

Remarks:
The Standard property can be set to one of the following values:
  • LIN13: to specify the LIN1.3 standard for triggering and decoding
  • LIN20: to specify the LIN2.0 standard for triggering and decoding
  • LIN13NLC: to specify the LIN1.3 standard with no length control systems for triggering and decoding
property sync_break_length¶

Sets and gets the length of the LIN sync break to be greater than or equal to 11, 12, or 13 clock lengths. The sync break is the idle period in the bus activity at the beginning of each packet that distinguishes one information packet from the previous one.

Access:

ReadWrite

Type:

int

Remarks:
Valid values are: 11, 12, 13
property trigger_condition¶

Sets and gets the LIN trigger condition.

Access:

ReadWrite

Type:

SerialBusLINTriggerCondition

Remarks:

• The TriggerCondition property can be set to one of the following values:

• SyncBreak: Sync Break
• ID: Frame ID
• nData: Frame ID and Data
• ParityError: Parity errors
• ChecksumError: Checksum errors
• Frame: Triggers on a symbolic frame
• FrameSig: Triggers on a symbolic frame and a signal value

• Use the TriggerID property to specify the frame ID.
• Use the TriggerPatternData properties to specify the data string length and value.
property trigger_id¶

Sets and gets the LIN identifier searched for in each CAN message when the LIN trigger mode is set to frame ID.

Access:

ReadWrite

Type:

str

Remarks:

• The TriggerID property can be specified in one of the following string formats:

• "n", where n: 7-bit integer in decimal from 0-63
• "#Bnn..n", where n: {0 | 1}
• "0xnn", where n: {0,..,9 | A,..,F} from 0x00 to 0x3f

• Setting the ID to a value of "-1" results in "0xXX" which is equivalent to all IDs.
property trigger_pattern_base¶

Sets and gets the number base for LIN pattern data.

Access:

ReadWrite

Type:

SerialBusLINPatternBase

Remarks:
Default base is binary.
property trigger_pattern_data¶

Sets and gets the LIN trigger data pattern searched for in each LIN data field.

Access:

ReadWrite

Type:

str

Remarks:

• The TriggerPatternData property can be specified in one of the following string formats:

• "n", where n: 32-bit integer in unsigned decimal
• "#Bnn...n", where n: {0 | 1 | X | $};
• "0xnn...n", where n: {0,..,9 | A,..,F | X | $}

• Set a string bit to "0" or "1" to set the corresponding bit in the data pattern to low or high, respectively.
• Set a string bit to "X" to ignore (mask off) that bit in the data pattern.
• Use the "$" character to indicate that the value of the corresponding bit will not be changed (the existing bit value is used).
property trigger_pattern_data_length¶

Sets and gets the number of 8-bit bytes in the LIN data string. The number of bytes in the string can be anywhere from 1 bytes to 8 bytes (64 bits). The value for these bytes is set by the TriggerPatternData property.

Access:

ReadWrite

Type:

int

property trigger_symbolic_frame¶

Sets and gets the specific message when the LIN trigger mode is set to Frame.

Access:

ReadWrite

Type:

str

property trigger_symbolic_signal¶

Sets and gets the specific signal when the LIN trigger mode is set to Frame and Signal.

Access:

ReadWrite

Type:

str

property trigger_symbolic_value¶

Sets and gets the specific signal value when the LIN trigger mode is set to Frame and Signal.

Access:

ReadWrite

Type:

float

Remarks:
Encoded signal values are not supported in the remote interface (even though they can be used in the front panel graphical interface).
