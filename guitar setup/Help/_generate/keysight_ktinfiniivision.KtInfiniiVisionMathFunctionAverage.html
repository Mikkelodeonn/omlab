KtInfiniiVisionMathFunctionAverage¶

Access interface members using: driver.math_functions[<name_or_index>].average
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionMathFunctionAverage¶

KtInfiniiVisionMathFunctionAverage interface.

property count¶

Specify the number of waveforms to be averaged together.

Access:

ReadWrite

Type:

int

Remarks:
The number of averages can be set from 2 to 65536 in increments of powers of 2.
