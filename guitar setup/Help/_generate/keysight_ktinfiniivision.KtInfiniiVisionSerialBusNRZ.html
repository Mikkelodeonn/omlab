KtInfiniiVisionSerialBusNRZ¶

Access interface members using: driver.serial_buses[<name_or_index>].nrz
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSerialBusNRZ¶

KtInfiniiVisionSerialBusNRZ interface.

property base¶

Sets and gets the base for the NRZ bus decode and Lister display.

Access:

ReadWrite

Type:

SerialBusNRZBase

Remarks:
  • When SerialBusNRZDisplay is word, legal decode base values are Hexadecimal, Decimal and Ascii.
  • When SerialBusNRZDisplay is bit, legal decode base value is Binary.
    • property baud_rate¶

    Sets and gets the baud rate of the NRZ signal.

    Access:

    ReadWrite

    Type:

    int

    Remarks:
    Valid range is 5000 to 5000000 in 100 b/s increments.
    property bit_order¶

    Sets and gets the order of transmission on the NRZ bus.

    Access:

    ReadWrite

    Type:

    SerialBusNRZBitOrder

    Remarks:
  • MSBFirst: specifies the most significant bit is transmitted first.
  • LSBFirst: specifies the least significant bit is transmitted first.
    • property data_words_size¶

    Sets and gets the number of words in the data field of NRZ protocol definition when SerialBusNRZDisplay is word.

    Access:

    ReadWrite

    Type:

    int

    Remarks:
  • Range : 1 to 255.
  • Auto is available as a selection only when the trailer field size is 0.
    • property display¶

    Sets and gets the format of the NRZ bus display.

    Access:

    ReadWrite

    Type:

    SerialBusNRZDisplay

    property frame_size¶

    Sets and gets the total frame size of the NRZ signal from 2 to 255 bits.

    Access:

    ReadWrite

    Type:

    int

    Remarks:
    It is equivalent to the sum of the number of bits in the header, data, and trailer fields in WORD format.
    property header_size¶

    Sets and gets the number of bits in the header field of NRZ protocol definition when SerialBusNRZDisplay is word.

    Access:

    ReadWrite

    Type:

    int

    Remarks:
    Range : 0 to 32.
    property idle_state¶

    Sets and gets the idle state of the NRZ signal.

    Access:

    ReadWrite

    Type:

    SerialBusNRZIdleState

    Remarks:
    Idle state: low or high.
    property idle_time¶

    Sets and gets the minimum idle time or inter-frame gap time in terms of the number of bits.

    Access:

    ReadWrite

    Type:

    float

    Remarks:
    Range : 1.50 to 32.00 in 0.25 increments
    property polarity¶

    Sets and gets the polarity of the NRZ signal.

    Access:

    ReadWrite

    Type:

    SerialBusNRZPolarity

    Remarks:
  • High: specifies that a positive voltage is used to encode a bit value of logic 1 (and a negative voltage encodes a bit value of logic 0).
  • Low: specifies that a negative voltage is used to encode a bit value of logic 1.
    • property source¶

    Sets and gets the oscilloscope channel connected to the NRZ signal.

    Access:

    ReadWrite

    Type:

    str

    Remarks:
    Source can be of the format:
    • Channel<n>, where n: 1 to the number of available analog channels.
    • Digital<d>, where d: 1 to the number of digital channels - 1.
    property start_bits¶

    Sets and gets the number of start bits for the NRZ signal.

    Access:

    ReadWrite

    Type:

    int

    Remarks:
    Range : 0 to 255.
    property trailer_size¶

    Sets and gets the number of bits in the trailer field of NRZ protocol definition when SerialBusNRZDisplay is word.

    Access:

    ReadWrite

    Type:

    int

    Remarks:
    Range : 0 to 32.
    property trigger_mode¶

    Sets and gets the trigger mode.

    Access:

    ReadWrite

    Type:

    SerialBusNRZTriggerMode

    Remarks:
  • SOF (Start Of Frame): triggers at the start of a NRZ frame, before the header field.
  • Value: triggers on the specified bit values up to 128 bits, after the specified number of starting bits.

    • The trigger value is always for bits as they arrive (that is, MSB first).
    • When the SerialBusNRZBitOrder is MSBFirst, the decoded value bit order matches the trigger value bit order.
    • When the SerialBusNRZBitOrder is LSBFirst, the decoded value bit order is opposite of the trigger value bit order.
    • property trigger_value_data¶

    Sets and gets the trigger value as a string of binary digits, when SerialBusNRZTriggerMode is value.

    Access:

    ReadWrite

    Type:

    str

    Remarks:
  • The trigger value bit order is always for bits as they arrive (that is, MSB first) regardless of the SerialBusNRZBitOrder.
  • Data format is :
      "nn...n" where n ::= {0 | 1 | X | $}
      "0xnn...n" where n ::= {0,..,9 | A,..,F | X | $}
  • The bit width (length) of the value is set with the using SerialBusNRZTriggerValueLength property.
    • property trigger_value_length¶

    Sets and gets the bit width (length) of the value to trigger on when SerialBusNRZTriggerMode is value.

    Access:

    ReadWrite

    Type:

    int

    Remarks:

    • Range : 4 to 128.
    • The actual value to trigger on is set with the SerialBusNRZTriggerValueData property.
    property word_size¶

    Sets and gets the number of bits per word in the data field of NRZ protocol definition when SerialBusNRZDisplay is word.

    Access:

    ReadWrite

    Type:

    int

    Remarks:
    Range : 2 to 32.
