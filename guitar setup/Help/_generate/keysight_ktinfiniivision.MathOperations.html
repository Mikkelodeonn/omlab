MathOperations¶

class MathOperations¶

Values for Math operations

Members:

ADD : ADD = Source1 + source2.

SUBTRACT : SUBTract = Source1 - source2.

MULTIPLY : MULTiply = Source1 * source2.

FFT : Using the Fast Fourier Transform (FFT), this operation displays the magnitudes of the frequency content that makes up the source waveform.

INTEGRATE : Integration on the selected waveform source.

DIFFERENTIATION : Differentiation on the selected waveform source.

SQUARE_ROOT : Square Root of the selected waveform source.

MAGNIFY : Magnify.

ABSOLUTE : Absolute.

NATURAL_LOGARITHM : Natural Logarithm on the selected waveform source.

COMMON_LOGARITHM : Common Logarithm on the selected waveform source.

EXPONENTIAL : Exponential on the selected waveform source.

BASE_TEN_EXPONENTIAL : Base Ten Exponential on the selected waveform source.

LOW_PASS_FILTER : Low Pass Filter

HIGH_PASS_FILTER : High Pass Filter.

DIVIDE : Divide operation.

LINEAR : Linear operation on the selected waveform source.

MEASURMENT_TREND : Measurement Trend.

BUS_TIMING : Bus Timing

BUS_STATE : Bus State

SQUARE : Square operation on the selected waveform source.

AVERAGE : Average operation on the selected waveform source.

MAX_HOLD : Operates on a single analog channel source or on a lower math function. The Max Hold (or Max Envelope) operator records the maximum vertical values found at each horizontal bucket across multiple analysis cycles and uses those values to build a waveform.

MIN_HOLD : Operates on a single analog channel source or on a lower math function. The Min Hold (or Min Envelope) operator records the minimum vertical values found at each horizontal bucket across multiple analysis cycles and uses those values to build a waveform.

CLOCK_RECOVERY : You can display recovered clocks from different sources using multiple math function waveforms; however, the same clock recovery method applies to all recovered clocks.

SMOOTHING : The smoothing operator limits the bandwidth of the source waveform. The smoothing operator can be used, for example, to smooth measurement trend waveforms.

ENVELOPE : The resulting math waveform is the amplitude envelope for an amplitude modulated (AM) input signal.

FFT_PHASE : Using the Fast Fourier Transform (FFT), this operation shows the phase relationships of the frequency content that makes up the source waveform

MAXIMUM : The maximum vertical values found at each horizontal bucket are used to build a waveform.

MINIMUM : The minimum vertical values found at each horizontal bucket are used to build a waveform.

PEAK : At each horizontal bucket, the minimum vertical values found are subtracted from the maximum vertical values found to build a waveform.
