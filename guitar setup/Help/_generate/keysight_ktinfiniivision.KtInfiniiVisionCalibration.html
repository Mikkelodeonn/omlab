KtInfiniiVisionCalibration¶

Access interface members using: driver.calibration
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionCalibration¶

KtInfiniiVisionCalibration interface.

calibrate(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionCalibration) → None¶

Starts the user calibration procedure.

Returns:

None

Remarks:
Before starting the user calibration procedure, you must set the rear panel calibration switch to "Unprotected" and you must connect BNC cables from the Trigger Out connector to the analog channel inputs. See the User's Guide for details.
property date¶

Read Only - Gets the date of the last calibration.

Access:

ReadOnly

Type:

str

Remarks:
The return format is date is as "year, month & day".
property enabled¶

Read Only - Returns the rear-panel calibration protect (CAL PROTECT) button state.

Access:

ReadOnly

Type:

CalibrationProtection

Remarks:
The Protected value indicates calibration is disabled, and Unprotected value indicates calibration is enabled.
property label¶

Calibration string (up to 32 characters not including the quotes).

Access:

ReadWrite

Type:

str

Remarks:
This property saves a string into the instrument's non-volatile memory. The string may be used to record calibration dates or other information as needed.
result(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionCalibration) → Tuple[int, str]¶

Read Only- Summary results of the last user calibration procedure.

Returns:

A tuple containing:

  • statusCode (int) : An integer status code.

  • statusString (str) : ASCII status string.

Type:

tuple[int, str]

Remarks:
The status codes and strings can be:
Status Code Status String
+0 Calibrated
-1 Not Calibrated
property signal_source¶

Signal on the rear panel trigger out BNC.

Access:

ReadWrite

Type:

CalibrationSignalSource

Remarks:
Calibration Signal Source:
  • WaveGen2 is only available on models with 2 WaveGen outputs.
  • Off is only supported by 1000X, X1200, M9240X and P9240X.
  • TrigSource is only supported by 3000T, 4000X, M9240X and P9240X.
  • NFC is only supported by 3000T, 4000X, 6000X, M9240X and P9240X.
  • WaveGen and WaveGen1 are equivalent.
