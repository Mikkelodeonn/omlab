    property iec_standard¶

    Sets and gets the standard to perform current harmonics compliance testing on.

    Access:

    ReadWrite

    Type:

    PowerHarmonicsStandard

    Remarks:
  • A-IEC 61000-3-2 Class A: for balanced three-phase equipment, household appliances (except equipment identified as Class D), tools excluding portable tools, dimmers for incandescent lamps, and audio equipment.
  • B-IEC 61000-3-2 Class B: for portable tools.
  • C-IEC 61000-3-2 Class C: for lighting equipment.
  • D-IEC 61000-3-2 Class D: for equipment having a specified power according less than or equal to 600 W, of the following types: personal computers and personal computer monitors, television receivers.
    • property line_frequency¶

    Sets and gets the line frequency setting for the current harmonics analysis.

    Access:

    ReadWrite

    Type:

    PowerHarmonicsFrequency

    Remarks:
  • F50: 50 Hz.
  • F60: 60 Hz.
  • F400: 400 Hz.
  • Auto: Automatically determines the frequency of the Current waveform.
    • property real_power_source¶

    Sets and gets the real power source (used for the current-per-watt measurement) when class D is selected as current harmonics analysis standard.

    Access:

    ReadWrite

    Type:

    PowerHarmonicsSource

    Remarks:
  • Measured: Real Power value used for the current-per-watt measurement is measured by the oscilloscope.
  • User: Real Power value used for the current-per-watt measurement is defined by the user.
    • property user_defined_real_power¶

    Sets and gets the Real Power value used in the current-per-watt measurement when Class D is selected as current harmonics analysis standard and real power source defined by user.

    Access:

    ReadWrite

    Type:

    float

    Remarks:
    The value returned will lie in range from 1.0 to 600.0
