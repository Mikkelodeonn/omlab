SerialBusARINC429Speed¶

class SerialBusARINC429Speed¶

Specifies the speed of the ARINC 429 interface for the selected bus.

Members:

LOW : Specifies low speed (12.5kb/s).

HIGH : Specifies high speed (100kb/s).

USER : Let user specify a user-defined baud rate.
