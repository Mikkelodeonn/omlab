property levels¶

Returns a comma-delimited list of the hit ranges for each color bin.

Access:

ReadOnly

Type:

str

Remarks:
  • The first two values show the hit range for the color bin with fewest number of hits, the next two values show the hit range for the next color bin, and so on.
  • The color used for the greatest number of hits (white in both themes) represents pixels with the greatest number to about half that number. The next color represents half as many hits, and so on, until the last range (green in the Intensity theme or dark blue in the Temperature theme) represents the remaining range of the fewest number of hits.

    property source¶

    Sets and gets the waveform source on which to perform the color grade analysis.

    Access:

    ReadWrite

    Type:

    str

    Remarks:
    • The parameter <source> can be specified in one of the following string formats:
    • Channel<n>, where n: 1 to the number of available analog channels.
    • Function<m>, where m: 1 to the number of available math functions.
    • Math<m>, where m: 1 to the number of available math functions.
    • Wmemory<r>, where r: 1 to the number of available reference waveforms.
    property theme¶

    Sets and gets the color theme used by color graded waveform display.

    Access:

    ReadWrite

    Type:

    DisplayColorTheme

    Remarks:
    The color grade theme specifies seven colors that represent the ranges of counter values (hits) in the database.
