KtInfiniiVisionMeasurement¶

Access interface members using: driver.measurements[<name_or_index>]
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionMeasurement¶

Root interface for the Measurement repeated capability.

configure_jitter_measurement(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionMeasurement, meas_function: keysight_ktinfiniivision.keysight_ktinfiniivision.MeasurementJitter, slope: keysight_ktinfiniivision.keysight_ktinfiniivision.EdgeSlope, number_of_periods: int, unit: keysight_ktinfiniivision.keysight_ktinfiniivision.MeasurementUnit) → None¶

Configure and adds the selected Jitter measurement.

Parameters:

  • meas_function (MeasurementJitter) – The Jitter measurement.

  • slope (EdgeSlope) – Edge Slope. This parameter is not available when MeasFunction is KtInfiniiVisionMeasurementJitterTIEData, KtInfiniiVisionMeasurementJitterCTCPWidth, or KtInfiniiVisionMeasurementJitterCTCNWidth.The KtInfiniiVisionEdgeSlopeBoth value is not available for KtInfiniiVisionMeasurementJitterNPeriod.

  • number_of_periods (int) – Number of periods from 1 to 99. This parameter is not available when MeasFunction is KtInfiniiVisionMeasurementJitterTIEData, KtInfiniiVisionMeasurementJitterTIEClock, KtInfiniiVisionMeasurementJitterCTCPWidth, or KtInfiniiVisionMeasurementJitterCTCNWidth.

  • unit (MeasurementUnit) – Units. This parameter is available when MeasFunction is KtInfiniiVisionMeasurementJitterTIEData or KtInfiniiVisionMeasurementJitterTIEClock.

Returns:

None

Remarks:
  • Prior to using this method, enable the jitter analysis using the :class:`KtInfiniiVisionJitter`.Enabled property.
  • MeasurementJitterCTCNWidth: The -Width to -Width (cycle-to-cycle negative width) jitter measurement subtracts the first cycle's negative pulse width from the second cycle's negative pulse width for the first measurement result. Then, the second cycle's negative pulse width is subtracted from the third cycle's negative pulse width for the second measurement result, and so on, until all of the cycles of the waveform have been measured.
  • MeasurementJitterCTCPWidth: The +Width to +Width (cycle-to-cycle positive width) jitter measurement subtracts the first cycle's positive pulse width from the second cycle's positive pulse width for the first measurement result. Then, the second cycle's positive pulse width is subtracted from the third cycle's positive pulse width for the second measurement result, and so on, until all of the cycles of the waveform have been measured.
  • MeasurementJitterNCJitter: The N-Cycle Period-Period jitter measurement takes a group of cycles and measures the period from the first edge of the first cycle of the group to the final edge of the last cycle of the group. The N-period of the first group is measured and subtracted from the N-period of the second group. After shifting ahead one cycle the next measurement is made.
  • MeasurementJitterNPeriod: The N-Period jitter measurement measures the time span of N consecutive periods. Then, it shifts ahead one period and measures the time span of the next N consecutive periods, and so on.
  • MeasurementJitterTIEClock: The Clock TIE (Time Interval Error) jitter measurement compares edges in a clock signal with the edges in an ideal clock signal determined by the clock recovery feature.
  • MeasurementJitterTIEData: The Data TIE (Time Interval Error) jitter measurement compares edges in a data signal with the edges in an ideal data signal determined by the clock recovery feature.
