KtInfiniiVisionDisplayAnnotation¶

Access interface members using: driver.display.annotation
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionDisplayAnnotation¶

KtInfiniiVisionDisplayAnnotation interface.

property background¶

Specifies the background of the annotation.

Access:

ReadWrite

Type:

DisplayAnnotationBackground

Remarks:

• Opaque: the annotation has a solid background.
• Inverted: the annotation's foreground and background colors are switched
• Transparent: the annotation has a transparent background.
property color¶

Specifies the annotation color.

Access:

ReadWrite

Type:

DisplayAnnotationColor

Remarks:
You can choose white, red, or colors that match analog channels, digital channels, math waveforms, reference waveforms, or markers.
property enabled¶

Enables or disables the annotation.

Access:

ReadWrite

Type:

bool

Remarks:
  • When set to true, the annotation appears in the upper left corner of the oscilloscope's display.
  • The annotation is useful for documentation purposes, to add notes before capturing screens.

    Parameters:

    Returns:

    Text

    Return type:

    str

    Remarks:
  • The annotation string can contain up to 254 characters.
  • You can include a carriage return in the annotation string using the characters "\n". Note that this is not a new line character but the actual "\" (backslash) and "n" characters in the string. Carriage returns lessen the number of characters available for the annotation string.
  • When carriage returns are present in the annotation text, they are returned as the actual carriage return character.
