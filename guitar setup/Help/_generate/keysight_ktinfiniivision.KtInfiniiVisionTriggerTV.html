KtInfiniiVisionTriggerTV¶

Access interface members using: driver.trigger.tv
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionTriggerTV¶

KtInfiniiVisionTriggerTV interface.

configure(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionTriggerTV, source: str, signal_format: keysight_ktinfiniivision.keysight_ktinfiniivision.TriggerTVSignalFormat, trigger_event: keysight_ktinfiniivision.keysight_ktinfiniivision.TriggerTVEvent, polarity: keysight_ktinfiniivision.keysight_ktinfiniivision.TriggerTVPolarity) → None¶

Configures the TV Trigger parameters.

Parameters:

  • source (str) – The source the oscilloscope monitors for the trigger event.

  • signal_format (TriggerTVSignalFormat) – The format of TV signal on which the oscilloscope triggers.

  • trigger_event (TriggerTVEvent) – The event on which the oscilloscope triggers in TV Trigger mode.

  • polarity (TriggerTVPolarity) – The polarity of the TV signal.

Returns:

None

property event¶

Sets and gets the TV trigger mode and field.

Access:

ReadWrite

Type:

TriggerTVEvent

Remarks:
The LAlternate parameter is not available when TriggerTVEventSignalFormat is of Genric type.
property line_number¶

Sets and gets the TV Trigger Line number which allows triggering on a specific line of video. The line number limit varies with the signal format and event.

Access:

ReadWrite

Type:

int

property polarity¶

Sets and gets the polarity of the TV that triggers the oscilloscope.

Access:

ReadWrite

Type:

TriggerTVPolarity

property signal_format¶

Sets and gets the current TV Trigger standard setting. The format of TV signal on which the oscilloscope triggers only NTSC, PAL, PAL-M and SECAM are supported currently.

Access:

ReadWrite

Type:

TriggerTVSignalFormat

Remarks:
With an extended Video triggering license, the oscilloscope additionally supports these standards:

• Generic: Generic mode is non-interlaced.
• EDTV 480p/60
• EDTV 567p/50
• HDTV 720p/50
• HDTV 720p/60
• HDTV 1080p/24
• HDTV 1080p/25
• HDTV 1080p/30
• HDTV 1080i/50
• HDTV 1080i/60
property source¶

Sets and gets TV trigger source.

Access:

ReadWrite

Type:

str

Remarks:
The parameter <source> can be specified in following string format: Channel<n>, where n: 1 to the number of available analog channels.
