KtInfiniiVisionSearchEdge¶

Access interface members using: driver.search.edge
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSearchEdge¶

KtInfiniiVisionSearchEdge interface.

configure(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionSearchEdge, source: str, slope: keysight_ktinfiniivision.keysight_ktinfiniivision.SearchEdgeSlope) → None¶

Configures the Source and Slope properties for an Edge search.

Parameters:

  • source (str) – The channel on which to search for edges. The source is a string specified in the format: Channel<n>, where n can be set to a value from 1 to the total number of analog channels available.

  • slope (SearchEdgeSlope) – The slope of the edge for the search.

Returns:

None

property slope¶

Sets and gets slope of the edge for the search.

Access:

ReadWrite

Type:

SearchEdgeSlope

Remarks:
The Slope property can be set to one of the following values:
  • Negative: specifies the negative slope
  • Positive: specifies the positive slope
  • Either: specifies either the negative or positive slope
property source¶

Sets and gets the source channel on which to search for edges.

Access:

ReadWrite

Type:

str

Remarks:
The parameter <source> can be specified in following string format: Channel<n>, where n: 1 to the number of available analog channels.
