class KtInfiniiVisionMeasurementCollectionConfiguration¶

KtInfiniiVisionMeasurementCollectionConfiguration interface.

configure_delay(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionMeasurementCollectionConfiguration, source1_slope: keysight_ktinfiniivision.keysight_ktinfiniivision.MeasurementEdgeSlope, source1_edge_number: int, source1_threshold: keysight_ktinfiniivision.keysight_ktinfiniivision.MeasurementThresholdType, source2_slope: keysight_ktinfiniivision.keysight_ktinfiniivision.MeasurementEdgeSlope, source2_edge_number: int, source2_threshold: keysight_ktinfiniivision.keysight_ktinfiniivision.MeasurementThresholdType) → None¶

Defines the slope directions, and edge numbers for the delay measurement. Also defines edge position parameters.

Parameters:

  • source1_slope (MeasurementEdgeSlope) – Specifies the edge slope for source1.

  • source1_edge_number (int) – Specifies the edge number (between 0 to 100) for source1.

  • source1_threshold (MeasurementThresholdType) – Specifies the edge threshold type for source1.

  • source2_slope (MeasurementEdgeSlope) – Specifies the edge slope for source2.

  • source2_edge_number (int) – Specifies the edge number (between 0 to 100) for source2.

  • source2_threshold (MeasurementThresholdType) – Specifies the edge threshold type for source1.

Returns:

None

Remarks:
• Parameter: sourceEdgeNumber for source1 and source2 should be from 0 to 1000.
• source1EdgeNumber setting of zero (0) specifies that the edge closest to the timebase reference point automatically be selected. In this case, source2EdgeNumber setting must also be zero (0), and the source2 edge closest to the selected source1 edge is used.
• When edge numbers greater than zero (0) are specified, edges are counted from the left side of the display for both sources.
• Sources can be selected using MeasurementsConfigurationSource2.

property window¶

Sets nd gets the current measurement window setting portion of the display,.

Access:

ReadWrite

Type:

MeasurementWindowType

Remarks:

• Main: the measurement window is the Main window.
• Zoom: the measurement window is the lower, Zoom window.
• Auto: when the zoomed time base is displayed, the measurement is attempted in the lower, Zoom window; if it cannot be made there, or if the zoomed time base is not displayed, the Main window is used.
• Gate: the measurement window is between the X1 and X2 cursors. When the zoomed time base is displayed, the X1 and X2 cursors in the Zoom window portion of the display are used.
