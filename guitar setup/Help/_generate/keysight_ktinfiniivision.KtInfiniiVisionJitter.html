configure_histogram(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionJitter) → None¶

Auto-configures and turns on the jitter measurement histogram for the selected measurement.

Returns:

None

Remarks:
  • Prior to using this method, enable the jitter analysis using the JitterEnabledproperty.
  • Configure and add the measurement using the ConfigureJitterMeasurement method.
    • property enabled¶

    Enables or disables the jitter analysis feature.

    Access:

    ReadWrite

    Type:

    bool

    Remarks:
    When jitter analysis is enabled, these oscilloscope settings are forced on:
    • Precision measurements with a 1M precision analysis record length, which gives better accuracy.
    • All edges in each acquisition are measured (instead of a single edge per acquisition, as is normally the case). For each acquisition, the measurement count increases by the number of edges in the acquisition. This applies to all measurements that look at edges, not just jitter analysis measurements.

    When jitter analysis is disabled:
    • The "precision measurements" and 1M precision analysis record length settings are returned to the settings present when jitter analysis was enabled.
    • The oscilloscope returns to measuring a specific edge in each acquisition (generally around the horizontal time reference) and ignoring all other edges in the acquisition, as is normally the case. For each acquisition, the measurement count increases by one.

    The preset value is false.
    property measurement¶

    Sets the measurement to analyze and returns the location of the measurement currently selected for histogram analysis.

    Access:

    ReadWrite

    Type:

    MeasurementSlot

    Remarks:
    The measurement slot you specify must have one of these measurements installed:
    • Data TIE (time interval error).
    • Time interval error measurements use clock recovery.
    • Clock TIE (time interval error).
    • Time interval error measurements use clock recovery.
    • N-Period.
    • N-Period to N-Period.
    • +Width to +Width.
    • -Width to -Width.
    • +Duty Cycle.
