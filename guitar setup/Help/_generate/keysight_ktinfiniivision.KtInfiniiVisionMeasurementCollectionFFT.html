get_bandwdith(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionMeasurementCollectionFFT, percentage: float, source: str) → float¶

Returns the measured Occupied Bandwidth value.

Parameters:

  • percentage (float) – Specifies the percentage of spectral power occupied bandwidth.

  • source (str) – Specifies the source for measurement.

Returns:

Occupied Bandwidth value.

Return type:

float

Remarks:

• Parameters:
• "Percentage" specifies the percent of spectral power occupied bandwidth is measured for.
• The "Source" parameter can be specified in one of the string formats: { FUNCtion<m> | MATH<m> | FFT } where m: 1 to the number of available math functions and must be an FFT waveform.

• Occupied Bandwidth measures the bandwidth (frequency range) containing some percent (usually 99%) of the total spectral power.
• While 99% is the industry norm, you can specify the percent you want to use in the measurement.
• The center frequency used in the measurement is the one defined for the FFT function, and the FFT span represents the total spectral power.
• When this measurement is tracked with cursors, the cursors show the measured bandwidth (frequency range).

    Returns the measured Total Harmonic Distortion value where fundamental frequency and harmonics are tracked manually.

    Parameters:

    • fundamental_frequency (float) - Specifies the fundamental frequency as a meausrement parameter (manaully tracked) for total harmonic measurement.

    • source (str) - Specifies the source value for the Total Harmonic Distortion measurement.

    Returns:

    Total Harmonic Distortion ratio percentage.

    Return type:

    float

    remarks:
    • To track fundamental frequency and harmonics manually, the fundamental frequency will be entered as a measurement parameter.
    • Parameters:
    • The "Source" parameter can be specified in one of the string formats: { FUNCtion<m> | MATH<m> | FFT } where m: 1 to the number of available math functions and must be an FFT waveform.

    • Total Harmonic Distortion (THD) is the ratio of power in the fundamental frequency to the power contained in the rest of the harmonics and noise.
    • THD is a measure of signal purity.
    • Total Harmonic Distortion (THD) measures the power contained in the bands surrounding each harmonic and compares it to the power in the band surrounding the fundamental frequency.
    • The width of the bands measured is the same for the fundamental frequency and each harmonic. That width is 1/2 of the fundamental frequency.
    • When this measurement is tracked with cursors, the cursors show the band surrounding the fundamental frequency that is being measured (at ±1/4 of the fundamental frequency).

get_power_ratio(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionMeasurementCollectionFFT, channel_width: float, channel_spacing: float, channel_sideband: str, source: str) → float¶

Returns the Adjacent Channel Power Ratio (or Channel Leakage Ratio).

Parameters:

  • channel_width (float) – Specifies the channel width for the FFT analysis measurement.

  • channel_spacing (float) – Specifies the channel spacing for the FFT analysis measurement.

  • channel_sideband (str) – Specifies the channel sideband for the FFT analysis measurement.

  • source (str) – Specifies the source for the FFT analysis measurement.

Returns:

Adjacent Channel Power Ratio (or Channel Leakage Ratio).

Return type:

float

Remarks:
• Adjacent Channel Power Ratio (or channel leakage ratio) measures the ratio of the power in the main frequency range to the power contained in one or more sidebands.
• The main range is specified by a channel width and a center frequency. The center frequency used in the measurement is the one defined for the FFT function.
• Parameters:
• "channelWidth" of main range and sideband channels is specified in Hertz (Hz).
• "channelSpacing" i.e. spacing between main range and sideband channels in specified in He;rtz (Hz).
• "channelSideband" is specified in one of the string formats: { CENTer | HIGH<sb> | LOW<sb> } where sb: sideband 1 to 5.
• The "Source" parameter can be specified in one of the string formats: { FUNCtion<m> | MATH<m> | FFT } where m: 1 to the number of available math functions and must be an FFT waveform.

• Sidebands (with the same width as the main range) exist above and below the main range separated by the channel spacing width.
• The sideband used for the measurement is selected with the <channelSideband> parameter. You can select the first through fifth sidebands above or below the main range (HIGH1 through HIGH5 above and LOW1 through LOW5 below). The full sideband must be in the graticule (on screen) to be measured. Otherwise, the measurement results will be "Incomplete".
• When this measurement is tracked with cursors, the cursors show the sideband being measured.
