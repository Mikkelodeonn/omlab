KtInfiniiVisionTriggerPattern¶

Access interface members using: driver.trigger.pattern
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionTriggerPattern¶

KtInfiniiVisionTriggerPattern interface.

property analog_pattern¶

Sets and gets the analog channel pattern. Only permissible character starting left side of the string will be accepted, rest of the string will be truncated.

Access:

ReadWrite

Type:

str

Remarks:
For example, if input string is "01010101XXXXXXX" and the model has 4 analog channels only "01010" will be accepted.
property condition¶

Sets and gets the pattern matching condition. This property specifies when the trigger event occurs with respect to the pattern, either trigger on entering the specified pattern or exiting the specified pattern.

Access:

ReadWrite

Type:

PatternMatchingMode

Remarks:

• Enter: when the pattern is entered.
• Lessthan: when the pattern is present for less than a time value.
• GreaterThan: when the pattern is present for greater than a time value. Thetrigger occurs when the pattern exits (not when the Greaterthan time value is exceeded)
• Timeout: when the pattern is present for greater than a time value. In this case, the trigger occurs when the Greaterthan time value is exceeded (not when the pattern exits).
• InRange: when the pattern is present for a time within a range of values.
• OutRange: when the pattern is present for a time outside of range of values.
• Pattern durations are evaluated using a timer. The timer starts on the last edge that makes the pattern (logical AND) true. Except when the Timeout qualifier is selected, the trigger occurs on the first edge that makes the pattern false, provided the time qualifier criteria has been met.
configure(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionTriggerPattern, analog_pattern: str, digital_pattern: str, condition: keysight_ktinfiniivision.keysight_ktinfiniivision.PatternMatchingMode) → None¶

Configures the pattern trigger

Parameters:

  • analog_pattern (str) – The analog channel pattern.

  • digital_pattern (str) – The digital channel pattern. This parameter will only be taken into account when MSO is licensed.

  • condition (PatternMatchingMode) – The pattern matching condition. This attribute specifies when the trigger event occurs with respect to the pattern, either trigger on entering the specified pattern or exiting the specified pattern.

Returns:

None

property digital_pattern¶

Sets and gets the digital channel pattern. Only permissible character starting left side of the string will be accepted, rest of the string will be truncated.

Access:

ReadWrite

Type:

str

Remarks:
For example, if input string is "01010101XXXXXXX" and the model has 8 digital channels only "01010101" will be accepted.
get_range(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionTriggerPattern) → Tuple[float, float]¶

Gets the duration time for the defined pattern.

Returns:

A tuple containing:

  • lessThanTime (float) : Less than time.

  • greaterThanTime (float) : Greater than time.

Type:

tuple[float, float]

property max_duration¶

Sets and gets the maximum duration for the defined pattern when pattern condition is set to Lessthan. The units are seconds.

Access:

ReadWrite

Type:

float

Remarks:
With the input value suitable suffix from { s | ms | us | ns | ps } can be selected.
property min_duration¶

Sets and gets the minimum duration for the defined pattern when pattern condition is set to Greaterthan. The units are seconds.

Access:

ReadWrite

Type:

float

Remarks:

• It can also specify the timeout value when the pattern condition is set to Timeout.
• With the input value suitable suffix from { s | ms | us | ns | ps } can be selected.
property number_base¶

Sets and gets the number base for trigger patterns.

Access:

ReadWrite

Type:

TriggerPatternFormat

Remarks:
The default base is ASCII.
set_range(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionTriggerPattern, less_than_time: float, greater_than_time: float) → None¶

Sets the duration for the defined pattern when the pattern condition is set to INRange or OUTRange

Parameters:

  • less_than_time (float) – Less than time. Permissible values are from 10 ns to 9.99 seconds.

  • greater_than_time (float) – Greater than time.. Permissible values are from 15 ns to 10 seconds

Returns:

None

Remarks:

• User can enter the parameters in any order, the smaller value becomes the greater than time, and the larger value becomes the less than time.
• With the input value suitable suffix from { s | ms | us | ns | ps } can be selected.
