KtInfiniiVisionDVM¶

Access interface members using: driver.dvm
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionDVM¶

KtInfiniiVisionDVM interface.

property auto_range_enabled¶

Enables or disables the Digital Voltmeter’s Auto Range capability.

Access:

ReadWrite

Type:

bool

Remarks:
• If the selected digital voltmeter (DVM) source channel is not used in oscilloscope triggering, this propery can turn the digital voltmeter's Auto Range capability on or off.

• When On, the DVM channel's vertical scale, vertical (ground level) position, and trigger (threshold voltage) level (used for the counter frequency measurement) are automatically adjusted. The Auto Range capability overrides attempted adjustments of the channel's vertical scale and position.
•When Off, the channel's vertical scale and position normally can be adjusted.
property current¶

Read Only - Returns the displayed 3-digit DVM value based on the current mode.

Access:

ReadOnly

Type:

float

Remarks:
The 3-digit DVM is a floating-point number.
property enabled¶

Enables or disables the Digital Voltmeter (DVM) analysis feature.

Access:

ReadWrite

Type:

bool

property frequency¶

Read Only - Returns the displayed 5-digit frequency value that is displayed below the main DVM value.

Access:

ReadOnly

Type:

float

Remarks:
For 3000T, 4000X and 6000X series, the Frequency capability is accessible from the Counter interface
property mode¶

Specifies the digital voltmeter (DVM) mode.

Access:

ReadWrite

Type:

DVMMode

Remarks:
• "Frequency Mode" in DVM is only allowed in X1000, X1200, X2000 & X3000 Series oscilloscopes.
• And requires the TriggerEdgeSource must be the same analog channel.
property source¶

Specifies the selected analog channel on which digital voltmeter (DVM) measurements are made.

Access:

ReadWrite

Type:

str

Remarks:
• The parameter < source > can be specified in the string format: Channel<n>, where

• n: 1 to the number of available analog channels for X1000, X1200 Series oscilloscopes.
• n: 1 - 2 or 1 - 4 for rest other series.

• The selected channel does not have to be on (displaying a waveform) in order for DVM measurements to be made.
