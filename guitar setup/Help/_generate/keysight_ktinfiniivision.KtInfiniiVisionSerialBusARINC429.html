KtInfiniiVisionSerialBusARINC429¶

Access interface members using: driver.serial_buses[<name_or_index>].arinc429
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSerialBusARINC429¶

KtInfiniiVisionSerialBusARINC429 interface.

auto_setup(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionSerialBusARINC429) → None¶

Automatically configures settings for the ARINC 429 serial bus mode.

Returns:

None

Remarks:
It sets the upper/lower trigger threshold to 3.0V and -3.0V repsectively, turn Noise Reject off, sets the probe attenuation to 10:0, sets the vertical scale to 4V/div, turn Serial Decode on, sets the base to Hex, sets the format to Label/SDI/Data/SSM, sets the trigger to the currently active serial bus and sets the trigger mode to Word Start.
property base¶

Sets and gets the ARINC 429 base setting (by selecting between hexadecimal and binary) display of the decoded data.

Access:

ReadWrite

Type:

SerialBusARINC429Base

Remarks:
  • The Base property can be set to one of the following values:
    • Binary: specifies binary base
    • Hexadecimal: specifies hexadecimal base
  • The Base property has no effect on the SDI and SSM fields, which are always displayed in binary, nor the Label field, which is always displayed in octal.

    • LabelData: specifies the Label/Data format

    set_trigger_range(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionSerialBusARINC429, lower_limit: str, upper_limit: str) → None¶

    Sets the range for the Label Range trigger mode for the selected bus.

    Parameters:

    • lower_limit (str) – The lower limit for the Label Range trigger mode for the selected bus.

    • upper_limit (str) – The upper limit for the Label Range trigger mode for the selected bus.

    Returns:

    None

    Remarks:
    The LowerLimit and UpperLimit parameters can be specified in one of the following formats:
    • "n", where n: 8-bit integer from 0-255
    • "#Hnn", where n: {0,..,9 | A,..,F}
    • "#Qnn", where n: {0,..,7}
    • "0xnn", where n: {0,..,9 | A,..,F}
    property signal_type¶

    Sets and gets the type of ARINC 429 signal being probed. Line A (non-inverted), Line B (inverted), or Differential (A-B).

    Access:

    ReadWrite

    Type:

    SerialBusARINC429SignalType

    Remarks:
    The SignalType property can be set to one of the following values:
    • LineA: specifies the Line A (non-inverted) signal type.
    • LineB: specifies the Line B (inverted) signal type.
    • Differential: specifies the Differential (A - B) signal type.
    property source¶

    Sets and gets which signal is used as the source for the selected bus.

    Access:

    ReadWrite

    Type:

    str

    Remarks:
    The source can be of the format: Channel<n>, where n: 1 to the number of available analog channels.
    property speed¶

    Sets and gets the speed of the ARINC 429 interface for the selected bus.

    Access:

    ReadWrite

    Type:

    SerialBusARINC429Speed

    Remarks:
    The Speed property can be set to one of the following values:
    • Low: specifies low speed (12.5kb/s)
    • High: specifies high speed (100kb/s)
    • User: let user specify a user defined baud rate using SerialBusARINC429BaudRate
    property trigger_label¶

    Sets and gets the Label portion of the trigger for the selected bus.

    Access:

    ReadWrite

    Type:

    str

    Remarks:
  • The TriggerLabel property can be specified in one of the following formats:
    • "n", where n: 8-bit integer from 0-255
    • "#Hnn", where n: {0,..,9 | A,..,F}
    • "#Qnn", where n: {0,..,7}
    • "0xnn", where n: {0,..,9 | A,..,F}
    • "0xXX" (don't care)
  • To set the label value to don't cares (0xXX), set the value to -1.
    • property trigger_pattern_data¶

    Sets and gets the Data portion of the trigger for the selected bus, in binary.

    Access:

    ReadWrite

    Type:

    str

    Remarks:
  • The TriggerPatternData property can be specified in the following format:
    • "nn..n", where n: {0 | 1 | X}
  • The length depends on the value of the DisplayFormat property:
    • If SerialBusARINC429DisplayFormat is set to Label/SDI/Data/SSM, then the data length is 19 bits.
    • If SerialBusARINC429DisplayFormat is set to Label/Data/SSM, then the data length is 21 bits.
    • If SerialBusARINC429DisplayFormat is set to Label/Data, then the data length is 23 bits.
  • If more bits are sent then the specified limit, the most significant bits will be truncated.
    • property trigger_pattern_sdi¶

    Sets and gets the SDI portion of the trigger for the selected bus, in binary. Length is always 2 bits.

    Access:

    ReadWrite

    Type:

    str

    Remarks:
    This property can be specified in the following format: "nn", where n: {0 | 1 | X}
    property trigger_pattern_ssm¶

    Sets and gets the SSM portion of the trigger for the selected bus, in binary. Length is always 2 bits.

    Access:

    ReadWrite

    Type:

    str

    Remarks:
    This property can be specified in the following format: "nn", where n: {0 | 1 | X}
    property trigger_type¶

    Sets and gets the ARINC 429 trigger mode for the selected bus.

    Access:

    ReadWrite

    Type:

    SerialBusARINC429TriggerType

    Remarks:
    The Trigger Type can be set to one of the following values:
    • WordStart: Word start mode
    • WordStop: Word stop mode
    • Label: Label mode
    • LabelBits: Label + Bits mode
    • LabelRange: Label range mode
    • ParityError: Parity error mode
    • WordError: Word error mode
    • GapError: Gap error mode
    • WordOrGapError: Word or Gap error mode
    • AllErrors: All errors mode
    • AllBits: All bits mode
    • TypeAllZeroBits: All zero bits mode
    • AllOneBits: All one bits mode
    property word_count¶

    Read Only - Returns the ARINC 429 word count.

    Access:

    ReadOnly

    Type:

    int
