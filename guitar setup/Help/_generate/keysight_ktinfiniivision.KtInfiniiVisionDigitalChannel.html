KtInfiniiVisionDigitalChannel¶

Access interface members using: driver.digital_channels[<name_or_index>]
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionDigitalChannel¶

Root interface for the DigitalChannel repeated capability.

property enabled¶

Enables/Disables the specified digital channel.

Access:

ReadWrite

Type:

bool

Remarks:
Only valid for the MSO models.
get_digital_setup(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionDigitalChannel) → str¶

query returns setup information for the specified digital channel

Returns:

Return type:

str

property label¶

Enables/Disables analog and digital channel labels.

Access:

ReadWrite

Type:

str

Remarks:

• This command is only valid for the MSO models.
• Label strings are 10 characters or less. If more than 10 charactersare used , then label is truncated to 10 characters.
property name¶

The repeated capability physical identifier.

Access:

ReadOnly

Type:

str

property position¶

Sets and gets the position of the specified channel.

Access:

ReadWrite

Type:

int

Remarks:
• If the returned value is "-1", this indicates there is no space to display the digital waveform.
• This command is only valid for the MSO models.
• Note that bottom positions might not be valid depending on whether digital buses, serial decode waveforms, or the zoomed time base are displayed.
Channel Size Position Top Bottom
Larg 0-7 7 0
Medium 0-15 15 0
Small 0-31 31 0
property size¶

Sets and gets the size of digital channels on the display.

Access:

ReadWrite

Type:

DigitalChannelSize

Remarks:

• The Digital channels sizes are small, medium and large.
• This command is only valid for the MSO models.
• Sizes are set for all digital channels. Therefore, if you set the size on digitalm channel 0 (for example), the same size is set on all other as well.
property threshold¶

Logic threshold value for all channels in the same pod as the specified channel. The threshold is used for triggering purposes and for displaying the digital data as high(above the threshold) or low (below the threshold).

Access:

ReadWrite

Type:

str

Remarks:

• For the user defind value <suffix>, can be used from { V | mV | uV }
• Permissible values are { CMOS | ECL | TTL } user defined <value> user defined value can be from -8.00 to +8.00.
• This command is only valid for the MSO models.
• The threshold is used for triggering purposes and for displaying the digital data as high (above the threshold) or low (below the threshold).
