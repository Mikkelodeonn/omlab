WaveformMeasurementType¶

class WaveformMeasurementType¶

Values for the MeasFunction parameter of the measurement Read and Fetch methods.

Members:

RISE_TIME : The length of time for a rising edge of the signal to rise from the low reference level to the high reference level. The units are seconds.

FALL_TIME : The length of time for a falling edge of the signal to fall from the high reference level to the low reference level. The units are seconds.

FREQUENCY : The frequency of one complete cycle in the waveform. The units are Hertz.

PERIOD : The length of time of one complete cycle in the waveform. The units are seconds.

PEAK_TO_PEAK : The absolute difference between the Voltage Max and the Voltage Min. The units are Volts.

VOLTAGE_MAX : The maximum amplitude found in the entire waveform. The units are Volts.

VOLTAGE_MIN : The minimum amplitude found in the entire waveform. The units are Volts.

VOLTAGE_HIGH : The voltage that corresponds to 100% when using the reference levels. The oscilloscope calculates this value using either the min/max or histogram methods.

VOLTAGE_LOW : The voltage that corresponds to 0% when using the reference levels. The oscilloscope calculates this value using either the min/max or histogram methods.

WIDTH_NEG : The length of time between the mid reference level points of a negative pulse in the waveform. The units are seconds.

WIDTH_POS : The length of time between the mid reference level points of a positive pulse in the waveform. The units are seconds.

DUTY_CYCLE_NEG : The ratio of the Width Neg to the Period of an integer number of cycles in the waveform expressed as a percentage.

DUTY_CYCLE_POS : The ratio of the Width Pos width to the Period of an integer number of cycles in the waveform expressed as a percentage.

AMPLITUDE : The Voltage High less the Voltage Low in Volts over the entire waveform.

OVER_SHOOT : The relative waveform distortion that follows an edge transition.

PRESHOOT : The relative waveform distortion that precedes an edge transition.

FREQUENCY_COUNTER : The High precision frequency measurement made with an internal frequency counter.

TIME_AT_MAX : The time of the maximum amplitude found in the entire waveform. The units are seconds.

TIME_AT_MIN : The time of the minimum amplitude found in the entire waveform. The units are seconds.

BURST_WIDTH : – NOT SUPPORTED IN 2000 X-SERIES – the width of the burst on the screen. The burst width is calculated as follows: burst width = (last edge on screen - first edge on screen)This option is not available if the source is FFT (Fast Fourier Transform).

FALLING_EDGE_COUNT : – NOT SUPPORTED IN 2000 X-SERIES – Measures the on-screen falling edge count.

FALLING_PULSE_COUNT : – NOT SUPPORTED IN 2000 X-SERIES – Measures the on-screen falling pulse count.

RISING_EDGE_COUNT : – NOT SUPPORTED IN 2000 X-SERIES – Measures the on-screen rising edge count.

RISING_PULSE_COUNT : – NOT SUPPORTED IN 2000 X-SERIES – Measures the on-screen rising pulse count.

STANDARD_DEVIATION : – NOT SUPPORTED IN 2000 X-SERIES – Measures the standard deviation of the selected waveform. The oscilloscope computes the standard deviation on all displayed data points.

BIT_RATE : Bit rate measurement.

NEGATIVE_DUTY_CYCLE : Installs a screen measurement and starts a negative duty cycle measurement.
