KtInfiniiVisionSerialBusCXPI¶

Access interface members using: driver.serial_buses[<name_or_index>].cxpi
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSerialBusCXPI¶

KtInfiniiVisionSerialBusCXPI interface.

property baud_rate¶

Sets and gets the baud rate of the CXPI signal from device under test.

Access:

ReadWrite

Type:

int

Remarks:
  • The default baud rate is 20 kb/s.
  • The CXPI baud rate can be set from 9600 b/s to 40000 b/s in 100 b/s increments.
    • property display_parity¶

    Enable or disable the parity bit to display in the identifier field.

    Access:

    ReadWrite

    Type:

    bool

    Remarks:
    When Off, the upper bit is masked. The parity is still checked, but it is not displayed unless a parity error occurs.
    property source¶

    Sets and gets the oscilloscope channel connected to the CXPI signal line.

    Access:

    ReadWrite

    Type:

    str

    Remarks:
    The source can be of the format: Channel<n>, where n: 1 to the number of available analog channels.
    property tolerance¶

    Sets and gets the tolerance as a percentage of the Tbit width.

    Access:

    ReadWrite

    Type:

    int

    Remarks:
    Range : 1 to 30
    property trigger_cxpi_frame¶

    Sets and gets the Count (CT) value of the CXPI frame you wish to trigger on.

    Access:

    ReadWrite

    Type:

    str

    Remarks:
  • This is a two-bit binary value in the format "nn" where n ::= {0 | 1 | X}.
  • Applicable for the trigger types that let the user trigger on data, as well as frame ID and frame information bits.
    • property trigger_cxpi_length¶

    Sets and gets the data length code of the CXPI frame you wish to trigger on.

    Access:

    ReadWrite

    Type:

    int

    Remarks:
  • When SerialBusCXPITriggerType is Data, Range :-1 (don't care) to 15.
  • When SerialBusCXPITriggerType is LData, Range :-1 (don't care) to 255.
  • It will also affect the number of data bytes user can specify in the trigger.
  • Applicable for the trigger types that let the user trigger on data.
    • property trigger_cxpinm¶

    Sets and gets the Network Management (NM) value of the CXPI frame you wish to trigger on.

    Access:

    ReadWrite

    Type:

    str

    Remarks:
  • This is a two-bit binary value in the format "nn" where n ::= {0 | 1 | X}.
  • Applicable for the trigger types that let the user trigger on data, as well as frame ID and frame information bits.
    • property trigger_id_filter¶

    Enable or disable modification of the trigger so that it occurs only for a specified ID.

    Access:

    ReadWrite

    Type:

    bool

    Remarks:
    Applicable for the trigger types that let the user trigger on CRC Field Errors, Inter-Byte Space Errors, Framing Errors, or Data Length Errors.
    property trigger_p_type¶

    Enable or disable the trigger on data types when the special PTYPE byte is present (ON) or not present (OFF).

    Access:

    ReadWrite

    Type:

    bool

    property trigger_pattern_data¶

    Stes and gets the specified data value for the trigger types that let you trigger on data.

    Access:

    ReadWrite

    Type:

    str

    Remarks:
  • This property can be specified in one of the following string formats:
    • "nn...n", where n: {0 | 1 | X | $}
    • "0xnn...n", where n: {0,..,9 | A,..,F | X | $}
  • If the string parameter starts with "0x", it is a hexadecimal string made up of hexadecimal and X (don't care) characters; otherwise, it is a binary string made up of 0, 1, and X (don't care) characters.
    • property trigger_pattern_data_length¶

    Sets and gets the length of the data to trigger on, from 0 to 12 bytes, limited by the data length code (DLC).

    Access:

    ReadWrite

    Type:

    int

    property trigger_pattern_id¶

    Sets and gets the frame ID value for the trigger types. It lets the user specify frame ID values in the trigger or allow filtering by the frame ID.

    Access:

    ReadWrite

    Type:

    str

    Remarks:
  • The TriggerPatternID property can be specified in one of the following string formats:
    • "nn...n", where n: {0 | 1 | X | $}
    • "0xnn...n", where n: {0,..,9 | A,..,F | X | $}
  • If the string parameter starts with "0x", it is a hexadecimal string made up of hexadecimal and X (don't care) characters; otherwise, it is a binary string made up of 0, 1, and X (don't care) characters.
    • property trigger_pattern_start_byte_position¶

    Sets and gets the starting byte location where the data value should be found.

    Access:

    ReadWrite

    Type:

    int

    Remarks:
    The starting byte location must be within the first 123 bytes when SerialBusCXPITriggerPType is disabled.
    property trigger_type¶

    Sets and gets the CXPI trigger type.

    Access:

    ReadWrite

    Type:

    SerialBusCXPITriggerType

    Remarks:
  • SOF(Start of Frame): triggers at the start bit of any frame.
  • EOF (End of Frame): triggers at the end of any frame.
  • PType: triggers on any frame that starts with the special PTYPE byte.
  • ID (Frame ID): triggers on a user-defined Frame ID at the end of the PID byte.
  • Data (Frame ID, Info and Data): triggers on CXPI frames at the end of the last data byte defined in the trigger.
  • LData (Frame ID, Info and Data (Long Frame)): triggers on CXPI frames at the end of the last data byte defined in the trigger.
  • CRCError (CRC Field Error): triggers when the calculated CRC does not match the transmitted CRC.
  • ParityError: triggers when the parity bit in the PID or PTYPE field is not correct.
  • IBSError (Inter-Byte Space Error): triggers when there are more than 9 bits between consecutive bytes in a frame.
  • IFSError (Inter-Frame Space Error): triggers when there are fewer than 10 idle bits before a new frame begins.
  • FramingError: triggers when the stop bit of a byte is not logical 1.
  • DLengthError (Data Length Error): triggers when there are more data bytes in a frame than is indicated by the DLC or Extended DLC field.
  • SampleError: triggers when 10 consecutive logical 0s are detected.
  • AllErrors: triggers on all CRC, Parity, IBS, Stop Bit, Data Length, and Sample errors.
  • SleepFrame: triggers when a normal frame is transmitted matching the definition of a sleep frame in the CXPI specification.
  • WakeupPulse: triggers when a wakeup pulse is detected.
