KtInfiniiVisionAnalogChannel¶

Access interface members using: driver.analog_channels[<name_or_index>]
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionAnalogChannel¶

Root interface for the AnalogChannel repeated capability.

property bandwidth_limit¶

Sets and gets the bandwidth limit value and turns on bandwidth limiting.

Access:

ReadWrite

Type:

float

Remarks:

• For waveforms with frequencies below the bandwidth limit, turning the bandwidth limit on removes unwanted high frequency noise from the waveform.
• Bandwidth limit also limits the trigger signal path of the channel.
• If the bandwidth limit is off, the query returns the full bandwidth of the oscilloscope.
• When the Maximum parameter is used, the oscilloscope's maximum possible bandwidth is returned.
• While you can request any limit; for X1000, X12000, X2000, X3000, and X4000 Series the oscilloscope will choose the only bandwidth limit available i.e. 25 MHz.
• For X6000 the oscilloscope will choose the one that is greater than or equal to the limit requested. The limits available depend on the bandwidth of oscilloscope, the channel's input impedance and the channel's V/div as shown in the following table.
Input Impedance V/div Oscilloscope Bandwidth Limits Available
1M Ohm >2 mV/div (all) 20 MHz
<=2 mV/div (all) 20 MHz or 200 MHz
50 Ohm (all) 1 GHz 20 MHz or 200 MHz
2.5 GHz 20 MHz, 200 MHz, or 1.5 GHz
4 GHz 20 MHz, 200 MHz, 1.5 GHz, or 3 GHz
6 GHz 20 MHz, 200 MHz, 1.5 GHz, or 3 GHz
property bandwidth_limit_enabled¶

Enables or disables the bandwidth limit.

Access:

ReadWrite

Type:

bool

Remarks:
If bandwidth limiting is currently Off, turning it On
• The bandwidth of the specified channel is limited to approximately 25 MHz for X1000, X1200, X2000, X3000, X4000, T3000, M9240X and P9240X Series Oscilloscopes.
• For X6000 Series Oscilloscopes, it will invoke the lowest possible bandwidth limit 20 MHz.
clear_protection(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionAnalogChannel) → None¶

Reset the analog channel input impedance to 50 Ohms after clearing the overvoltage protection.

Returns:

None

Remarks:

• When the analog channel input impedance is set to 50 Ω, the input channels are protected against overvoltage.
• When an overvoltage condition is sensed, the input impedance for the channel is automatically changed to 1 MΩ.
• This property does nothing for X1000, X1200 and X2000, Series Oscilloscopes as the analog channel input impedance is always 1 MΩ, so automatic overvoltage protection is not necessary. And no protection settings are required to cleared.
configure(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionAnalogChannel, range: float, offset: float, coupling: keysight_ktinfiniivision.keysight_ktinfiniivision.ChannelCoupling, probe_attenuation: float, enabled: bool) → None¶

Configures the range, offset, coupling, probe attenuation, and channel enabled state of the oscilloscope.

Parameters:

  • range (float) – Specifies the vertical range. This value sets the Vertical Range property.

  • offset (float) – Specifies the vertical offset. This value sets the Vertical Offset property.

  • coupling (ChannelCoupling) – Specifies how to couple the input signal.

  • probe_attenuation (float) – Specifies the probe attenuation. This value sets the Probe Attenuation property.

  • enabled (bool) – Specifies if the channel is enabled for acquisition. This value sets the Channel Enabled property.

Returns:

None

configure_characteristics(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionAnalogChannel, input_impedance: float, input_frequency_max: float) → None¶

Configures the input impedance and the maximum frequency of the input signal which control the electrical characteristics of the channel.

Parameters:

  • input_impedance (float) – The input impedance for the channel. The driver sets the Input Impedance to this value.

  • input_frequency_max (float) – The maximum input frequency for the channel. The driver sets the Max Input Frequency to this value.

Returns:

None

property input_frequency_max¶

The maximum input frequency of the channel. It is the frequency at which the input circuitry attenuates the input signal by 3 dB. The units are hertz.

Access:

ReadWrite

Type:

float

Remarks:
  • For 6000X series this property sets the bandwidth limit value and turns on bandwidth limiting.
  • You can request any limit, the oscilloscope will choose the one that is greater than or equal to the limit requested. The limits available depend on the bandwidth of oscilloscope, the channel's input impedance, and the channel's V/div as shown below in the table:

    • Input Impedance V/div Oscilloscope Bandwidth Limits Available
    1M Ohm >2 mV/div (all) 20 MHz
    <=2 mV/div (all) 20 MHz or 200 MHz
    50 Ohm (all) 1 GHz 20 MHz or 200 MHz
    2.5 GHz 20 MHz, 200 MHz, or 1.5 GHz
    4 GHz 20 MHz, 200 MHz, 1.5 GHz, or 3 GHz
    6 GHz 20 MHz, 200 MHz, 1.5 GHz, or 3 GHz

    property label¶

    The analog channel label.

    Access:

    ReadWrite

    Type:

    str

    Remarks:

    • For 2000X Family: Label strings are 10 characters or less, and may contain any commonly used ASCII characters. Labels with more than 10 characters are truncated to 10 characters. Lower case characters are converted to upper case.
    • For 3000X, 4000X and 6000X families: Label strings are 32 characters or less, and may contain any commonly used ASCII characters. Labels with more than 32 characters are truncated to 32 characters. Lower case characters are converted to upper case.
    • Setting a label for a channel also adds the name to the label list in non-volatile memory (replacing the oldest label in the list).

    property offset¶

    The location of the center of the range that you specify with the Range property. The units are volts, with respect to ground. For example, to acquire a sine wave spanning 0.0 to 10.0 volts, set Offset to 5.0 volts.

    Access:

    ReadWrite

    Type:

    float

    Remarks:

    • With the input value, <suffix> can be chosen from { V | mV }
    • If offset value is set to a value outside of the legal range, the offset value is automatically set to the nearest legal value.
    • Legal values are affected by the probe attenuation setting.
    property probe_attenuation¶

    The scaling factor by which the probe attenuates the input signal. For example, with a 10:1 probe, the value is 10.0.

    Access:

    ReadWrite

    Type:

    float

    Remarks:

    • The obsolete attenuation values X1, X10, X20, X100 are also supported.
    • The probe attenuation factor may be from 0.001 to 10000.
    • This property does not change the actual input sensitivity of the oscilloscope. It changes the reference constants for scaling the display factors, for making automatic measurements, and for setting trigger levels.
    • If an AutoProbe probe is connected to the oscilloscope, the attenuation value cannot be changed from the sensed value. Attempting to set the oscilloscope to an attenuation value other than the sensed value produces an error.
    property probe_head_type¶

    Sets and gets an analog channel probe head type and dB value.

    Access:

    ReadWrite

    Type:

    ChannelProbeHeadType

    Remarks:
  • Valid only for the 113xA Series probes.
  • The probe head type and dB values are:
      SEND0: Single-ended, 0 dB.
      SEND6: Single-ended, 6 dB.
      SEND12: Single-ended, 12 dB.
      SEND20: Single-ended, 20 dB.
      DIFF0: Differential, 0 dB.
      DIFF6: Differential, 6 dB.
      DIFF12: Differential, 12 dB.
      DIFF20: Differential, 20 dB.
      DSMA: Differential SMA probe head, 0 dB.
      DSMA6: Differential SMA probe head, 6 dB.

    property probe_r_sense¶

    Sets and gets the R-sense resistor value that is being probed in DUT, When the N2820A high-sensitivity current probe is used with the N2825A user-defined R-sense head.

    Access:

    ReadWrite

    Type:

    float

    Remarks:
  • Suppoeted R-sense resistor values are from 1 mΩ to 1MΩ.
  • When the N2820A high-sensitivity current probe is not attached, infinite value is retrned by property.
  • When the N2820A high-sensitivity current probe is attached and a special head is attached to the probe, the property returns the value of the special head.
    • property probe_sense¶

    Read Only - The probe attenuation value the oscilloscope automatically senses. If the automatic probe sense is disabled, its value is the manual probe attenuation setting.

    Access:

    ReadOnly

    Type:

    float

    property probe_signal¶

    Sets and gets the channel probe signal type (STYPe) to differential or single-ended when using the 113xA Series probes and determines how offset is applied.

    Access:

    ReadWrite

    Type:

    ChannelProbeSignalType

    Remarks:
  • Valid only for the 113xA Series probes.
  • When single-ended is selected, the ChannelOffset changes the offset value of the probe amplifier.
  • When differential is selected, the ChannelOffset changes the offset value of the channel amplifier.
    • property probe_skew¶

    Channel-to-channel skew factor for the specified channel. Each analog channel can be adjusted + or -100 ns for a total of 200 ns difference between channels.

    Access:

    ReadWrite

    Type:

    float

    Remarks:
    The oscilloscope's probe skew control can be used to remove cable-delay errors between channels.
    property probe_zoom¶

    Sets and gets the zoom state, whether the cable will have the Zoom In waveform (ON) or the Zoom Out waveform (OFF), when the N2820A high-sensitivity current probe is used with both the Primary and Secondary cables.

    Access:

    ReadWrite

    Type:

    bool

    Remarks:
    The other cable will have the opposite waveform.
    property protection¶

    Read Only - State of the input protection for specified channel. If a channel input has experienced an overload, TRIP (tripped) will be returned otherwise NORM (normal).

    Access:

    ReadOnly

    Type:

    property range¶

    The absolute value of the input range the oscilloscope can acquire for the channel. The units are volts. For example, to acquire a sine wave spanning -5.0 to 5.0 volts, set Range to 10.0 volts.

    Access:

    ReadWrite

    Type:

    float

    Remarks:

    • With the input value, <suffix> can be chosen from { V | mV }
    • When using 1:1 probe attenuation, legal values for the range are from 16 mV to 40 V.
    • If the probe attenuation is changed, the scale value is multiplied by the probe's attenuation factor.
    property scale¶

    Vertical scale, or units per division, of the selected channel.

    Access:

    ReadWrite

    Type:

    float

    Remarks:

    • With the input value, <suffix> can be chosen from { V | mV }
    • When using 1:1 probe attenuation, legal values for the scale are from 2 mV to 5 V.
    • If the probe attenuation is changed, the scale value is multiplied by the probe's attenuation factor.

    Measurement units for the connected probe.

    Access:

    Type:

    ChannelUnits

    Remarks:
    • Voltage to be selcted for a voltage probe and Ampere for a current probe.
    • Measurement results, channel sensitivity, and trigger level will reflect the measurement units you select.
