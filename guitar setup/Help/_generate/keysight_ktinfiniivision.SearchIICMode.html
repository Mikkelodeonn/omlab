SearchIICMode¶

class SearchIICMode¶

Values for the type of IIC information to find in the Lister display.

Members:

READ7 : Searches for 7-bit address frames containing Start:Address7:Read:Ack:Data.

WRITE7 : Searches for 7-bit address frames containing Start:Address7:Write:Ack:Data

MISSING_ACKNOWLEDGE : Searches for missing acknowledge events

NO_ACKNOWLEDGE : Searches for address with no acknowledge events

R7_DATA2 : Searches for 7-bit address frames containing Start:Address7:Read:Ack:Data:Ack:Data2

W7_DATA2 : Searches for 7-bit address frames containing Start:Address7:Write:Ack:Data:Ack:Data2

RESTART : Searches for another start condition occurring before a stop condition.

READ_EPROM : Searches for EEPROM data reads

ADDRESS : Searches for a packet with the specified address.
