KtInfiniiVisionSerialBusCAN¶

Access interface members using: driver.serial_buses[<name_or_index>].can
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSerialBusCAN¶

KtInfiniiVisionSerialBusCAN interface.

property baud_rate¶

Sets and gets the standard baud rate of the CAN signal. The baud rate is set from 10 kb/s to 1 Mb/s in 100 b/s increments. If you enter a baud rate that is not divisible by 100 b/s, the baud rate is set to the nearest baud rate divisible by 100 b/s.

Access:

ReadWrite

Type:

int

Remarks:

• User can also set the baud rate of the CAN signal to 5 Mb/s. Fractional baud rates between 4 Mb/s and 5 Mb/s are not allowed.
• If the baud rate you select does not match the system baud rate, false triggers may occur.
• Valid values are from 10000 to 4000000 in 100b/s increments.

property sample_point¶

Sets and gets the current CAN sample point setting.

Access:

ReadWrite

Type:

float

Remarks:

• User can set the point during the bit time where the bit level is sampled to determine whether the bit is dominant or recessive.
• The sample point represents the percentage of time between the beginning of the bit time to the end of the bit time.
• Valid values are: 30.0 to 90.0 in NR3 format for X6000 series oscilloscopes.
• For others valid values are: 60, 62.5, 68, 70, 75, 80, 87.5
property signal_type¶

Sets and gets the CAN signal type when TriggerCondition is set to SOF (Start of Frame).

Access:

ReadWrite

Type:

SerialBusCANSignalType

Remarks:
The SignalType property can be set to one of the following values:

• Dominant high signals:

• CANH: the actual CAN_H differential bus signal.
• DIFH: the CAN differential (H-L) bus signal connected to an analog source channel using a differential probe.

• Dominant low signals:

• CANL: the actual CAN_L differential bus signal.
• RX: the Receive signal from the CAN bus transceiver.
• TX: the Transmit signal to the CAN bus transceiver.
• DIFL: the CAN differential (L-H) bus signal connected to an analog source channel using a differential probe.
• Differential: the CAN differential bus signal connected to an analog source channel using a differential probe. This is the same as DIFL.
property source¶

Sets and gets the source for the CAN signal.

Access:

ReadWrite

Type:

str

Remarks:

• The Source property can be specified in one the following string formats:

• For DSO Models:

• "Channel<n>", where <n> can be from 1 to the number of analog channels.
• "Value_External" - for External

• For MSO Models:

• "Channel<n>", where <n> can be from 1 to the number of analog channels.
• "DigitalChannel<d>", where <d> can be from 0 to the number of digital channels minus 1. For X2000 series DigitalChannels are not supported as source.

property trigger_condition¶

Sets and gets the CAN trigger on condition.

Access:

ReadWrite

Type:

SerialBusCANTriggerCondition

Remarks:
The TriggerCondition property can be set to one of the following values:
  • SOF: will trigger on the Start of Frame (SOF) bit of a Data frame, Remote Transfer Request (RTR) frame, or an Overload frame
  • Data: will trigger on CAN Data frames matching the specified Id, Data, and the DLC (Data length code)
  • Error: will trigger on CAN Error frame
  • DData: will trigger on CAN frames matching the specified Id of a Data frame
  • Either: will trigger on the specified Id, regardless if it is a Remote frame or a Data frame
  • IDRemote: will trigger on CAN frames matching the specified Id of a Remote frame
  • AllErrors: will trigger on CAN active error frames and unknown bus conditions
  • Overload: will trigger on CAN overload frames
  • SerialBusCANTriggerConditionAckError - will trigger on a data or remote frame acknowledge bit that is recessive

The table below shows the remote programming parameter and the corresponding front-panel softkey selection:
Remote Parameter Front-panel Trigger on: softkey selection (softkey text - softkey popup text)
SOF SOF: Start of Frame
Data ID & Data: Data Frame ID and Data
Error Error: Error frame
IDData ID & ~RTR" Data Frame ID (~RTR)
IDEither ID: Remote or Data Frame ID
IDRemote ID & RTR: Remote Frame ID (RTR)
AllErrors All Errors: All Errors
Overload Overload: Overload Frame
AckError Ack Error: Acknowledge Error

CAN Id specification is set by the TriggerPatternIDType properties.
CAN Data specification is set by the TriggerPatternData property.
CAN Data Length Code is set by the TriggerPatternDataLength property.
HD3 series oscilloscopes models HD304MSO and HD302MSO does not support FDData and FDMSignal options.
property trigger_pattern_data¶

Specifies the CAN data pattern resource according to the string parameter. This pattern, along with the data length (set by the TriggerPatternDataLength property), control the data pattern searched for in each CAN message.

Access:

ReadWrite

Type:

str

Remarks:

• The TriggerPatternData property can be specified in one of the following string formats:
  • "nn...n", where n: {0 | 1 | X | $}
  • "0xnn...n", where n: {0,..,9 | A,..,F | X | $}

• If the string parameter starts with "0x", it is a hexadecimal string made up of hexadecimal and X (don't care) characters; otherwise, it is a binary string made up of 0, 1, and X (don't care) characters.
• If more bits are sent than specified by the TriggerPatternDataLength property, the most significant bits will be truncated.
• If the data length is changed after the string is programmed, the added or deleted bits will be added to or deleted from the least significant bits.
property trigger_pattern_data_length¶

Sets and gets the number of 8-bit bytes in the current CAN data pattern lenegth setting.

Access:

ReadWrite

Type:

int

Remarks:
The number of bytes in the string can be anywhere from 1 bytes to 8 bytes (64 bits). The value for these bytes is set by the TriggerPatternData property.
property trigger_pattern_id¶

Sets and gets the CAN identifier pattern resource according to the string parameter. This pattern, along with the identifier mode (set by the TriggerPatternIDType property), control the identifier pattern searched for in each CAN message.

Access:

ReadWrite

Type:

str

Remarks:

• The TriggerPatternID property can be specified in one of the following string formats:
  • "nn...n", where n: {0 | 1 | X | $}
  • "0xnn...n", where n: {0,..,9 | A,..,F | X | $}

• If the string parameter starts with "0x", it is a hexadecimal string made up of hexadecimal and X (don't care) characters; otherwise, it is a binary string made up of 0, 1, and X (don't care) characters.
• If more bits are sent than allowed (11 bits in standard mode, 29 bits in extended mode) by the TriggerPatternIDType property, the most significant bits will be truncated.
• If the ID mode is changed after the string is programmed, the added or deleted bits will be added to or deleted from the most significant bits.
