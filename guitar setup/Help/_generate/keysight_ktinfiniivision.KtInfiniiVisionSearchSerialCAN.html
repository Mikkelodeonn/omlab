KtInfiniiVisionSearchSerialCAN¶

Access interface members using: driver.search.serial.can
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSearchSerialCAN¶

KtInfiniiVisionSearchSerialCAN interface.

property mode¶

Sets and gets the type of CAN information to find in the Lister display.

Access:

ReadWrite

Type:

SearchCANMode

Remarks:
The Type property can be set to one of the following values:
  • Data: searches for CAN Data frames matching the specified ID, Data, and the DLC (Data length code)
  • IDData: searches for CAN frames matching the specified ID of a Data frame
  • IDEither: searches for the specified ID, regardless if it is a Remote frame or a Data frame
  • IDRemote: searches for CAN frames matching the specified ID of a Remote frame
  • AllErrors: searches for CAN active error frames and unknown bus conditions
  • Overload: searches for CAN overload frames
  • Error: searches for CAN Error frame
  • AckError: searches for CAN Acknowledge Error frame
  • FormError: searches for CAN Form Error frame
  • StuffError: searches for CAN Stuff Error frame
  • CRCError: searches for CAN CRC Error frame
  • CANTypeMsgSig: searches for CAN symbolic message and signal value
  • CANTypeMsg: searches for CAN symbolic message
property pattern_data¶

Sets and gets the data value when searching for Data Frame ID and Data. The data value is a string in the format: “0xnn…n” where n: {0,..,9|A,..,F|X} for hexadecimal.

Access:

ReadWrite

Type:

str

Remarks:
The length of the data value is specified using the SerachSerialCANPatternDataLength property.
property pattern_data_length¶

Sets and gets the length of the data value when searching for Data Frame ID and Data. Permissible values are: 1 to 8.

Access:

ReadWrite

Type:

int

Remarks:
The data value is specified using the SearchSerialCANPatternIDType property.
property pattern_id¶

Sets and gets the ID value when searching for a CAN event. The ID value is a string in the format: “0xnn…n” where n: {0,..,9|A,..,F|X} for hexadecimal.

Access:

ReadWrite

Type:

str

Remarks:
The ID value can be a standard ID or an extended ID, depending on the value of the SearchSerialCANPatternIDType property.
property pattern_id_type¶

Specifies whether a standard ID value or an extended ID value is used when searching for a CAN event.

Access:

ReadWrite

Type:

SearchCANPatternIDType

Remarks:

•The PatternIDType property can be set to one of the following values:

• Standard: specifies that a standard ID value is used for searching
• Extended: specifies that an extended ID value is used for searching

• The ID value is specified using the PatternID property.
property symbolic_message¶

Sets and gets the specific message when CAN symbolic data has been loaded (recalled) into the oscilloscope and the CAN serial search mode is set to Message or Message and Signal.

Access:

ReadWrite

Type:

str

property symbolic_signal¶

Sets and gets the specific signal when CAN symbolic data has been loaded (recalled) into the oscilloscope and the CAN serial search mode is set to Message and Signal.

Access:

ReadWrite

Type:

str

property symbolic_value¶

Sets and gets the specific signal value when CAN symbolic data has been loaded (recalled) into the oscilloscope and the CAN serial search mode is set to Message and Signal.

Access:

ReadWrite

Type:

float

Remarks:
Encoded signal values are not supported in the remote interface (even though they can be used in the front panel graphical interface).
