KtInfiniiVisionExternal¶

Access interface members using: driver.external
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionExternal¶

KtInfiniiVisionExternal interface.

property bw_limit¶

The current setting of the low-pass filter

Access:

ReadWrite

Type:

bool

property enabled¶

Enables or disables the external trigger input display.

Access:

ReadWrite

Type:

bool

Remarks:
In DSOX1204A/G oscilloscopes, the external trigger input setting can be set to Of only.
property label¶

The label for the external trigger digital waveform. Setting a label for the external waveform also adds the name to the label list in non-volatile memory (replacing the oldest label in the list).

Access:

ReadWrite

Type:

str

Remarks:
Label strings are 10 characters or less, and may contain any commonly used ASCII characters. Labels with more than 10 characters are truncated to 10 characters. Lower case characters are converted to upper case.
property probe_attenuation¶

Scaling factor by which the probe attached to the external trigger attenuates the input.

Access:

ReadWrite

Type:

float

Remarks:
• The probe attenuation factor may be from 0.1 to 1000. For example, with a 10:1 probe, the value is 10.0.
• This property does not change the actual input sensitivity of the oscilloscope.
• But reference constants for scaling the display factors and for setting trigger levels are changed.
• If an AutoProbe probe is connected to the oscilloscope, the attenuation value cannot be changed from the sensed value.
• Attempting to set the oscilloscope to an attenuation value other than the sensed value produces an error.
property range¶

Full-scale range. If the probe attenuation is changed, the range value is multiplied by the probe attenuation factor.

Access:

ReadWrite

Type:

float

Remarks:
• When entering the range as input, suffix { V | mV } can be used.
• When using DSOX1000, DSOX1200, X4000 or X6000 Series oscilloscopes, the range is either 1.6 V or 8 V when you are using a 1:1 probe.
• When using EDUX1000, X2000, X3000, T3000, M9240X or P9240X Series oscilloscopes, the range can only be set to 8 V when you are using a 1:1 probe.
• If the probe attenuation is changed, the range value is multiplied by the probe attenuation factor.
property threshold¶

The external trigger input threshold (trigger) voltage level in volts.

Access:

ReadWrite

Type:

float

Remarks:
While specifying the input value of external trigger, suffix { V | mV } can be used.
property units¶

The measurement units for the probe connected to the external trigger input.

Access:

ReadWrite

Type:

ExternalProbeUnits

Remarks:
• Voltage to be selected for voltage probe.
• Ampere for current probe.
• Measurement results, channel sensitivity, and trigger level will reflect the measurement units you select.
property vertical_position¶

The external trigger input waveform’s vertical position on the oscilloscope display.

Access:

ReadWrite

Type:

float

Remarks:
When the external trigger input's waveform is displayed, a cyan digital waveform, based on the threshold voltage level, appears on the oscilloscope display. This waveform is one division tall, and the base of the waveform can be positioned from -3.5 divisions to 2.5 divisions.
