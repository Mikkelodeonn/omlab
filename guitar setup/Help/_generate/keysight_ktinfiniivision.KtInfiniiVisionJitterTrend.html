configure(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionJitterTrend) → None¶

Auto-configures and turns on the jitter measurement trend for the selected measurement.

Returns:

None

Remarks:
  • Prior to using this method, enable the jitter analysis using the :class:`KtInfiniiVisionJitter`.AnalysisEnabled property.
  • Configure and add the measurement using the :class:`KtInfiniiVisionJitter`.ConfigureJitterMeasurement method.

    Remarks:

    • property smoothing_points¶

    The number of smoothing points to use when jitter trend smoothing is enabled using ConfigureSmoothing method.

    Access:

    ReadWrite

    Type:

    int

    Remarks:
  • The input value can be an odd number of points, from 3 up to half of the measurement record or precision analysis record.
  • Preset value is 5.
