KtInfiniiVisionSerialBusSPI¶

Access interface members using: driver.serial_buses[<name_or_index>].spi
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSerialBusSPI¶

KtInfiniiVisionSerialBusSPI interface.

property bit_order¶

Sets and gets the bit order, most significant bit first (MSB) or least significant bit first (LSB), used when displaying data in the serial decode waveform and in the Lister.

Access:

ReadWrite

Type:

SerialBusSPIBitOrder

Remarks:
The BitOrder property can be set to one of the following values:
  • LSBF: Least Significant Bit First
  • MSBF: Most Significant Bit First
property clock_slope¶

Sets and gets the rising edge (Positive) or falling edge (Negative) of the SPI clock source that will clock in the data.

Access:

ReadWrite

Type:

SerialBusSPIClockSlope

Remarks:
The ClockSource property can be set to one of the following values:
  • Negative: Falling edge
  • Positive: Rising edge
property clock_source¶

Sets and gets the source for the SPI serial clock.

Access:

ReadWrite

Type:

str

Remarks:

• The ClockSource property can be specified in one the following string formats:

• For DSO Models:

• "Channel<n>", where <n> can be from 1 to the number of analog channels.

• For MSO Models:

• "Channel<n>", where <n> can be from 1 to the number of analog channels.
• "DigitalChannel<d>", where <d> can be from 0 to the number of digital channels minus 1. For X2000 series DigitalChannels are not supported as source.
property clock_timeout¶

Sets and gets the SPI signal clock timeout resource in seconds from 100 ns to 10 s when the Framing property is set to SerialBusSPIFramingTimeout. The timer is used to frame a signal by a clock timeout.

Access:

ReadWrite

Type:

float

property delay¶

Sets and gets the number of bits to ignore (delay) before decoding the MISO stream.

Access:

ReadWrite

Type:

int

Remarks:
Range : 2 to 63.

property framing¶

property trigger_pattern_data¶

Sets and gets the SPI data pattern resource according to the string parameter. This pattern, along with the data width, control the data pattern searched for in the data stream.

Access:

ReadWrite

Type:

str

Remarks:

• The TriggerPatternMISOData can be specified in one of the following string formats:

• "nn...n", where n: {0 | 1 | X | $}
• "0xnn...n", where n: {0,..,9 | A,..,F | X | $}

• If the string parameter starts with "0x", it is a hexadecimal string made up of hexadecimal and X (don't care) characters; otherwise, it is a binary string made up of 0, 1, and X (don't care) characters.
• The SerialBusSPITriggerPatternWidth property should be set before this.

property trigger_type¶

Sets and gets whether the SPI trigger will be on the MOSI data or the MISO data.

Access:

ReadWrite

Type:

SerialBusSPITriggerType

Remarks:

• The TriggerType property can be set to one of the following values:

• MOSI
• MISO

• When triggering on MOSI data , the data value is specified by the SerialBusSPITriggerPatternMOSIWidth properties.
• When triggering on MISO data , the data value is specified by the SerialBusSPITriggerPatternMISOWidth properties.
