KtInfiniiVisionTriggerWidth¶

Access interface members using: driver.trigger.width
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionTriggerWidth¶

KtInfiniiVisionTriggerWidth interface.

property condition¶

Sets and gets the trigger duration qualifier. Whether a pulse within or outside the high and low thresholds triggers the oscilloscope.

Access:

ReadWrite

Type:

TriggerWidthCondition

Remarks:

• Entered: when the pattern is entered.
• Lessthan: when the pattern is present for less than a time value.
• Greaterthan: when the pattern is present for greater than a time value. The trigger occurs when the pattern exits (not when the Greaterthan time value is exceeded).
• Timeeout: when the pattern is present for greater than a time value. In this case, the trigger occurs when the Greaterthan time value is exceeded (not when the pattern exits).
• InRange: when the pattern is present for a time within a range of values.
• OutRange: when the pattern is present for a time outside of range of values.
• Pattern durations are evaluated using a timer. The timer starts on the last edge that makes the pattern (logical AND) true. Except when the Timeout qualifier is selected, the trigger occurs on the first edge that makes the pattern false, provided the time qualifier criteria has been met.
configure(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionTriggerWidth, source: str, level: float, threshold_low: float, threshold_high: float, polarity: keysight_ktinfiniivision.keysight_ktinfiniivision.TriggerWidthPolarity, condition: keysight_ktinfiniivision.keysight_ktinfiniivision.TriggerWidthCondition) → None¶

Configures the width trigger.

Parameters:

  • source (str) – The source the trigger monitors for a trigger event.

  • level (float) – The voltage threshold for the trigger sub-system.

  • threshold_low (float) – The low width threshold time in seconds.

  • threshold_high (float) – The high width threshold time in seconds.

  • polarity (TriggerWidthPolarity) – The polarity of the pulse that triggers the oscilloscope.

  • condition (TriggerWidthCondition) – Whether a pulse within or outside the high and low thresholds triggers the oscilloscope.

Returns:

None
