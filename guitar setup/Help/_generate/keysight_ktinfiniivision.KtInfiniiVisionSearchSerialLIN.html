KtInfiniiVisionSearchSerialLIN¶

Access interface members using: driver.search.serial.lin
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSearchSerialLIN¶

KtInfiniiVisionSearchSerialLIN interface.

property id¶

Sets and gets the frame ID value when searching for LIN events

Access:

ReadWrite

Type:

str

Remarks:
  • The ID property can be specified in one of the following string formats:
    • "n" where n: 7-bit integer in signed decimal
    • "#Hnn" where n: {0,..,9 | A,..,F}
    • "#Bnn" where n: {0 | 1 }
    • "0xnn" where n: {0,..,9 | A,..,F}
  • Valid range of values are: 0 to 63 or 0x00 to 0x3f.
    • property mode¶

    Selects the type of LIN information to find in the Lister display

    Access:

    ReadWrite

    Type:

    SearchLINMode

    Remarks:
  • The Type property can be set to one of the following values:
    • ID: searches for a frame ID
    • Data: searches for a frame ID and data
    • Error: searches for errors
    • Frame: searches for symbolic frames
    • FrameSig: searches for symbolic frames and signal values
  • Frame IDs are specified using the SearchSerialLINID property.
  • Data values are specified using the SearchSerialLINPatternData property.
    • property pattern_data¶

    Sets and gets the data value when searching for LIN events.

    Access:

    ReadWrite

    Type:

    str

    Remarks:
  • The PatternData property can be specified in one of the following string formats:
    • "n" where n: 32-bit integer in signed decimal
    • "0xnn...n" where n: {0,..,9 | A,..,F | X}

  • The length of the data value entered is specified using the SearchSerialLINPatternDataLength property.
    • property pattern_data_length¶

    Sets and gets the length (from 1 to 8) of the data value when searching for LIN events. Valid values are from 1 to 8.

    Access:

    ReadWrite

    Type:

    int

    Remarks:
    The data value is specified using the SearchSerialLINPatternData property.
    property pattern_format¶

    Sets and gets the number base for data value.

    Access:

    ReadWrite

    Type:

    SearchLINPatternFormat

    Remarks:
    The pattern format can be set to one of the following values:
    • Hexadecimal: the hexadecimal base for data
    • Decimal: the decimal base for data
    property symbolic_frame¶

    Sets and gets the specific message when LIN serial search mode is set to Frame.

    Access:

    ReadWrite

    Type:

    str

    Remarks:
    It specifies the signal value to search for when LIN symbolic data has been loaded (recalled) into the oscilloscope and the LIN serial search mode is set.
    property symbolic_signal¶

    Sets and gets the specific signal when LIN serial search mode is set to Frame and Signal.

    Access:

    ReadWrite

    Type:

    str

    Remarks:
    It specifies the signal value to search for when LIN symbolic data has been loaded (recalled) into the oscilloscope and the LIN serial search mode is set.
    property symbolic_value¶

    Sets and gets the specific signal value when LIN serial search mode is set to Frame and Signal.

    Access:

    ReadWrite

    Type:

    float

    Remarks:

    • It specifies the signal value to search for when LIN symbolic data has been loaded (recalled) into the oscilloscope and the LIN serial search mode is set.
    • Encoded signal values are not supported in the remote interface (even though they can be used in the front panel graphical interface).
