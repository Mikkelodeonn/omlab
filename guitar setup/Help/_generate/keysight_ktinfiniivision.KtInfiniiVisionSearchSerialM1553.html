KtInfiniiVisionSearchSerialM1553¶

Access interface members using: driver.search.serial.m1553
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSearchSerialM1553¶

KtInfiniiVisionSearchSerialM1553 interface.

property mode¶

Sets and gets the type of MIL-STD-1553 information to find in the Lister display.

Access:

ReadWrite

Type:

SearchSerialM1553Mode

Remarks:
The Mode property can be set to one of the following values:
  • DataStart: Finds the start of a data word (at the end of a valid Data Sync pulse).
  • CommandStart: Finds the start of a Command/Status word (at the end of a valid C/S Sync pulse).
  • RTA: Finds the Command/Status Word whose RTA matches the specified value. The value is specified in hex.
  • RTA11: Finds the RTA and the remaining 11 bits that match the specified criteria. The RTA can be specified as a hex value and the remaining bits are specified as 1 or 0.
  • ParityError: Finds (odd) parity bits that are incorrect for the data in the word.
  • SyncError: Finds invalid sync pulses.
  • ManchesterError: Finds Manchester encoding errors.
property pattern_data¶

Sets and gets the additional 11 bits when searching for the MIL-STD-1553 Remote Terminal Address + 11 Bits.

Access:

ReadWrite

Type:

str

Remarks:
The PatternData property can be specified in one of the following formats: "nn...n", where n: {0 | 1 | X}
property remote_terminal_address¶

Sets and gets the Remote Terminal Address (RTA) value when searching for MIL-STD-1553 events.

Access:

ReadWrite

Type:

str

Remarks:
The RTA property can be specified in one of the following formats:
  • "n", where n is an integer from 0-31
  • "#Hnn", where n: {0,..,9 | A,..,F}
  • "0xnn", where n: {0,..,9 | A,..,F}
