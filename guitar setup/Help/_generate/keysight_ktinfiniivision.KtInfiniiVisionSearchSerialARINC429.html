KtInfiniiVisionSearchSerialARINC429¶

Access interface members using: driver.search.serial.arinc429
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSearchSerialARINC429¶

KtInfiniiVisionSearchSerialARINC429 interface.

property label¶

Sets and gets the ARINC 429 label value when labels are used in the selected search mode.

Access:

ReadWrite

Type:

str

Remarks:

• The Label property is specified in of the following formats:

• "n", where n: 8-bit integer in decimal format
• "#Hnn", where n: { 0,..,9 | A,..,F }
• "#Qnnn", where n: { 0,..,7 }
• "0xnn", where n: { 0,..,9 | A,..,F }

• The return value for this property is in decimal format.
property mode¶

Specifies the type of ARINC 429 information to find in the Lister display.

Access:

ReadWrite

Type:

SearchSerialARINC429Mode

Remarks:
The Mode property can be set to one of the following values:
  • Label: Specifies the Label search mode.
  • LabelBits: Specifies the Label + Bits search mode.
  • ParityError: Specifies the Parity Error search mode.
  • WordError: Specifies the Word Error search mode.
  • GapError: Specifies the Gap Error search mode.
  • WordOrGapError: Specifies the Word or Gap Error search mode.
  • AllErrors: Specifies All Errors search mode.
property pattern_data¶

Sets and gets the ARINC 429 data pattern resource according to the string parameter. This pattern controls the data pattern searched for in each ARINC 429 word.

Access:

ReadWrite

Type:

str

Remarks:

• The PatternData property is specified in the following format where n: { 0 | 1 }
• The pattern string will be truncated on the left-hand-side if the length exceeds the pattern length of the particular ARINC format.
• Pattern length for the different formats:

• LDSDI:

• Label: 8 bits.
• SDI: 2 bits.
• Data: 19 bits.
• SSM: 2 bits.

• LDSSM:

• Label: 8 bits.
• Data: 21 bits.
• SSM: 2 bits.

• LData:

• Label: 8 bits.
• Data: 23 bits.
property pattern_sdi¶

Sets and gets the ARINC 429 two-bit SDI pattern resource according to the string parameter. This pattern controls the SDI pattern searched for in each ARINC 429 word.

Access:

ReadWrite

Type:

str

Remarks:

• The specified SSM is only used if the SerialBusARINC429DisplayFormat property i set to the SDI field.
• The PatternSSM property is specified in the format: "nn", where n: { 0 | 1 }
property pattern_ssm¶

Sets and gets the ARINC 429 two-bit SSM pattern resource according to the string parameter. This pattern controls the SSM pattern searched for in each ARINC 429 word.

Access:

ReadWrite

Type:

str

Remarks:

• The specified SSM is only used if the SerialBusARINC429DisplayFormat property i set to the SSM field.
• The PatternSSM property is specified in the format: "nn", where n: { 0 | 1 }
