KtInfiniiVisionSearchSerialI2S¶

Access interface members using: driver.search.serial.i2_s
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSearchSerialI2S¶

KtInfiniiVisionSearchSerialI2S interface.

property audio_channel¶

Specifies the channel on which to search for I2S events: right, left, or either channel.

Access:

ReadWrite

Type:

SearchI2SAudioChannel

Remarks:
The AudioChannel property can be set to one of the following values:
  • Right: for the right audio channel
  • Left: for the left audio channel
  • Either: for either left or right audio channel
get_range(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionSearchSerialI2S) → Tuple[int, int]¶

Gets the data value range when searching for I2S events.

Returns:

A tuple containing:

  • lowerLimit (int) : The lower limit for the data value range when searching for I2S events.

  • upperLimit (int) : The upper limit for the data value range when searching for I2S events.

Type:

tuple[int, int]

property mode¶

Sets and gets the type of I2S information to find in the Lister display.

Access:

ReadWrite

Type:

SearchI2SMode

Remarks:

• The Type property can be set to one of the following values:

• Equal: searches for the specified audio channel's data word when it equals the specified word.
• NotEqual: searches for any word other than the specified word.
• LessThan: searches for channel data words less than the specified value.
• GreaterThan: searches for channel data words greater than the specified value.
• InRange: searches for channel data words in the range.
• OutRange: searches for channel data words outside the range.

• Data word values are specified using the SearchSerialI2SPatternData property.
• Values ranges are specified using the SearchSerialI2SSetRange and SearchSerialI2SGetRange methods.
property pattern_data¶

Sets and gets the data word value when searching for I2S events.

Access:

ReadWrite

Type:

str

Remarks:
The data word value is a string, which can be specified in one of the following string formats:
  • "n" where n: 32-bit integer in signed decimal
  • "#Bnn...n" where n: {0 | 1 | X}
  • "0xnn...n" where n: {0,..,9 | A,..,F | X}
property pattern_format¶

Sets and gets the number base for data value.

Access:

ReadWrite

Type:

SearchI2SPatternFormat

Remarks:
The pattern format can be set to one of the following values:
  • Binary: the binary base for data
  • Hexadecimal: the hexadecimal base for data
  • Decimal: the decimal base for data
set_range(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionSearchSerialI2S, lower_limit: str, upper_limit: str) → None¶

Sets the data value range when searching for I2S events.

Parameters:

  • lower_limit (str) – The lower limit for the data value range when searching for I2S events.

  • upper_limit (str) – The upper limit for the data value range when searching for I2S events.

Returns:

None

Remarks:

  • The LowerLimit and UpperLimit parameters of the data value range can be specified in one of the following string formats:
    • "n" where n: 32-bit integer in signed decimal
    • "#Bnn...n" where n: {0 | 1 }
    • "0xnn...n" where n: {0,..,9 | A,..,F}

  • This method is only used when SearchSerialI2SMode is set to InRange or OutRange.

  • User may enter the parameters in any order. The smaller value becomes LowerLimit and the larger value becomes UpperLimit.
