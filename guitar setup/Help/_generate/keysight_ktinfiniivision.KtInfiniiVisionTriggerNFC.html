KtInfiniiVisionTriggerNFC¶

Access interface members using: driver.trigger.nfc
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionTriggerNFC¶

KtInfiniiVisionTriggerNFC interface.

property arm_event¶

Sets and gets the arm event when TriggerEvent is ATrigger(Arm event).

Access:

ReadWrite

Type:

TriggerNFCArmEvent

Remarks:
  • Valid arm event depend on the signaling technology.
  • When a TriggerEvent other than ATRigger (Arm and Trigger) is selected, the arm event is NONE.
    • property arm_trigger_time¶

    Returns the time between the arm and the trigger when the ATRigger (Arm and Trigger) TriggerEvent is selected.

    Access:

    ReadOnly

    Type:

    float

    property input_waveform_source¶

    Sets and gets the input waveform source for the NFC trigger.

    Access:

    ReadWrite

    Type:

    str

    Remarks:
    Source - Channel{1|2|..|max analog channels}
    property is_timeout¶

    Returns whether the timeout occurred.

    Access:

    ReadOnly

    Type:

    float

    Remarks:
  • With the ATrigger (Arm and Trigger) TriggerEvent, if the second event does not occur within the timeout period, the oscilloscope triggers when the timeout period expires.
  • A return value of 1 says the desired trigger event did not occur within the specified time after the arm event.
  • A return value of 0 says the desired trigger event occurred before the timeout.
    • property reverese_polarity_enabled¶

    Enables or disables the oscilloscope to trigger on signals with “reverse” polarity.

    Access:

    ReadWrite

    Type:

    bool

    Remarks:
    When OFF, the oscilloscope will trigger on signals with "obverse" polarity.
    property standard¶

    Sets and gets the signaling technology used by the input signal.

    Access:

    ReadWrite

    Type:

    TriggerNFCStandard

    Remarks:
  • A or A106 — NFC-A standard, 106 kbits/s.
  • B or B106 — NFC-A standard, 106 kbits/s.
  • F212 — NFC-F standard, 212 kbits/s.
  • F424 — NFC-F standard, 424 kbits/s.
    • property timeout_enabled¶

    Sets and gets the timeout period enable.

    Access:

    ReadWrite

    Type:

    bool

    Remarks:
  • Currently, ON is the only valid setting.
  • With the ATrigger (Arm and Trigger) TriggerEvent, if the second event does not occur within the timeout period, the oscilloscope triggers when the timeout period expires.
    • property timeout_period¶

    Sets and gets the timeout period.

    Access:

    ReadWrite

    Type:

    float

    Remarks:
    With the ATrigger (Arm and Trigger) TriggerEvent, if the second event does not occur within the timeout period, the oscilloscope triggers when the timeout period expires.
