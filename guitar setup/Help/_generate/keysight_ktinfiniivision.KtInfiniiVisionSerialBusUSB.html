KtInfiniiVisionSerialBusUSB¶

Access interface members using: driver.serial_buses[<name_or_index>].usb
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSerialBusUSB¶

KtInfiniiVisionSerialBusUSB interface.

property address¶

Sets and gets the 7-bit Address portion of the trigger for the selected bus, in binary or hex.

Access:

ReadWrite

Type:

str

Remarks:
• Its value can be in binary format or in hexadecimal format.

• "nn" where n = {0 | 1 | X}
• "0xn" where n ::= {0,..,9 | A,..,F | X | $}

property d_minus_source¶

Sets and gets which signal is used as the USB D- source for the selected bus.

Access:

ReadWrite

Type:

str

Remarks:

• The DMinusSource can be specified in one the following string formats:

• For DSO Models:

• "Channel<n>", where <n> can be from 1 to the number of analog channels.

• For MSO Models:

• "Channel<n>", where <n> can be from 1 to the number of analog channels.
• "DigitalChannel<d>", where <d> can be from 0 to the number of digital channels minus 1.

• On 4-channel oscilloscopes, users should use different channel pairs for the D+ and D- signals. This provides the maximum sample rate. (Channels 1 and 2 are one pair and channels 3 and 4 are the other pair.)
