KtInfiniiVisionTriggerGlitch¶

Access interface members using: driver.trigger.glitch
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionTriggerGlitch¶

KtInfiniiVisionTriggerGlitch interface.

property condition¶

Sets and gets the mode of operation of the glitch pulse width trigger whether it glitches less than, greater than or within a range of the specified time duration.

Access:

ReadWrite

Type:

TriggerGlitchCondition

configure(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionTriggerGlitch, source: str, level: float, width: float, polarity: keysight_ktinfiniivision.keysight_ktinfiniivision.TriggerGlitchPolarity, condition: keysight_ktinfiniivision.keysight_ktinfiniivision.TriggerGlitchCondition) → None¶

Configures the glitch trigger Source, Level, Width, Polarity, and Condition. A glitch trigger occurs when the edge of a pulse that matches the Width and Polarity crosses the specified Level (in Volts).

Parameters:

  • source (str) – Specifies the trigger source. This value sets the Trigger Source property.

  • level (float) – Specifies the trigger level. This value sets the Trigger Level property.

  • width (float) – Specifies the glitch triggering glitch width in seconds.

  • polarity (TriggerGlitchPolarity) – Specifies the glitch polarity. This value sets the Glitch Polarity property.

  • condition (TriggerGlitchCondition) – Specifies the glitch condition. This value sets the Glitch Condition property.

Returns:

None

Remarks:
Note: TriggerType should be set to Glitch before executing this method.

set_range(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionTriggerGlitch, lower_limit: float, upper_limit: float) → None¶

Sets the pulse width duration for the selected source.

Parameters:

  • lower_limit (float) – LowerLimit. Permissible values are from 10 ns to 9.99 seconds

  • upper_limit (float) – UpperLimit. Permissible values are from 15 ns to 10 seconds

Returns:

None

Remarks:
User can enter the parameters in any order, the smaller value becomes the greater than time and the larger value becomes the less than time.
property source¶

Sets and gets the pulse width source.

Access:

ReadWrite

Type:

str

Remarks:

• The parameter <source> can be specified in one of the following string formats:
• Channel<n>, where n: 1 to the number of available analog channels.
• Digital<d>, where d: 1 to the number of available digital channels - 1.

• If all channels are off, then "None" is returned.
