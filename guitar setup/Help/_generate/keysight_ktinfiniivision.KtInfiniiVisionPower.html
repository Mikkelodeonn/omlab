apply_analysis(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionPower, analysis_type: keysight_ktinfiniivision.keysight_ktinfiniivision.PowerAnalysisType) → None¶

Performs the specified power analysis.

Parameters:

analysis_type (PowerAnalysisType) – The power analysis type.

Returns:

None

Remarks:
  • Power Analysis type:
      CLResponse: Control loop response (Bode) analysis
      Efficiency: Efficiency power analysis
      Harmonics: Current harmonics analysis
      InRush: Inrush current analysis
      Modulation: Modulation analysis
      OnOff: Turn on/off analysis
      PSRR: Power supply rejection ratio (PSRR) analysis
      Quality: Power quality analysis
      Ripple: Output ripple analysis
      Slew: Slew rate analysis
      Switch: Switching loss analysis
      Transient: applies the transient analysis using theinitial current and new current settings.
    • auto_deskew(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionPower) → None¶

    Launches the auto deskew process on the oscilloscope.

    Returns:

    None

    Remarks:

    • Prerequisites:

    • Demagnetize and zero-adjust the current probe.
    • Make connections to the U1880A deskew fixture.
    • Make sure the voltage probe and current probe channels are specified appropriately.
  • Use the lowest attenuation setting on the high voltage differential probes whenever possible because the voltage levels on the deskew fixture are very small.
  • Using a higher attenuation setting may yield inaccurate skew values (and affect the measurements made) because the noise level is magnified as well.
  • The deskew values are saved in the oscilloscope until a factory default or secure erase is performed. The next time user run the Power Application, user can use the saved deskew values or perform the deskew again.
  • AutoDeskew is needed when part of the test setup changes (for example, a different probe, different oscilloscope channel, etc.) or when the ambient temperature has changed.

    property quality_measurement_type¶

    Sets and gets the type of measurement to make in the power quality analysis.

    Access:

    ReadWrite

    Type:

    PowerQualityType

    Remarks:

    • Power Factor: Ratio of the actual power to the apparent power
    • Real (Actual) Power: The portion of power flow that, averaged over acomplete cycle of the AC waveform, results in net transfer of energy in one direction.
    • Apparent Power: The portion of power flow due to stored energy, which returns to the source in each cycle.
    • Reacitve Power: The difference between apparent power and realpower due to reactance.
    • Crest Factor: Crest factor is the ratio between the instantaneous peak current/voltage required by the load and the RMS current/voltage (RMS stands for Root Mean Square, which is a type of average).
    • Phase Angle: In the power triangle (the right triangle where apparent_power^2 = real_power^2 + reactive_power^2), phase angle is the angle between the apparent power and the real power, indicating the amount of reactive power.
