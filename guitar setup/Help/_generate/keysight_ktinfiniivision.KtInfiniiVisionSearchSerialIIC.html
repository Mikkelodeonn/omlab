KtInfiniiVisionSearchSerialIIC¶

Access interface members using: driver.search.serial.iic
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSearchSerialIIC¶

KtInfiniiVisionSearchSerialIIC interface.

property address¶

Sets and gets the address values when searching for IIC events.

Access:

ReadWrite

Type:

str

Remarks:
  • The Address property can be specified in one of the following string formats:
    • "n" where n is an integer
    • "0xnn" where n: {0,..,9 | A,..,F}

  • The returned value is always in an integer string format
    • property condition¶

    Sets and gets the data value qualifier used when searching for IIC EEPROM data read events.

    Access:

    ReadWrite

    Type:

    SearchIICCondition

    Remarks:
    The Condition property can be set to one of the following values:
    • Equal
    • NotEqual
    • LessThan
    • GreaterThan
    property mode¶

    Sets and gets the type of IIC information to find in the Lister display.

    Access:

    ReadWrite

    Type:

    SearchIICMode

    Remarks:
  • The Type property can be set to one of the following values:
    • Read7: searches for 7-bit address frames containing Start:Address7:Read:Ack:Data
    • Write7: searches for 7-bit address frames containing Start:Address7:Write:Ack:Data
    • MissingAcknowledge: searches for missing acknowledge events
    • NoAcknowledge: searches for address with no acknowledge events
    • R7Data2: searches for 7-bit address frames containing Start:Address7:Read:Ack:Data:Ack:Data2
    • W7Data2: searches for 7-bit address frames containing Start:Address7:Write:Ack:Data:Ack:Data2
    • Restart: searches for another start condition occurring before a stop condition
    • ReadEprom: searches for EEPROM data reads
    • REPRom — searches for EEPROM data reads

  • When searching for events containing addresses, address values are specified using the Address property.

    • HD3 series oscilloscopes models HD302MSO and HD304MSO does not support ReadEprom option.
  • When searching for events containing data, data values are specified using the SearchSerialIICPatternData2 properties.
    • property pattern_data¶

    Sets and gets the data values when searching for IIC events.

    Access:

    ReadWrite

    Type:

    str

    Remarks:

  • The PatternData property can be specified in one of the following string formats:
    • "n" where n is an integer
    • "0xnn" where n: {0,..,9 | A,..,F}


  • When searching for IIC EEPROM data read events, user can specify the data value qualifier using the Condition property.

    • • To set don't care values, use the integer -1.
    property pattern_data2¶

    Sets and gets the second data value when searching for IIC events with two data values.

    Access:

    ReadWrite

    Type:

    str

    Remarks:

    • The PatternData2 property can be specified in one of the following string formats:
    • "n" where n is an integer
    • "0xnn" where n: {0,..,9 | A,..,F}

    • To set don't care values, use the integer -1.
