KtInfiniiVisionCursors¶

Access interface members using: driver.cursors
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionCursors¶

KtInfiniiVisionCursors interface.

property mode¶

Sets and gets the cursors mode.

Access:

ReadWrite

Type:

CursorsMode

Remarks:
The cursor modes are:
  • Off: removes the cursor information from the display
  • Manual: enables manual placement of the X and Y cursors. If the front-panel cursors are off, or are set to the front-panel Hex or Binary mode, setting this property Manual will put the cursors in the front-panel Normal mode.
  • Measurement: cursors track the most recent measurement
  • Waveform: the Y1 cursor tracks the voltage value at the X1 cursor of the waveform specified by the X1Y1source, and the Y2 cursor does the same for the X2 cursor and its X2Y2source.
  • Binary: logic levels of displayed waveforms at the current X1 and X2 cursor positions are displayed in the Cursor sidebar dialog in binary.
  • Hexadecimal: logic levels of displayed waveforms at the current X1 and X2 cursor positions are displayed in the Cursor sidebar dialog in hexadecimal.
use_cursor_position(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionCursors, cursors_type: keysight_ktinfiniivision.keysight_ktinfiniivision.CursorPosition) → None¶

Sets Positions of X1,X2 & Y1,Y2 depending upon the chosen values of XUnits & YUnits.

Parameters:

cursors_type (CursorPosition) – Cursors Type

Returns:

None

Remarks:
• For X1 Position & X2 Position, if the units chosen are:

• Degrees: The value of X1 will be 0 & X2 will be 360.
• Percentage: The value of X1 will be 0 & X2 will be 100.
• For Y1 Position & Y2 Position, if the units chosen are:

• Base: It is used for making measurements in the units associated with the cursors source.
• Percentage: The value of Y1 will be 0 & Y2 will be 100.

• Changing X/Y Units affects the input and output values of the MakerY1Position, MarkerY2Position & MarkerYDelta properties too.

property x1_position¶

Specifies the X1 cursor position.

Access:

ReadWrite

Type:

float

Remarks:
• With X1 position as input one of <suffix> from { s | ms | us | ns | ps | Hz | kHz | MHz } can be selected.
• Set MarkerMode is to Manual, if not set to Waveform.
• Sets the X2 cursor position to the specified value.
• If the front-panel cursors are off, the marker position values are not defined.
• Make sure to set MarkerMode Manual or Waveform to put the cursors in the front-panel.
property x1_y1_source¶

The source for the cursors. The channel you specify must be enabled for cursors to be displayed.

Access:

ReadWrite

Type:

str

Remarks:
• The parameter < source > can be specified in one of the following string formats:
• Channel<n>, where n: 1 to the number of available analog channels.
• Function<m>, where m: 1 to the number of available math functions valid for T3000, X4000, X6000, M9240X & P9240X Series Oscilloscopes. Where as "Function" only valid for X1000, X1200, X2000 & X3000 Series Oscilloscopes.
• Math<m>, where m: 1 to the number of available math functions valid for T3000, X4000, X6000, M9240X & P9240X Series Oscilloscopes. Where as "Math" only valid for X1000, X1200, X2000 & X3000 Series Oscilloscopes.
• Wmemory<r>, where r: 1 to the number of available reference waveforms for T3000, X4000, X6000, M9240X & P9240X Series Oscilloscopes. And r : { 1 | 2 } for X1000, X1200, X2000 & X3000 Series Oscilloscopes.
• FFT, valid only for T3000, M9240X & P9240X Series Oscilloscopes.
• Histogram, valid only for X6000 Series Oscilloscopes.
• CGrade, valid only for X6000 Series Oscilloscopes.

• The channel specified must be enabled for cursors to be displayed. If the channel or function is not on, an error message is issued.
• If the MarkerMode is currently not set to Waveform, then on setting source through this property will put the cursors in the Manual mode. Setting the source for one pair of markers (for example, X2Y2) sets the source for the other (for example, X1Y1).
• If the MarkerMode is currently set to Waveform, the X2Y2 source can be set separate from the X1Y1 source.
• "Math" is an alias for "Function". if the < source > is set to any of them, "Function" is returned.

Access:

ReadOnly

Type:

float

Remarks:
• X delta = (Value at X2 cursor) - (Value at X1 cursor)
• If the front-panel cursors are off, the marker position values are not defined.
• Make sure to set MarkerMode Manual or Waveform to put the cursors in the front-panel Normal mode.
property x_units¶

Sets & gets the X cursors units.

Access:

ReadWrite

Type:

CursorsXUnits

Remarks:
• The XUnits can be set to one of the following units.

• Seconds - for making time measurements.
• Hertz: for making frequency measurements.
• Degrees: for making phase measurements. Set X1 to 0 using MarkerX2Position.
• Percent: for making ratio measurements. Set X1 to 0 using MarkerX2Position.

• Changing the XUnits property affects the input and output values of the MarkerXDelta properties.
