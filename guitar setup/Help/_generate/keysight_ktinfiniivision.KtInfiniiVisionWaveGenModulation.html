property enabled¶

Enables or disables modulated waveform generator output.

Access:

ReadWrite

Type:

bool

Remarks:

• You can enable modulation for all waveform generator function types except pulse, DC, and noise.
• On T3000, X4000, X6000, M9240X and P9240X series oscilloscopes it supports both waveform generators (i.e. WaveGen1, WaveGen2).
• On X1000, X1200, X2000 and X3000 series oscilloscopes it supports one waveform generator only (i.e WaveGen1).

property type¶

Sets and gets the modulation type.

Access:

ReadWrite

Type:

ModulationType

Remarks:

• AM Modulation Type: The amplitude of the original carrier signal is modified according to the amplitude of the modulating signal.

• You can use the WaveGensModulationAMFrequency property to set the modulating signal frequency.
• You can use the WaveGensModulationAMDepth property to specify the amount of amplitude modulation.

• FM Modulation Type: The frequency of the original carrier signal is modified according to the amplitude of the modulating signal.

• You can use the WaveGensModulationFMFrequency property to set the modulating signal frequency.
• You can use the WaveGensModulationFMDeviationproperty to specify the frequency deviation from the original carrier signal frequency.

• FSK Modulation Type: The output frequency "shifts" between the original carrier frequency and a "hop frequency" at the specified FSK rate.

• The FSK rate specifies a digital square wave modulating signal.
• You can use the WaveGensModulationFSKFrequency property to specify the "hop frequency".
• You can use the WaveGensModulationFSKRateKtInfiniiVisionWaveGenModulationFSK.Rate property to specify the rate at which the output frequency "shifts"

• On T3000, X4000, X6000, M9240X and P9240X series oscilloscopes it supports both waveform generators (i.e. WaveGen1, WaveGen2).
• On X1000, X1200, X2000 and X3000 series oscilloscopes it supports one waveform generator only (i.e WaveGen1).
