KtInfiniiVisionTriggerEdge¶

Access interface members using: driver.trigger.edge
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionTriggerEdge¶

KtInfiniiVisionTriggerEdge interface.

configure(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionTriggerEdge, source: str, level: float, slope: keysight_ktinfiniivision.keysight_ktinfiniivision.TriggerSlope) → None¶

Configures the conditions for edge trigger. An edge trigger occurs when the trigger source signal passes through the trigger level with the specified slope.

Parameters:

  • source (str) – Specifies the trigger source. This value sets the Trigger Source property.

  • level (float) – Specifies the trigger level. This value sets the Trigger Level property.

  • slope (TriggerSlope) – Specifies the trigger slope. This value sets the Trigger Slope property.

Returns:

None

Remarks:

• If trigger source is VAL_LINE or VAL_WGEN, then Level parameter is ignored.
• Also, if trigger source is VAL_LINE and slope is Alternate, then slope parameter is ignored. Similarly if trigger source is VAL_WGEN and slope is any of Negative, Positive, Alternate, then slope parameter is ignored.
property reject_filter_type¶

Sets and gets the status of reject filter. Turns the low-frequency or high-frequency reject filter on or off.

Access:

ReadWrite

Type:

TriggerEdgeRejectFilterType

Remarks:

• User can turn on one of these filters at a time.
• The high frequency reject filter adds a 50 kHz low-pass filter in the trigger path to remove high frequency components from the trigger waveform. Use the high frequency reject filter to remove high-frequency noise, such as AM or FM broadcast stations, from the trigger path.
• The low frequency reject filter adds a 50 kHz high-pass filter in series with the trigger waveform to remove any unwanted low frequency components from a trigger waveform, such as power line frequencies, that can interfere with proper triggering.
• TriggerEdgeRejectFilterType can change the coupling setting.
property slope¶

Sets and gets the current slope, a rising or a falling edge, that triggers the oscilloscope.

Access:

ReadWrite

Type:

TriggerSlope

property source¶

Sets and gets the source for trigger operations. Source is dependent on TriggerType. Set TriggerType before setting source.

Access:

ReadWrite

Type:

str

Remarks:

• The parameter <source> can be specified in one of the following string formats:

• For DSO Models: { Channel<n> | External | LINE | WGEN | WGEN1 | WGEN2 | WMOD } where
n: 1 to the number of available analog channels.

• For MSO Models: { Channel<n> | Digital<d> | External | LINE | WGEN | WGEN1 | WGEN2 | WMOD } where
n: 1 to the number of available analog channels.
d: 1 to the number of available digital channels - 1.

• Wave and WGen1 are equivalent.
• WGen2 only available on models with 2 WaveGen outputs.
• WGen2 and WMod are valid with X1000, X1200, X2000 and X3000 series oscilloscopes.
• External: triggers on the rear panel ecternal trigger IN signal.
• Line: triggers at the 50% level of the rising or falling edge of the AC power source signal.
• WGen, WGen1, WGen2: triggers at the 50% level of the rising edge of the waveform generator output signal. This option is not available when the DC, Noise, or Cardiac waveforms are selected.
• WMod: when waveform generator FSK or FM modulation is used, triggers at the 50% level of the rising edge of the modulating signal.
