KtInfiniiVisionSearchRunt¶

Access interface members using: driver.search.runt
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSearchRunt¶

KtInfiniiVisionSearchRunt interface.

property condition¶

Sets and gets the runt search qualifier. It specifies whether to search for a runt that is greater than a time value, less than a time value or any time value.

Access:

ReadWrite

Type:

SearchRuntCondition

Remarks:
The Condition property can be set to one of the following values:
  • GreaterThan: to search for a runt that is greater than a time value
  • LessThan: to search for a runt that is less than a time value
  • None: to search for a runt for any time value
configure(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionSearchRunt, source: str, polarity: keysight_ktinfiniivision.keysight_ktinfiniivision.SearchRuntPolarity, condition: keysight_ktinfiniivision.keysight_ktinfiniivision.SearchRuntCondition, qualifier_time: float) → None¶

Configures the Source, Polarity, Condition and QualifierTime properties for a Runt search.

Parameters:

  • source (str) – The channel on which to search for the runt pulse. The source is a string specified in the format: Channel<n>, where n can be set to a value from 1 to the total number of analog channels available.

  • polarity (SearchRuntPolarity) – Sets/Gets the polarity for the runt search.

  • condition (SearchRuntCondition) – Specifies whether to search for a runt that is greater than a time value, less than a time value or any time value.

  • qualifier_time (float) – When searching for runt pulses whose widths are greater than or less than a time, the QualifierTime property specifies the time value.

Returns:

None

property polarity¶

Sets and gets the polarity for the runt search.

Access:

ReadWrite

Type:

SearchRuntPolarity

Remarks:
The Polarity property can be set to one of the following values:
  • Positive: to specify positive polarity for the runt search
  • Negative: to specify negative polarity for the runt search
  • Either: to specify either negative or positive polarity for the runt search
property qualifier_time¶

Sets and gets the specified runt time value.

Access:

ReadWrite

Type:

float

Remarks:

• When searching for runt pulses whose widths are greater than or less than a time, thisproperty specifies the time value (in seconds).
• With the input value suitable suffix from { s | ms | us | ns | ps } can be selected.
property source¶

Sets and gets the channel on which to search for the runt pulse.

Access:

ReadWrite

Type:

str

Remarks:
The parameter <source> can be specified in following string format: Channel<n>, where n: 1 to the number of available analog channels.
