class KtInfiniiVisionSerialBusM1553¶

KtInfiniiVisionSerialBusM1553 interface.

auto_setup(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionSerialBusM1553) → None¶

Automatically configures oscilloscope settings for triggering and serial decode on MIL-STD-1553 signals.

Returns:

None

Remarks:
Its also sets the high/low trigger thresholds, the probe attenuation to 10.0, turns on serial decode, turns off trigger noise reject and sets the trigger mode to MIL-STD 1553.
property base¶

Sets and gets the base to use for the MIL-STD 1553 decode display.

Access:

ReadWrite

Type:

SerialBusM1553Base

Remarks:
The Base property can be set to one of the following values:
  • Binary: specifies the binary base
  • Hexadecimal: specifies the hexadecimal base

Sets and gets the signal ehich is used as the source for the selected bus.

str

Remarks:
Source can be of the format: Channel<n>, where n: 1 to the number of available analog channels.
property trigger_pattern_data¶

Sets and gets the 11 bits setting to trigger on if the trigger type has been set to RTA11 (RTA + 11 Bits).

Access:

ReadWrite

Type:

str

Remarks:
This property can be specified in the following format: "nn...n", where n: {0 | 1 | X}
property trigger_rta¶

Sets and gets the Remote Terminal Address (RTA) to trigger on if the trigger type has been set to RTA using the TriggerType property.

Access:

ReadWrite

Type:

str

Remarks:
This property can be specified in one of the following formats:
  • "n", where n is an integer from 0-31
  • "#Hnn", where n: {0,..,9 | A,..,F}
  • "0xnn", where n: {0,..,9 | A,..,F}
property trigger_type¶

Specifies the type of MIL-STD 1553 trigger to be used.

Access:

ReadWrite

Type:

SerialBusM1553TriggerType

Remarks:
This property can be set to one of the following values:
  • DataStart (Data Word Start): triggers on the start of a Data word (at the end of a valid Data Sync pulse).
  • DataStop (Data Word Stop): triggers on the end of a Data word.
  • CommandStart (Command/Status Word Start): triggers on the start of Comamnd/Status word (at the end of a valid C/S Sync pulse).
  • CommandStop (Command/Status Word Stop): triggers on the end of a Command/Status word.
  • RTA (Remote Terminal Address): triggers if the RTA of the Command/Status word matches the specified value. The value is specified in hex.
  • RTA11 (RTA + 11 Bits): triggers if the RTA and the remaining 11 bits match the specified criteria. The RTA can be specifed as a hex value, and the remaining 11 bits can be specifed as a 1, 0, or X (don't care).
  • ParityError (Parity Error): triggers if the (odd) parity bit is incorrect for the data in the word.
  • ManchesterError (Manchester Error): triggers if a Manchester encoding error is detected.
  • SyncError (Sync Error): triggers if an invalid Sync pulse is found.
