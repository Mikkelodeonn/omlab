KtInfiniiVisionSearchPeak¶

Access interface members using: driver.search.peak
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSearchPeak¶

KtInfiniiVisionSearchPeak interface.

property excursion¶

Sets and gets the change in level that must occur (in other words, hysteresis) to be recognized as a peak.

Access:

ReadWrite

Type:

float

Remarks:
  • Preset value is 0.
  • The threshold level units are specified by MathFunctionFFTVerticalUnits.
    • property number_of_peaks¶

    Sets and gets the maximum number of FFT peaks to find.

    Access:

    ReadWrite

    Type:

    int

    Remarks:
  • Input range is 1 to 11.
  • Preset value is 4.
    • property source¶

    Sets and gets the FFT math function waveform that will be searched.

    Access:

    ReadWrite

    Type:

    str

    Remarks:

    • Source must be an FFT Waveform.
    • The parameter <source> can be specified in following string format:

    • Function<m>, where m: 1 to 4.
    • Math<m>, where m: 1 to 4.
    property threshold¶

    Sets and gets the threshold level necessary to be considered a peak.

    Access:

    ReadWrite

    Type:

    float

    Remarks:
  • Preset value is 0.
  • The threshold level units are specified by MathFunctionFFTVerticalUnits.
