KtInfiniiVisionTriggerEdgeBurst¶

Access interface members using: driver.trigger.edge_burst
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionTriggerEdgeBurst¶

KtInfiniiVisionTriggerEdgeBurst interface.

configure(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionTriggerEdgeBurst, source: str, slope: keysight_ktinfiniivision.keysight_ktinfiniivision.TriggerEdgeBurstSlope, idle_time: float, nth_edge: int) → None¶

Configures the trigger source, trigger slope, idle time and edge count parameters for the Nth Edge Burst trigger.

Parameters:

  • source (str) – Specifies the input that produces the Nth edge burst trigger.

  • slope (TriggerEdgeBurstSlope) – Specifies whether the rising edge (Positive) or falling edge (Negative) of the Nth edge in a burst will generate a trigger.

  • idle_time (float) – Sets the Nth edge in a burst idle resource (in seconds from 10 ns to 10 s). The timer is used to set the minimum time before the next burst.

  • nth_edge (int) – Sets the Nth edge at burst counter resource. The edge counter is used in the trigger stage to determine which edge in a burst will generate a trigger.

Returns:

None

property slope¶

Specifies whether the rising edge (Positive) or falling edge (Negative) of the Nth edge in a burst will generate a trigger.

Access:

ReadWrite

Type:

TriggerEdgeBurstSlope

Remarks:
The Slope property can be set to one of the following values:
  • Negative: specifies that the falling edge (Negative) of the Nth edge in a burst will generate a trigger
  • Positive: specifies that the rising edge (Positive) of the Nth edge in a burst will generate a trigger
property source¶

Sets and gets the Nth edge burst trigger source.

Access:

ReadWrite

Type:

str

Remarks:

• The parameter <source> can be specified in one of the following string formats:
• Channel<n>, where n: 1 to the number of available analog channels.
• Digital<d>, where d: 1 to the number of available digital channels - 1.

• If all channels are off, then "None" is returned.
