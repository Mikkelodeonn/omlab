KtInfiniiVisionMathFFT¶

Access interface members using: driver.math.fft
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionMathFFT¶

KtInfiniiVisionMathFFT interface.

property center_frequency¶

Center frequency for FFT function. Permissible values are 0 Hz to 25E9 Hz.

Access:

ReadWrite

Type:

float

Remarks:
The Unit of Frequency is Hz. The <frequency> is the current center frequency in NR3 format. The range of legal values for :
• For X1000, X1200, X2000, X3000 Series Oscilloscopes - 0 Hz to 25 Hz
• For T3000, M9240X, P9240X Series Oscilloscopes - 1 Hz to 100 GHz.
• For x6000 Series Oscilloscopes - 25 GHz to 25 GHz.
property span¶

Frequency span of the display when FFT is selected.

Access:

ReadWrite

Type:

float

Remarks:
• The current frequency span legal values are 1 Hz to 100 GHz.
• If you set the frequency span to a value outside of the legal range, the step size is automatically set to the nearest legal value.
property vertical_units¶

Specifies the FFT vertical units.

Access:

ReadWrite

Type:

MathFFTVerticalUnits

Remarks:
The VerticalUnits property can be set to one of the following values:

< units >: { Decibel | VRMS } for the FFT (magnitude) operation.
< units >: { Degrees | Radians } for the FFT phase operation.

• For the FFT (Magnitude) operation units, Decibel equates to the user interface's Logarithmic selection, and VRMS equates to the user interface's Linear selection.
property window_type¶

Windowing transforms or operations for the FFT.

Access:

ReadWrite

Type:

MathFFTWindowType

Remarks:

• The FFT operation assumes that the time record repeats. Unless an integral number of sampled waveform cycles exist in the record, a discontinuity is created between the end of one record and the beginning of the next.
• This discontinuity introduces additional frequency components about the peaks into the spectrum. This is referred to as leakage.
• To minimize leakage, windows that approach zero smoothly at the start and end of the record are employed as filters to the FFTs. Each window is useful for certain classes of input signals.

• Rectangular: useful for transient signals, and signals where there are an integral number of cycles in the time record.
• Hanning: useful for frequency resolution and general purpose use. It is goodfor resolving two frequencies that are close together, or for making frequency measurements. This is the default window.
• FlatTop: best for making accurate amplitude measurements of frequency peaks.
• Bharris (Blackman-Harris)" (triangular, with end points at zero) window is similar to the Hanning window in that it is good for making accurate frequency measurements, but its higher and wider secondary lobes make it not quite as good for resolving frequencies that are close together.
• Bartlett: (triangular, with end points at zero) window is similar to the Hanning window in that it is good for making accurate frequency measurements, but its higher and wider secondary lobes make it not quite as good for resolving frequencies that are close together. Not available for X1000, X1200, X2000 and X3000 Series oscilloscopes.
