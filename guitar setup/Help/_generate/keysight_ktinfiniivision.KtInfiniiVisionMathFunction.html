property enabled¶

Enables/Disables the math function.

Access:

ReadWrite

Type:

bool

Remarks:
• For T3000 and X4000 Series Oscilloscopes, one math function can be displayed at a time. If one math function is on and then another math function is turned on, the first math function will be turned off.
• For X6000 Series Oscilloscopes all math functions can be displayed at the same time.
• When math functions are off, they are still calculated so that they can be cascaded, that is, used as a source for a higher math function.
• Automatic vertical scaling of the math function waveform occurs when the function display is turned from off to on.

property offset¶

Voltage or vertical value represented at center screen for the selected function.

Access:

ReadWrite

Type:

float

Remarks:
• This property is equivalent to MathFunctionsReferenceLevel.
• The range of legal values is generally +/-10 times the current scale of the selected function, but will vary by function. If you set the offset to a value outside of the legal range, the offset value is automatically set to the nearest legal value.
property operation¶

Sets and gets the Waveform math operation.

Access:

ReadWrite

Type:

MathOperations

Remarks:

• Operators perform their function on two analog channel sources.
• Transforms operate on a single analog channel source or on lower math functions.
• Filters operate on a single analog channel source or on a lower math function.
• On 1000X, 2000X and 3000X series, this property can only be used by "Math2". All other math functions (i.e. "Math1", "Math3" and "Math4") does not use this property.
• Here "Math1" controls the g(t) and "Math2" controls the f(t).
• If a math function is on, changing the operator will cause an automatic vertical scaling of the new math function waveform.

  • This property is equivalent to MathsFunctionsOffset property.
    • property scale¶

    Vertical scale, or units per division, of the selected function.

    Access:

    ReadWrite

    Type:

    float

    Remarks:
    • With the input value any of <suffix> can also be used from { V | dB }.
    • Automatic vertical scaling of the math function waveform occurs when the function display is turned from off to on or, if the function is already on, when the operation is changed.
    • If you want to change the math function's vertical scaling, you should do it after the math function display is turned on or after the operation is changed.

    property source1¶

    The first source for the operation math functions or the single source for the transform functions, filter functions, or visualization functions.

    Access:

    ReadWrite

    Type:

    str

    Remarks:

    • Higher math functions can operate on lower math functions when using operators other than the simple arithmetic operations (+, - , \*, /). For example, if "Math1" is a subtraction of Channel1 and Channel2, the "Math2" could be set up as a FFT operation on "Math1". These are called cascaded math functions.
    • The Source1 property can be specified in one of the following string formats:

    • For Channel<n>, where n: 1 to the number of available analog channels. And <n>, { 1 | 2 | 3 | 4 } for 4ch models in X2000 and X3000 Series Oscilloscopes.
    • For Goft, valid only for X1000, X1200, X2000 and X3000 Series Oscilloscopes.
    • For Bus<m> where <m>, { 1 | 2 } Not valid for X1000 and X1200 Series Oscilloscopes.
    • For WMemory<r > where r: 1 to the number of reference waveforms. Only valid for T3000, X4000, X6000, M9240X and P9240X Series Oscilloscopes.
    • For Math<c> and Function<c> can be integer starting from 1 but lower than <m> where m is 1 to number of available math functions.

    • The "GOFT" parameter is only available for the FFT function. It lets you specify, as the function input source, the addition, subtraction, or multiplication of two channels.
    • To cascade math functions, select the lower math function using theis property. When cascading math functions, to get the most accurate results, be sure to vertically scale lower math functions so that their waveforms take up the full screen without being clipped.
    • When MathFunctionsOperation is Trend, because its operate on measurement it gives an error of "Settings Conflict" and not a source waveform.
    • NOTE: On 1000X, 2000X and 3000X series, "Math1" controls the g(t) function and "Math2" controls the f(t) function of the oscilloscope.
    property source2¶

    Specifies the second source for math operator functions that have two sources. It is not used for the transform functions, filter functions, or visualization functions (except when the measurement trend visualization’s measurement requires two sources).

    Access:

    ReadWrite

    Type:

    str

    Remarks:

    • Source2 property setting is not used for the transform functions like FFT, filter functions, or visualization functions (except when the measurement trend visualization's measurement requires two sources).
    • The Source2 property can be specified in one of the following string formats:

    • For Channel<n>, where n: 1 to the number of available analog channels. And <n>, { 1 | 2 | 3 | 4 } for 4ch models in X2000 and X3000 Series Oscilloscopes.
    • For WMemory<r > where r: 1 to the number of reference waveforms. Only valid for T3000, X4000, X6000, M9240X and P9240X Series Oscilloscopes.
    • "NONE": read-only, used by single-source math operations.

    • When MathFunctionsOperation is Trend, because its operate on measurement it gives an error of "Settings Conflict" and not a source waveform.
