class KtInfiniiVisionSerialBusSENTTriggerFastChannel¶

KtInfiniiVisionSerialBusSENTTriggerFastChannel interface.

property data¶

Sets and gets the status and data nibbles that will be triggered on when the FCData trigger mode is chosen.

Access:

ReadWrite

Type:

str

Remarks:

The input format of string can be of the following format:

  • <Input String> :: = "nnnn..." where n :: = { 0 | 1 | X }
  • <Input String> :: = "0xn..." where n :: = { 0,..,9 | A,..,F | X |$}
