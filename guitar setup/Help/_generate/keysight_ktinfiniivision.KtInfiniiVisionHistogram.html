KtInfiniiVisionHistogram¶

Access interface members using: driver.histogram
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionHistogram¶

KtInfiniiVisionHistogram interface.

property axis¶

Sets and gets the orientation of the histogram.

Access:

ReadWrite

Type:

HistogramAxis

Remarks:
• When "Waveform" is seletced as a HistogramMode, then this property specifies the orientation of the histogram. The <axis> chosen:

• Horizantal: The limits window is divided into columns, and the number of hits in each column is displayed in a histogram bar graph at the bottom of the graticule.
• Vertical: The limits window is divided into rows, and the number of hits in each row is displayed in a histogram bar graph at the left of the graticule.

• When "Measurement" is seletced as a HistogramMode, histograms are always displayed horizontally at the bottom of the graticule.

get_result(self: keysight_ktinfiniivision.keysight_ktinfiniivision.KtInfiniiVisionHistogram, result_type: keysight_ktinfiniivision.keysight_ktinfiniivision.HistogramResultType) → float¶

Returns the histogram results for the specified measurement.

Parameters:

result_type (HistogramResultType) – The measurement result type.

Returns:

The histogram measurement result.

Return type:

float

Remarks:
  • The result will be from the following measurements:
      BWidth: Returns the width of each bin (bucket) in the histogram.
      Hits: Returns the sum of all hits in all bins (buckets) in the histogram.
      M1S: Returns the percentage of histogram hits that lie within ±1 Std Dev of the mean.
      M2S: Returns the percentage of histogram hits that lie within ±2 Std Dev of the mean.
      M3S: Returns the percentage of histogram hits that lie within ±3 Std Dev of the mean.
      Maximum: Returns the value corresponding to the maximum bin that has any hits.
      Mean: Returns the mean value of the histogram.
      Median: Returns the median value of the histogram.
      Minimum: Returns the value corresponding to the minimum bin that has any hits.
      Mode: Returns the mode value of the histogram.
      Peak: Returns the maximum number of hits in any single bin.
      PPeak: Returns the delta between the Max and Min values.
      SDeviation: Returns the standard deviation of the histogram values.
    • property measurement¶

    The measurement to analyze.

    Access:

    ReadWrite

    Type:

    MeasurementSlot

    Remarks:
    • Available when HistogramMode is set to Measurement.
    • User can select a measurement slot if a measurement is installed at a slot.
    • There are 10 locations (or slots) that installed measurements can occupy.
    property mode¶

    The type of histogram or disables the histogram analysis feature.

    Access:

    ReadWrite

    Type:

    HistogramMode

    Remarks:
    • Off: disables the histogram analysis feature.
    • Waveform: shows the number of times a waveform crosses into (or hits) a row or column of a user-defined window.

    • For vertical histograms, the window is divided into rows.
    • For horizontal histograms, the window is divided into columns.
    • Use the HistogramAxis command to specify a vertical or horizontal histogram.

    • Measurement: shows the distribution of a measurement's results just like ordinary measurement statistics.

    • property type¶

    Specifies the histogram type.

    Access:

    ReadWrite

    Type:

    HistogramType

    Remarks:
    • When the Historgram type is

    • Horizontal: The limits window is divided into columns, and the number of hits in each column is displayed in a histogram bar graph at the bottom of the graticule. row or column of a user-defined window.
    • Vertical: The limits window is divided into rows, and the number of hits in each row is displayed in a histogram bar graph at the left of the graticule.
    • Measurement: Then it shows the distribution of a measurement's results similar to ordinary measurement statistics.

    • Preset value is HistogramTypeHorizontal.
