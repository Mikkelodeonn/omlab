KtInfiniiVisionSerialBusCollectionLister¶

Access interface members using: driver.serial_buses.lister
Where driver is a reference to the driver’s root interface returned by the constructor.
class KtInfiniiVisionSerialBusCollectionLister¶

KtInfiniiVisionSerialBusCollectionLister interface.

property display¶

sets and gets the Lister Display setting. Configures which of the serial buses to display in the lister, or whether the lister is off.

Access:

ReadWrite

Type:

SerialBusListerDisplay

Remarks:
The Display property can be set to one of the following values:
  • Off: for turning the Lister off
  • SerialBus1: to display SerialBus1 in the Lister
  • SerialBus2: to display SerialBus2 in the Lister
  • All: to display information for all serial buses. The decode information for different buses is interleaved in time in this case

Serial bus decode must be on (using the :class:`KtInfiniiVisionSerialBus`.Enabled property) before it can be displayed in the Lister.

property time_reference¶

Sets ad gets the Lister time reference setting. Configures whether the time value for a Lister row is relative to the trigger or the previous Lister row.

Access:

ReadWrite

Type:

SerialBusListerTimeReference

Remarks:
The TimeReference property can be set to one of the following values:
  • Trigger: to specify that the time value for a Lister row is relative to the trigger
  • Previous: to specify that the time value for a Lister row is relative to the previous Lister row
